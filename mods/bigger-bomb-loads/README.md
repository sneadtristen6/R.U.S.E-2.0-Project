# Bigger Bomb Loads

Multiplies bomber payload (2.0x): more bombs dropped per pass and a wider dispersion pattern, for dedicated bomber/dive-bomber aircraft only.

Rebuilt from the RUSE-Mod-Manager mod `Bigger_Bomb_Loads_V1.rmod` (version 1.0.0, made on game build 24087620) with `tools/rmod_to_mod.py`, so it builds with our engine and can go into a mod set (docs/MOD_FORMAT.md §13). Numbers and names are the original's.

**In this mod:** 12 objects changed, 22 values set.

Everything in the original is here.
