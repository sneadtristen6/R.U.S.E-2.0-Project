# Low Altitude Planes

Scales every aircraft's flight altitude to 0.25x the original (cruise altitude, attack/approach altitudes, dive-bomb start/end altitudes, and looping-maneuver altitudes all scale together) so planes fly much lower across the board.

Rebuilt from the RUSE-Mod-Manager mod `Low_Altitude_Planes_V1.rmod` (version 1.0.0, made on game build 24087620) with `tools/rmod_to_mod.py`, so it builds with our engine and can go into a mod set (docs/MOD_FORMAT.md §13). Numbers and names are the original's.

**In this mod:** 63 objects changed, 445 values set.

Everything in the original is here.
