# FNAT All The Time

It increases the pinned threshold to 2000000 which makes every unit in the game to ignore damage and not retreat, I made the change to the units also not listed in the menus like the rudel and the atomic b17, it should make operations intresting as well.

Rebuilt from the RUSE-Mod-Manager mod `FNAT_All_The_Time_V1.rmod` (version 1.0.0, made on game build 24087620) with `tools/rmod_to_mod.py`, so it builds with our engine and can go into a mod set (docs/MOD_FORMAT.md §13). Numbers and names are the original's.

**In this mod:** 294 objects changed, 294 values set.

Everything in the original is here.
