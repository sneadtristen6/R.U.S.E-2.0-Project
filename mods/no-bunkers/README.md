# No Bunkers

Removes the option to construct any nation's fixed-defense building (MG nests, AT/AA bunkers, blockhaus, pillboxes, artillery positions/shelters, outposts) by hiding them from the build menu and pricing them unaffordably. Existing bunkers already on a map are not deleted or affected -- this only blocks building new ones.

Rebuilt from the RUSE-Mod-Manager mod `No_Bunkers_V1.rmod` (version 1.0.0, made on game build 24087620) with `tools/rmod_to_mod.py`, so it builds with our engine and can go into a mod set (docs/MOD_FORMAT.md §13). Numbers and names are the original's.

**In this mod:** 17 objects changed, 34 values set.

Everything in the original is here.
