# Infinite Fanaticism

Sets every unit's Pinned threshold to one point above its own HP, so it would have to take more damage than it can survive to ever be suppressed -- units fight until destroyed instead of breaking under fire.

Rebuilt from the RUSE-Mod-Manager mod `Infinite_Fanaticism_V1.rmod` (version 1.0.0, made on game build 24087620) with `tools/rmod_to_mod.py`, so it builds with our engine and can go into a mod set (docs/MOD_FORMAT.md §13). Numbers and names are the original's.

**In this mod:** 306 objects changed, 306 values set.

Everything in the original is here.
