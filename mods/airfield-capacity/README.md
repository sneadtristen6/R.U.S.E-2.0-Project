# Airfield Capacity

Raises the number of planes that can fit in an Airfield from 8 to 128.

Rebuilt from the RUSE-Mod-Manager mod `Airfield_Capacity_V1.rmod` (version 1.0.0, made on game build 24087620) with `tools/rmod_to_mod.py`, so it builds with our engine and can go into a mod set (docs/MOD_FORMAT.md §13). Numbers and names are the original's.

**In this mod:** 1 object changed, 1 value set.

## Assumptions to check in-game

- the TTunableConstante the original changed by position is changed in every TTunableConstante object instead (the game has one per constants file)

Everything in the original is here.
