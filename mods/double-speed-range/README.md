# Double Speed & Range

Doubles movement speed, attack range (unit reflex range + weapon range), and vision range for every ground unit, aircraft, and infantry squad.

Rebuilt from the RUSE-Mod-Manager mod `Double_Speed_Range_V1.rmod` (version 1.0.0, made on game build 24087620) with `tools/rmod_to_mod.py`, so it builds with our engine and can go into a mod set (docs/MOD_FORMAT.md §13). Numbers and names are the original's.

**In this mod:** 424 objects changed, 1305 values set.

Everything in the original is here.
