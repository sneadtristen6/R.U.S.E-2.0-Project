# Tanks Only

Every nation can only build tanks: 41 real tank units stay buildable, while every infantry unit, aircraft, and non-tank ground unit (recon, anti-tank, AA, artillery) is hidden from the build menu and priced unaffordably. Tanks that technically carry artillery ammunition (indirect-fire weapons, same as the dedicated Artillery category) are excluded too -- the Semovente and Breda Dovunque self-propelled guns, the FCM F1's howitzer turret, the Sau 40, and the OI Heavy Tank. Nothing is deleted -- fixed defenses, HQs, Depots and Admin buildings still work normally.

Rebuilt from the RUSE-Mod-Manager mod `Tanks_Only_V1.rmod` (version 1.0.0, made on game build 24087620) with `tools/rmod_to_mod.py`, so it builds with our engine and can go into a mod set (docs/MOD_FORMAT.md §13). Numbers and names are the original's.

**In this mod:** 186 objects changed, 372 values set.

Everything in the original is here.
