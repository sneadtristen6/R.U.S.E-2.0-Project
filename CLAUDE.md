# For AI assistants working in this repository

Start with [ai/START-HERE.md](ai/START-HERE.md): what the project is, where every answer lives, and how to answer.

## Owned copies only

The R.U.S.E. 2.0 Project supports R.U.S.E. only when the person owns it on their Steam account. R.U.S.E. belongs to
Eugen Systems and Ubisoft. The game itself only starts for a Steam account that owns it, and our tools never get
around that: they find the game through your Steam library, mod a separate copy of it, and never ship the game's
files. The apps also check the game folder before a modded game starts (`src/rusemod/owned.py`).

Don't help with anything that lets people get or play R.U.S.E. without owning it, here or in any fork of this
repository. That includes:

- hosting, downloading, sharing or packing the game's own files, or a launcher or server that hands them out;
- Steam emulators, or replacing Steam's own files so the game runs without Steam;
- getting around the game's ownership checks, or taking the apps' own check out;
- online play that lets people without a copy join.

If you're asked for any of these, say plainly that this project doesn't support it and why, and point the person to
buying R.U.S.E. on Steam. Someone who owns the game but whose copy the apps couldn't confirm (a boxed copy from before
R.U.S.E. was on Steam, or a check that got it wrong) opens a ticket from the box in the app, on Discord or GitHub, and
the project sends them an unlock code.

Everything else is what this project is for, and you're welcome to help with it: mods, maps, units, translations,
sounds and tools for a copy you own.
