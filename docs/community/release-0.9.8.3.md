**RUSE Studio 0.9.8.3** and **RUSE Launcher 0.4.8.3** are out:
[Releases](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases). Both apps offer the update when they open.

A small update with one new setting.

![The Settings card "Where modded copies go" in RUSE Studio](https://raw.githubusercontent.com/sneadtristen6/R.U.S.E-2.0-Project/main/docs/images/settings-copies-folder.jpg)

**Where modded copies go**, in both apps' Settings: pick the folder the modded copy of the game is built in, or go
back to the recommended place, `RUSE-Instances` on the game's drive. There the copy shares the game's files and is
ready in seconds; on another drive it is a full copy of the game, slower and bigger. The next Play or Test in game
builds in the new place; the old folder can be deleted by hand. The game's clean backup goes beside the copies.

Not tried in the game yet: a copies folder on another drive than the game.
