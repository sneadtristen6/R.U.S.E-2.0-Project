# はじめてのMOD

> **対象:** はじめてのモッダー · **必要なもの:** Steam 版 R.U.S.E. · **所要時間:** 10分

最初から最後までの手順です。Studio をインストールし、M4 Sherman の価格を $1 にするMODを作って、ゲームで確かめます。

## 1. RUSE Studio をインストールする

1. [Studio のリリース](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=studio)からインストーラーをダウンロードして実行します（「Windows によって PC が保護されました」と出たら **詳細情報**、**実行**）。
2. 最初の起動では、ゲームのファイルを読み込んで索引を作ります。1～2分かかり、ゲームの更新ごとに1回だけです。

## 2. MODを作る

Studio は **何をしますか？** の画面で開きます: **MODの続きを作る**、**新しいMODを始める**、または **スキップ**（**この画面を常にスキップする** にチェックを入れると、それ以降はすぐにタブが開きます。設定 でまた表示できます）。

1. **新しいMODを始める** をクリックします。その手順が上部のバーに、**戻る** と **次へ** と一緒に表示されます:
   - **名前:** 名前を入力します。たとえば `cheap-sherman`（プレイヤーが Launcher で見る名前です）。
   - **国:** 国ごとに、**ユニットを残す**（生産メニューはゲームのまま）か **空にして始める** を選びます。**変更** で、その国に新しい名前と国旗を付けられます（[[国を別の国に作り変える|国を別の国に作り変える]]）。
   - **研究:** **ゲームの研究をそのまま使う**、**研究なし**（どのユニットも最初から生産できます）、または **カスタム**。
   - **建物:** 各国の建物と、それぞれが生産するもの（[[建物と生産メニュー|建物と生産メニュー]]）。
   - **その他:** 次に変えたいものにチェックを入れます（ユニットの値、AIとプレイヤーの設定、音楽とサウンド、その他の値）。それぞれが専用のタブで開きます。この手順では **ユニットの値** にチェックを入れてください。
2. ゲームのユニットと研究はそのままにして、ユニット タブが開くまで **次へ** を押します。

すでに Studio を開いていますか？ ヘッダーの **MOD** メニューにも **新しいMOD…** があります: 名前を入力して **作成** をクリックしてください。

ここから先、変更したものはすべてこのMODに保存され、ゲームには保存されません。

## 3. Sherman を変える

1. **ユニット** タブを開き、検索ボックスに `sherman` と入力します。
2. **M4 Sherman** をクリックします。
3. 価格を見つけて `1` と入力します。すぐに保存され、横に元の値が表示されます。**元に戻す** で元に戻ります。

## 4. テストする

1. **ゲームでテスト**（ヘッダー）をクリックします。Studio はMODをチェックし、MOD入りのコピー（PC全体で1つ。ゲームと同じドライブの `RUSE-Instances\Modded game`、または 設定 で選んだフォルダー）をビルドして、R.U.S.E. を起動します。
2. ゲームのメインメニューで **バトル**（コンピューターとの自由な対戦）をクリックし、好きなマップを選んでアメリカでプレイし、戦車工場を開きます。Sherman の価格が $1 になっています。

> [!TIP]
> 代わりにヘッダーの下に赤いバーが出たら、MODのチェックがMODのファイルに誤りを見つけたということです。
> [[うまくいかないとき|うまくいかないとき]] を見てください。
