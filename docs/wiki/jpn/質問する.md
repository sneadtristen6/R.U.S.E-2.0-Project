# 質問する

マニュアルに見つかりませんでしたか？
[Discussions > ❓ Help](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) で質問してください（投稿には無料の GitHub アカウントが必要です）。

1. まず Help を検索してください。誰かがすでに同じ質問をしているかもしれません。
2. やろうとしていること、試したこと、使っているアプリとバージョンを書いてください。
3. 回答で解決したら **Mark as answer** をクリックしてください。次の人がその回答を見つけられます。
