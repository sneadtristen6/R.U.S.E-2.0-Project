# 他の時代のユニット

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.9.8.2 以降とMOD · **所要時間:** 1ユニットにつき1、2分

第一次大戦から現代までの366のユニットが、**ユニット** タブでゲーム自身のユニットと並んでいます: 第一次大戦、第二次大戦+、冷戦、現代の戦車と航空機が、1つのゲームの中に。どれも別の作者による無料の 3D モデル（CC BY）で、すでにゲームに合わせてあり、その国のマーキングが付き、クレジットされています。追加するまでは、どれもMODには入っていません。

## ある時代のユニットを手に入れる

1. **ユニット** タブで、種類の上にある時代を選びます: **第一次大戦**、**第二次大戦+**、**冷戦**、**現代**（**バニラ** はゲーム自身のユニットで、いつものリストです）。
2. 初回は、その時代のユニット数とサイズが **第一次大戦のユニットをダウンロード**（またはその時代のもの）と一緒に表示されます。Studio はプロジェクトの GitHub からダウンロードし、使う前にすべてのファイルを確認して、リストに並べます。

   | 時代 | ユニット | ダウンロード |
   |---|---|---|
   | 第一次大戦 | 61 | 232 MB |
   | 第二次大戦+ | 32 | 198 MB |
   | 冷戦 | 149 | 996 MB |
   | 現代 | 124 | 709 MB |

3. ダウンロードした時代は、新しいユニットが公開されると自分で更新されます: Studio がそう知らせて、取ってきます。

時代のユニットも、ゲームのものと同じように絞り込めます: 種類（地上か航空）、国（中国も）、タイプ、そして検索ボックス。

## MODに加える

1. ユニットをクリックします。そのページに、モデルの画像と作者が表示されます: **モデル作者** とその名前、ライセンス、そして作者が公開した場所へのリンク。
2. フォームを埋めます:
   - **新しいユニットの名前**（すべての言語で表示されます）。
   - **ベースにする**: 最初の値（速度、装甲、武器、遊び方）を引き継ぐゲームのユニット。おすすめのものが最初にあります。同じ種類のユニットならどれでも選べます。
   - **価格**（すべてのバトルの日付）。
   - **サイズ**: 1 でベースのユニットと同じ長さです。提案されるのは実物大（実際の幅、航空機なら翼幅を、ゲーム自身の縮尺で）で、0.05 から 20 まで選べます。スライダーをドラッグするか、名前の付いた位置の1つをクリックします: **極小**、**ゲームのサイズ**（1: ベースのユニットと同じ長さで、ゲームがその種類のユニットを描く大きさ）、**実物大**、**巨大**。実物大の現代の航空機は、ゲームの第二次世界大戦の航空機よりずっと大きくなります（J-16 は Lancaster と同じくらいの長さです）。
   - **生産メニュー**: その国と、購入する工場。
   - **研究元**: それを研究するユニット、または **なし：最初から購入可能**、それに **研究価格** と **研究時間**（時間は秒か分で入力します: 隣の切り替えで選びます）。
3. **MODに追加** をクリックします。これでMODの新しいユニットになりました: **ページを開く** で、ほかのユニットと同じように、どの値も、モデルも、カードも変えられます。**MODから取り除く** で、また削除できます。

## 後からサイズを変える

ユニットのページの **独自のモデル** に、同じスライダーがあります: サイズを選んで **サイズ変更** をクリックします（モデル自身のファイルからもう一度合わせ直されるので、選ぶものはありません）。**MODのすべての航空機**（または地上ユニット）で、すべてを一度に変えられます: **ゲームのサイズ**、**実物大**、**小さく**（5分の1）、**大きく**（4分の1）。ゲームはユニットのモデルを読み込むときに読むので、遊んでいる間にサイズは変わりません: 新しいサイズは次のビルド（ゲームでテスト）から表示されます。

## 研究の連鎖

ユニットは、その国の生産メニューのどのユニットからでも研究できます。自分のMODの時代ユニットからもです: 冷戦の戦車を加え、次にそれから研究する現代の戦車を加えます。第一次大戦と第二次大戦+のユニットはすぐに購入できます。冷戦と現代のユニットは、ふさわしいユニットから研究するものとして始まります（どれを提案するか、そしてその理由は、フォームに書かれています）。

他のユニットの研究元になっているユニットを取り除くとき、どうなるかは **設定 > 研究** で決まります:

- **先に警告する**（既定）: Studio はそのユニットから研究されるユニットを **それでも外す** と一緒に並べます。
- **拒否する**: ユニットは残り、先に他のユニットをどう変えればよいかがメッセージに表示されます。
- **つなぎ直す**: それぞれ、取り除いたユニット自身の親から、それぞれの価格と時間で研究されるようになります（または最初から購入可能になります）。

なくなったユニットから研究されることになったままのユニットは、その **アップグレードと研究** ボックスと確認バーにそう表示され、別のユニットを選ぶか、なしにするまで、ビルドはそこで止まります。

## 騎馬分隊

**第二次大戦+** には **騎馬分隊** も並びます。作者は sneadtristen6 で、小銃兵と重火器兵がそれぞれ自分の馬に乗ります。
何もダウンロードしないので、第二次大戦+ のユニットをダウンロードしたかどうかに関係なく表示されます。時代のユニットと同じく、
追加するまでMODには入りません。

1. クリックします。ページに作者と、追加すると何が起きるかが書かれています。
2. 時代のユニットと同じようにフォームを埋めます：名前、価格、**生産メニュー**、**グループ**、そして **研究元** のユニット。
   **ベースにする** は常にゲームの G.I. 分隊（アメリカの小銃兵）です。馬と騎手はその分隊の兵士用に作られるためです。
3. **MODに追加** を押します。Studio があなたの PC で、あなた自身のゲームから馬と騎手を作り、ユニットを作成し、
   小銃兵と重火器兵に馬を与えます。各手順は進むたびにボタンの下に経過時間とともに表示されます。必要なものをゲームから
   得られない場合は、Studio が理由を表示し、何も追加されません。
4. これでMODの新しいユニットです。**ページを開く** で、ほかのユニットと同じくどの値でも変更できます。
   **MODから外す** で、2 つのモデルとそのアニメーションごと外れます。

作者の sneadtristen6 は、MODの `CREDITS-era-units.md` に時代のユニットの作者と並んで記載されます。

ゲームで確認済み：G.I. 分隊のコピーに **モデルを読み込む…** で作った、馬に乗ったこの騎手たち。ゲームでまだ試していない
こと：このリストから追加した騎馬分隊。

## クレジット

時代ユニットの作者は、すべてクレジットされます: そのページと、ユニットを加えたときに Studio が書くMODの `CREDITS-era-units.md` に。このファイルはMODと一緒に残してください: モデルのライセンスがそれを求めています。作者の全リストは [時代ユニットのリリース](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases/tag/era-units) にあります。

## ゲームで確認できたこと

確認済み: すぐに読み込まれ、生産メニューに独自のカードが出ること。研究タブとアップグレードの連鎖。独自のモデル。サイズ。まだ試していないもの: 牽引砲（インポーターがまだ合わせられないので、ベースのユニットのモデルで表示されます）、そしてゲームが研究時間を秒で数えるかどうか。
