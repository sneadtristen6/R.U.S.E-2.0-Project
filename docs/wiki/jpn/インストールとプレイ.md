# インストールとプレイ

> **対象:** プレイヤー · **必要なもの:** Steam の R.U.S.E.（インストール済み） · **所要時間:** 5分

**手短に言うと:** リリースページから **RUSE-Launcher-Setup** をダウンロードして実行し、**RUSE Launcher** を開いて **対応MOD** をクリック、MODにチェックを入れて **インストール** を押し、MODセットに入れたら **プレイ**。下の各ステップで、どこをクリックするかを正確に説明します。

MODで遊ぶのに必要なのは **RUSE Launcher** だけです。**RUSE Studio** はMODを作るためのものです（このページの最後を参照）。

## ステップ1: Launcher をダウンロードする

1. [Launcher のリリース](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=launcher)のページを開きます。
2. 最新のものがいちばん上にあり、**Latest** と表示されています（例: *RUSE Launcher 0.4.8.9*）。
3. その下の **Assets** までスクロールし、**RUSE-Launcher-Setup-0.4.8.9.exe** をクリックします（バージョン番号は変わります。`RUSE-Launcher-Setup` で始まる `.exe` を選んでください）。ブラウザーがダウンロードします。

そこにある他のファイル（`RUSE-Launcher-notes.json`、*Source code*）は必要ありません。

## ステップ2: インストールする

1. ダウンロードしたファイルを開きます（ふつうは **ダウンロード** フォルダーにあります）。
2. **「WindowsによってPCが保護されました」と出たら:** **詳細情報** をクリックし、次に **実行** をクリックします。このアプリは Windows の評価チェックにとってまだ新しいものです。コードはこの GitHub で公開されています。
3. インストーラーを進めます。**ゲームファイルのクリーンなコピーを保存する** はチェックしたままにしてください。アプリがゲームのフォルダーを変えることはありませんが、他のMODマネージャーや手作業の編集は変えることがあり、MOD入りのゲームはどれもそのファイルから作られます。コピーはアプリの初回起動時に作られます（数分かかり、ゲームとほぼ同じディスク容量を使います）。
4. **RUSE Launcher** を起動します（スタートメニューか、デスクトップのショートカット）。初回は **言語を選んでください**: 11の言語のどれでも選べます（ゲームの10言語とペルシア語（فارسی））。上部の言語ボタンで、いつでも変えられます。Launcher は Steam を通じて R.U.S.E. を自分で見つけます。見つからないと表示されたら: **設定 > ゲームフォルダ > フォルダを選ぶ…** で、`RUSE.exe` があるフォルダーを選びます（ふつうは `C:\Program Files (x86)\Steam\steamapps\common\R.U.S.E`）。

> [!IMPORTANT]
> **R.U.S.E. 2.0 は、Steam で所有しているゲームのコピーでしか動きません。** MOD入りのゲームが始まる前に、Launcher と Studio がゲームフォルダーをチェックします: そこに R.U.S.E. がインストールされたという Steam の記録、その中にある Steam 自身のファイル、そしてゲームを Steam なしで動かすファイルがないこと。確認できない場合は、ボックスにその理由と対処法が表示されます（それまで **プレイ** はオフのままです）: [[うまくいかないとき|うまくいかないとき]] を参照してください。

## ステップ3: MODを手に入れる

**私たちのリストから（いちばん簡単）:** **対応MOD** をクリックし、欲しいMODにチェックを入れて **インストール** を押します。各ファイルはダウンロードされ、ライブラリに入る前にリストと照らし合わせて確認されます。

**誰かが共有したファイルから:** **MODファイルを追加…** をクリックしてファイルを選ぶか、ファイルをウィンドウにドラッグします。Launcher が受け付けるのは:
- `.rusemod`: RUSE Studio で作られたもの
- `.rmod`: LittleGroove の RUSE Mod Manager 用に作られたもの
- `.zip`: MODのフォルダーを zip にしたもの

まずファイルを確認します。MODでないファイルや、プログラムを含むファイルは、理由を示して拒否されます。

**ゲーム本体のファイルの形で配られている古いMOD**（ゲームフォルダーにコピーするように言われた `.dat` パック）: **古いMODを変換…** をクリックし、そのフォルダーを選んで名前を付け、**変換してライブラリに追加** をクリックします。ゲームフォルダーには手を触れません。

## ステップ4: 遊ぶものを選ぶ

1. **MODセット** とは、一緒に遊ぶMODを順番に並べたものです。**新しいMODセット…** をクリックし、MODを追加して順番に並べます（2つのMODが同じものを変えるときは、下にあるほうが優先されます）。
2. 一緒に遊べない2つのMODがあると、Launcher は遊ぶ前に、どれとどれか、そしてその理由を教えてくれます。

## ステップ5: プレイ

MODセットを選んで **プレイ** を押します。初回は Launcher がMOD入りのゲームのコピーをビルドします（1分ほど）。その後は変わった部分だけです。そして R.U.S.E. が、あなたのMOD入りで起動します。

MOD入りのゲームには **金色の R.U.S.E. 2.0** が表示されます: バトルの場面で始まり、メインメニュー、各メニュー、ロード画面に金色のタイトルが付きます。これは初回に、あなたの PC で、あなた自身のゲームのファイルから作られます（一度だけ、数分）。ゲーム本来のタイトルのままにするには、**設定** の **ゲームのタイトル** のチェックを外してください。

> [!NOTE]
> **Steam** から R.U.S.E. を起動すると、これまでどおりMOD**なし**でゲームが始まります。MODで遊ぶには、Launcher の **プレイ** から起動してください。Steam のインストールが変更されることはありません。

## 更新

Launcher は起動するたびに新しいバージョンを確認します。更新があると表示されたら **今すぐ更新** をクリックしてください。更新が「certificate verify failed」で失敗する場合は、ステップ1の最新の `RUSE-Launcher-Setup` をブラウザーでダウンロードして実行してください。古いものの上にインストールされ、MODはそのまま残ります。

**必須のアップデート：** 必須と指定されたアップデート（セキュリティ修正などの重要なもの）は飛ばせません。Launcher の上に画面が表示され、アップデートが自動でインストールされてから Launcher がもう一度開きます。インストールが終わるまで **プレイ** は使えません。インターネットにつながっていないときは画面がそう伝えます。接続して **もう一度試す** を押してください。Studio も同じで、**ゲームでテスト** が使えなくなります。

## 困ったときは

| 表示されるもの | 対処法 |
|---|---|
| 「WindowsによってPCが保護されました」 | **詳細情報**、次に **実行**（ステップ2）。 |
| Launcher が R.U.S.E. を見つけられない | **設定 > ゲームフォルダ > フォルダを選ぶ…** で、`RUSE.exe` のあるフォルダーを選ぶ。 |
| 「certificate verify failed: unable to get local issuer certificate」 | Launcher 0.4.8.4 以降を入手してください（ステップ1）。[[うまくいかないとき|うまくいかないとき]] も参照。 |
| MODのインストール時に「unable to get issuer certificate」または「この PC はサイトのセキュリティ証明書を信頼していません」 | Launcher 0.4.8.9 以降を入手する（ステップ1）か、ブラウザーでMODをダウンロードして **MODファイルを追加…** を使ってください。[[うまくいかないとき|うまくいかないとき]] も参照。 |
| ゲームが自分のMODなしで始まる | Steam からではなく、Launcher の **プレイ** で起動してください。 |
| フレンドが自分のゲームに参加できない | 全員が同じMODを同じ順番で入れている必要があります: [[フレンドとプレイ|フレンドとプレイ]]。 |
| その他 | [[うまくいかないとき|うまくいかないとき]]、または [Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) や [Discord](https://discord.gg/h54t5baNsC) で質問してください。 |

## Linux と Steam Deck（Proton 経由）

アプリのウィンドウがページを表示できないとき（Proton では Microsoft の WebView2 が起動しないため、青いままになります）、アプリは代わりに Web ブラウザーで開き、小さなボックスがそれを知らせます。遊んでいる間はボックスを開いたままにし、閉じるとアプリも閉じます。Linux ではまだ試していません。どうだったかを [Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) で教えてください。

## MODを作る: RUSE Studio

1. [Studio のリリース](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=studio)のページを開きます。Studio はプレビュー版なので、そのリリースには **Pre-release** と表示されています。最新のものを選んでください。
2. **Assets** の下の **RUSE-Studio-Setup-0.9.8.9.exe**（最新バージョン）をクリックし、ステップ2と同じように実行します。
3. **RUSE Studio** を起動し、[[はじめてのMOD|はじめてのMOD]] に沿って進めてください（10分）。
