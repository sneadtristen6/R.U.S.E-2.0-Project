# モデルの取り込み

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.9.6 以降、MOD、3D モデル（.3ds、.glb または .gltf） · **所要時間:** 数分

新しいユニットに、Blender などの 3D ツールで作った独自の 3D モデルを付けます。[M1 Abrams のMOD](https://github.com/sneadtristen6/Ruse-Mods) はこうして作られました: 別の 3D プログラムから R.U.S.E. に取り込まれた最初のモデルで、ゲームで確認済みです。

モデルは、新しい建物に、その見た目の一部の代わりとして付けることも（[[建物と生産メニュー|建物と生産メニュー]] を参照）、自分の岩、小物、茂み、木としてマップに置くこともできます（[[建物と木を配置する|建物と木を配置する]] を参照）。どちらも Studio 0.9.8.8 からで、ゲームで確認済みです。

ユニットのページでは、これらはすべて **見た目と動き** にあります: **モデルを読み込む…** は **モデル** の行のボタンで、モデルの残りの設定（サイズ、**移動**、**Blenderで変更**）はその行の **もっと見る** の中にあります。**分隊の兵士** は独立した行で、モデルのアニメーションの働きは **サウンドとアニメーション** の行の **もっと見る** の中にあります。

## 1. モデルを用意する

画像（.tga または .png）付きの **.3ds**、または **.glb** か **.gltf**（画像は中に入っています: PNG、JPG または WebP）。取り込み機能が読めないモデル（圧縮されたメッシュ、KTX2 の画像）では、そのことと、Blender での直し方が表示されます。

- **Blender から:** File > Export > glTF 2.0（ファイル > エクスポート > glTF 2.0）、形式は **glTF Binary (.glb)**。
- **無料モデルのサイトから:** 多くの戦車は、.tga 画像のフォルダーが付いた .3ds で配られています。フォルダーは届いたままにしておいてください: Studio は .3ds の隣や1つ上のフォルダーにある画像を、.3ds ファイルが使う短縮名（`Main_Defuse.tga` なら `MAIN_DEF.TGA`）でも見つけます。
- MODを共有する前にモデルのライセンスを確認し、MODの README で作者をクレジットしてください。

**役に立つこと:** 部品に、それが何かを表す名前が付いていること。Studio は、名前に *turret*（または *tourelle*、*tower*）を含む部品を砲塔と一緒に回し、*barrel*、*gun*、*cannon* を含む部品も一緒に回します。砲塔の上に載っている部品も一緒に回ります。それ以外はすべて車体と一緒に動きます。砲はまっすぐ前を向いているようにしてください。

Abrams の例: **"Tank Abrams" by ags**、[downloadfree3d.com](https://downloadfree3d.com/3d-models/vehicles/tank/tank-abrams/) で無料（.3ds と .tga 画像、部品名は Main_Body、Main_Turre、Main_Barre など）。

## 2. ユニットを作る

**ユニット** タブで、上部の **新しいユニット（モデルを読み込む）** をクリックし、元にするユニットを選びます（戦車なら戦車: Abrams なら Sherman）。名前を付けて **作成** をクリックすると、新しいユニットのページが **モデルを読み込む…** のところで開きます。新しいユニットのモデルは、このユニットのモデルと同じように回転し、走ります。ゲームのユニットのページにも同じ入り口があります: **見た目と動き** の **モデル** の行の **このユニットから新しいユニット…**。（Studio 0.9.6 にはどちらのボタンもまだありません: ユニットを開き、そのページで **新しいユニット…** を選んでください。）

## 3. 取り込む

新しいユニットのページの **見た目と動き** の **モデル** の行で:

1. **もっと見る** を押して **サイズ** を設定します: コピー元のユニットに対する長さの比です。**1** は同じ長さ。Sherman に対する M1 Abrams は **1.36** です（実際の全長の比）。
2. **モデルを読み込む…**（行のボタン）をクリックし、.3ds か .glb を選びます。

Studio はモデルをユニットに合わせます: 前向き（砲が向いている方向）、長さ、コピー元のユニットと同じ位置、モデル上の位置のまま回る砲塔、地面に立つ位置。画像はそのモデル専用のテクスチャになります。ページには 3D で表示され、どの部品が砲塔と一緒に回るかも分かります。見つからなかった画像があれば、それがどれかを表示します: 画像をモデルの隣に置いて、もう一度取り込んでください。

MODには `files/models/<the unit's name>.glb` として保存されます。**コピー元のモデルを使う** で、また取り除けます。

**後からサイズを変える:** サイズのボックスの下のスライダーは **極小** から **巨大** まで（0.05 から 20）で、**ゲームのサイズ**（1）と、時代ユニットなら **実物大** に印が付いています。**サイズ変更** をクリックすると、モデル自身のファイルからもう一度合わせ直されます。新しい航空機（または地上ユニット）が複数あれば、1回のクリックで全部のサイズが変わります。ゲームはモデルを読み込むときに読むので、新しいサイズは次のビルドから表示されます。

**置かれる位置:** 新しいモデルはコピー元のユニットの中央に置かれるので、ほとんどのモデルはここで何もする必要がありません。うまく収まらないときは、**モデル** の行の **もっと見る** で、サイズの下の **移動** を使ってください。**前**、**右**、**上** の3つの数値を、ゲームの単位で入れます（コピー元のユニットの長さがその単位でいくつかは、ページに表示されます）。マイナスは逆向きで、0, 0, 0 で合わせた位置に戻ります。**移動する** をクリックすると、モデル自身のファイルから、その分だけ離して合わせ直されます。砲塔とプロペラも一緒に動くので、正しい場所で回り続けます。3D ビューの青い輪はコピー元のユニットが立つ位置で、輪の上の印が前です。サイズを変えても移動はそのままです。ユニット自身のボーンにリギングされたモデル（兵士、砲の操作員）は、ボーンのある場所から動きません: そうしたモデルは Blender で動かしてください。Studio 0.9.8.17 より前に取り込んだモデルは、もう一度取り込むか移動するまで、サイズを変えても以前の位置（砲塔がコピー元のユニットの砲塔の上）のままです。時代ユニットのモデルは、それぞれ元の位置のままです。

**航空機:** Studio から Blender で開いて取り込み直した航空機は、前を向き、コピー元の航空機のプロペラがどうであれ、モデルにあるプロペラをその位置に、その数だけ保ちます: 地上ではブレード、空中では回転する円盤です。ゲームで確認済み。ほかの場所から持ってきたモデルは、プロペラを描かれたまま、止まった状態で保ちます: 取り込み機能は、どの部品がプロペラかをまだ見分けられません。3D ビューでは、ゲームが回転するプロペラを描くのと同じように、航空機の円盤が半透明で表示されます。

**兵士、砲の操作員、さらに多くの航空機:** 兵士、砲の操作員、そして以前は Studio がモデルを合わせられなかった航空機（P-47 など）にも、ユニット自身のボーンにリギングされたモデルなら、独自のモデルを付けられます: たとえば、ゲームのモデルの1つを Studio から Blender で開き、そこで変更したものです。モデルは何も動かされず、拡大縮小もされずに、そのままそのボーンに付きます。同じモデルで描かれる分隊のほかの兵士も、同じモデルを身に着けます。小銃分隊、砲の操作員、P-47 で、ゲームで確認済み。ゲームが専用のモデルで描く重火器兵（米軍小銃分隊のバズーカ兵）は、下の **分隊の兵士** でモデルを与えるまで、元のモデルのままです。

**MODのプレイヤー:** Studio 0.9.8.17 以降で取り込んだモデルを含むMODには、Launcher 0.4.8.17 以降が必要です: それより古い Launcher はモデルにコピー元のユニットのスケルトンを与えるため、砲塔が間違った点を中心に回ります。0.4.8.17 は必須のアップデートなので、Launcher が自動でインストールします。

## 自分の兵士を作る手順

分隊（小銃兵、空挺兵、どの歩兵でも）なら、Blenderの作業をStudioが一緒に進めます。

1. **分隊を作ります。** 上の手順2と同じように、分隊（たとえばアメリカの小銃分隊）から作ります。
2. **兵士をBlenderで開きます。** 新しい分隊のページの **独自のモデル** で **Blenderで変更** を押します。兵士と骨が、ゲームと同じ位置でBlenderに開きます。Blenderがない場合は **Blenderを入手（無料）** でインストールし、すでにある場合は **Blenderを選択…** で場所をStudioに教えます。
3. **兵士を変えるか、自分のモデルを骨に付けます。** 変える場合はそのまま編集します。自分のモデルを使う場合は、**File > Import** で同じシーンに読み込み、兵士に重ねます。自分のモデルをクリックし、**Shift+クリック** で骨を選び、**Ctrl+P > With Automatic Weights** を押します。ゲームの兵士を残さない場合は削除します。
4. **送ります。** Blender上部の **R.U.S.E. Studioへ送る** を押します。
5. **戻します。** Studioで **モデルを戻す** を押します。分隊の小銃兵があなたのモデルになります。ゲームが重火器兵を専用のモデルで描く分隊（米軍小銃分隊のバズーカ兵など）では、モデルを与えるまで、重火器兵はコピー元の分隊と同じです。**分隊の兵士** の行に兵士ごとの状態が表示され、そこの **モデルを読み込む…** はその兵士専用です。**ゲームでテスト** で確認できます。

知っておくと便利なこと:
- Blenderのファイルはmodのフォルダーに残ります：`Documents\RUSE 2.0\Mods\<あなたのmod>\blender\<ユニット名>\`。modを共有するときには含まれません。次の **Blenderで変更** は、最後に送ったものから始まります。
- モデルの一部の点に骨がない場合（Blenderの自動ウェイトはいくつか漏らします）、ページがその数を表示します。それらは兵士の腰と一緒にしか動きません。**Weight Paint** で骨に塗ってから、もう一度送ってください。
- **カスタム軍服** の分隊では、あなたのモデルが軍服の代わりになり（塗装はmodに残ります）、**コピー元のモデルを使う** で軍服が戻ります。
- ゲームの兵士の骨で作った.glbがすでにある場合は、**モデルを読み込む…** でそのまま取り込めます。
- 分隊が使うモデルは、取り込んだ後、modのフォルダーに `files\models\<ユニット名>.glb` として保存されます。重火器兵専用のモデルは `files\models\<ユニット名>@bazooka.glb` です。
- **分隊の兵士** には、分隊のほかの人形がどのモデルで描かれるかも表示されます：倒れた兵士と、遠くから見たときの人形（米軍小銃分隊では、バズーカ兵のモデルで描かれます）。

## このユニットのアニメーション：各動作で再生するもの

独自のボーンを持つモデル（馬、騎手を乗せた馬、どんな生き物でも）は、自分のアニメーションも一緒に持ち込みます。ユニットの
ページの**このユニットのアニメーション**には、ゲーム内の各動作でユニットが何を再生するかが表示されます：

- **じっと立つ**、**歩く**、**走る**が最初に並びます：モデルに最低限必要なものです。どれかに専用のものがなければ、ページが
  そう伝え、代わりに何を再生するかを示します。
- 各動作はモデルのアニメーションの一覧です。1つ選ぶか、**最も近いもの**のままにします：その場合はモデルが持つ一番近いもの
  を再生し、一覧がどれかを示します。最も近いものとは、順に：その動作の名前のアニメーション（stand や idle、walk、run や
  gallop、fire、death など）、なければ一番近い動作が再生するもの（歩きなら走り、走りなら歩き、次に待機。射撃なら照準、次に
  待機。どの死亡も普通の死亡）です。ビルドも同じ規則を使うので、ページが示すものがゲームで再生されます。
- 名前が t_ または b_ で始まるアニメーション（hr_t_fire、hr_b_run）は、体の上半分または下半分だけで再生されます：騎手の
  ものは上、馬のものは下です。
- **その他の動作**の下に、残りが種類別に並びます：その場で、移動、照準と射撃、重火器、被弾、死亡。
- **長距離の移動**では、ゲームは分隊をトラックに乗せます。独自のアニメーションを持つユニットは、代わりにそこで選んだアニメー
  ション（「最も近いもの」のままなら走り）を再生しながら、トラックと同じ速さで自分で移動します。トラックのままにするには
  **自分のトラックで**を選びます。

**コピーはアニメーションを引き継ぎます：**独自のアニメーションを持つユニットからコピーしたユニットは、同じアニメーション
を再生します。そのユニットだけ変えるには、**サウンドとアニメーション** の行の **RUSE Decoyで変更** を押し、**このユニットだけ** を選んでください。

この方法で Studio で作った Horse Squad はゲームで動きました（2026年11月）。
## 独自のボーンとアニメーションを持つモデル

馬、騎手を乗せた馬、どんな生き物でも：独自のボーンを持つモデルを、そのアニメーションごと分隊に載せられます。

1. **Blenderで作ります**：独自のボーン（名前は自由）を持つアーマチュアにモデルを載せ、アニメーションごとにアクションを作ります。アクションには内容どおりの名前を付けます：少なくとも **stand**（または **idle**）、**walk**、**run**。**death**、**fire**、**reload**、**hit**、**crouch**、**aim**、**look**、**flee**、**grenade** も認識されます。
2. **書き出します**：**File > Export > glTF 2.0**、形式は **glTF Binary (.glb)**、**Animation** にチェック。
3. **分隊を作ります**（上の手順2と同じ）。そのページの **見た目と動き** の **モデル** の行で **モデルを読み込む…** を押し、.glb を選びます。Studioはボーンが兵士のものではないことを見て、独自のボーンとすべてのアニメーションごと読み込みます。ページには、ボーンの数、各アニメーションとその長さ、そして分隊のいくつの動作で再生されるかが表示されます。
4. **ゲームでテスト** で確認できます。

知っておくと便利：
- 分隊の各動作は、その名前のアニメーションを再生します。名前の合うアニメーションがない動作には、まだアニメーションがありません。ページにその数が出ます。
- Blenderで変更した場合は、もう一度読み込んでください。同じ名前のアニメーションがファイルにある限り、各動作はそのアニメーションのままです。
- モデルとすべてのアニメーションはmodに保存されます：`files\models\<ユニット名>.glb`、各アニメーションは `files\anim\own\<ユニット名>\<アニメーション名>.baf`。
- **コピー元のモデルを使う** で、モデルをアニメーションごと外せます。
- 重火器兵のいる分隊：**分隊の兵士** で、小銃兵のモデルと同じボーンで作った専用の馬と騎手を与えると、小銃兵のアニメーションを使います。別のボーンだと、コピー元の分隊でのアニメーションを使い、ページが警告します：ゲームが止まることがあります。小銃兵のモデルを外すと、重火器兵のモデルも一緒に外れます。
- この方法で Studio で作った Horse Squad はゲームで動きました（2026年11月）。この方法で作ったほかのものは、まだゲームで試されていません。

## 4. カードを作って、テストする

新しいモデルが点線の枠の中でちょうどよく見えるまで 3D ビューを回し、**この視点をカードにする** をクリックします（[[ユニットの編集|ユニットの編集]] を参照）。次に **ゲームでテスト**: ユニットはバトルで、その工場にあります。

## Blender で変更する

`files/models/<the unit's name>.glb` は、ほかの .glb と同じように Blender で開けます。2つのオブジェクト名（車体の `chassis`、砲塔の `tourelle_01`）はそのままにして、同じファイルに上書きでエクスポートしてください（glTF Binary）: 次のビルドでそれが使われます。

ユニットのページの **Blenderで開く** は、各部品のボーンにゲームと同じ名前を付けます。そのため、ゲーム自身の戦車を Blender で開いて取り込み直しても、砲塔は回ったままです（Studio 0.9.8.8。それより前に書き出したモデルは古い名前のままなので、Blender でもう一度開いてください）。

**間違った場所に付いていたモデル**（Studio 0.9.8.7 以前で、Panther と、Studio が砲塔を読み違えていたほかの85のユニットから作った新しいユニット）: そのユニットで **モデルを読み込む…** をもう一度使うと、砲塔の上に付きます。

## まだ初期段階

- 履帯と車輪はまだ回りません: 車体と一緒に動きます。
- 砲の発射炎と残骸は、コピー元のユニットのものです。
- 画像は、ゲーム自身のユニットの画像と同じく、幅が最大1024にされます。
- ゲーム自身のモデル（Sherman、航空機2機、小銃分隊、砲の操作員）を使って、ゲーム内で試しました: ほかの場所から持ってきたモデル、ほかの砲塔付き戦車、360度回る砲塔、プロペラのないユニットをコピーした航空機では、まだ試していません。

コマンドラインから: `ruse import-model "Tank Abrams.3ds" --like coc_shermanm4_tir --unit
Descriptor_Unit_R2_M1_Abrams --size 1.36 --mod <your mod folder>`。`--move` を付けると、Studio と同じ方法で合わせます: `--move 50 0 -10` は合わせた位置から前へ 50、下へ 10 動かし（前、右、上の順）、`--move 0 0 0` はその位置のままにします。`--move` を付けなければ、コマンドは今までどおり、砲塔をコピー元のユニットの砲塔に合わせる古い方法で合わせます。
