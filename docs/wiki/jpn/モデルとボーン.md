# モデルとボーン

> **必要なもの:** RUSE Studio 0.9.8.20 以降、新しいユニットの入った MOD、ボーンを変えるなら Blender（無料） ·
> **所要時間:** 読むのに 10 分

R.U.S.E. の兵士や馬、あらゆる生き物が動くのは、その 3D モデルに **ボーン**（骨）があるからです。このページでは、ボーン
とは何か、ゲームがどう使うか、ユニットのページにあるボーンの欄がそれぞれ何を意味し、どうすればよいかを説明します。戦車は
砲塔と車輪をアニメーションなしで回すので、このページは主に兵士、馬、生き物の話です。

## ボーンとは

- **モデル** は点でできた殻で、その上に画像が塗られています。
- その中には骨格のように **ボーン** があります：上腕、前腕、手、頭、馬の脚のそれぞれ。各ボーンは別のボーンにぶら下がり
  （手は前腕に、前腕は上腕に）、最初のボーンまでつながっています。
- 殻の各点は 1 本または数本のボーンに付いて動きます：袖の点は腕に付いて動きます。点が各ボーンにどれだけ付いて動くかが、
  その点の **ウェイト** です。
- **アニメーション** はボーンをフレームごとに動かし、殻がそれに付いて動きます。こうして兵士は歩き、狙い、倒れます。
- Blender では、モデルのボーンは **armature** という 1 つのオブジェクトです。

## ゲームでの使われ方

- ゲームはモデルのボーンを、名前ではなく **ボーンのリストでの順番** で動かします。そのため、あるモデル用に作ったアニメー
  ションは、同じボーンが同じ順番で並んだモデルにしか合いません。
- 役目を持つボーンもあります：射撃は武器の銃口のボーンから出て、上半身は背骨のボーンで目標の方へ向き、武器はボーンの上で
  表示・非表示になり、砲塔や車輪はボーンの上で回ります。あなたのモデルに足りないものは、ユニットのページが 1 つずつ名前を
  挙げます（下の **ゲームで動きますか？** を参照）。
- 兵士は **2 つのアニメーションを同時に** 再生します：体の上半分（狙う、撃つ）に 1 つ、下半分（歩く、走る）に 1 つ。
  馬と騎手も同じです：下の **上半身と下半身** を参照。
- ボーンが 64 本を超えるモデルをゲームが動かすのは確認されていません。

## 2 種類のモデル

| | ゲームの兵士のボーンに乗ったもの | 独自のボーンを持つもの |
|---|---|---|
| **どんなものか** | Blender で変えた兵士、または兵士のボーンに付けた自分のモデル | 馬、騎手を乗せた馬、あらゆる生き物。Blender で自分のボーンに作ったもの |
| **作り方** | 分隊カードの **Blenderで開く**：兵士それぞれがボーンごと開きます（[[Blenderで開く|Blenderで開く]] を参照） | Blender で作り、**兵士ごと** の下の兵士の行にある **モデルを読み込む…**（[[モデルの取り込み|モデルの取り込み]] を参照） |
| **アニメーション** | ゲームのもの（兵士と同じ） | 自分のもの（ファイルから） |
| **上半身と下半身** | ゲームのまま：選ぶものはありません | あなたが選びます（Studio がボーンを提案） |
| **大きさと位置** | Blender で作ったとおり、兵士のボーンの上 | ファイルのとおり |

どちらなのかはページに出ます。ゲームの兵士のボーンに乗ったモデルなら「このモデルはゲームの兵士の骨に乗っているので、
ゲームの上半身と下半身をそのまま使います。選ぶものはありません。」、独自のボーンを持つモデルなら「独自のボーンが
あります：」とその本数です。**汎用騎馬分隊**（**ユニット** タブ、**第二次大戦+**）は独自のボーンを持つ分隊です：
[[他の時代のユニット|他の時代のユニット]] を参照。

## ページのどこに出るか

新しいユニットのページでは、ボーンに関するものはすべて **見た目と動き** にあります：

| 欄 | 場所 | わかること |
|---|---|---|
| **ボーンとアニメーション** | **サウンドとアニメーション** 行の **もっと見る** | モデルのボーンの本数と、各アニメーションの長さ、それを再生するユニットの動作の数（独自のボーンを持つモデル） |
| **上半身と下半身** | **サウンドとアニメーション** 行の **もっと見る** | モデルが上半身と下半身に分かれる場所 |
| **このユニットのアニメーション** | **サウンドとアニメーション** 行の **もっと見る** | ユニットが動作ごとに再生するアニメーション：[[ユニットのアニメーション|ユニットのアニメーション]] を参照 |
| **ゲームで動きますか？** | **モデル** 行の **もっと見る**。分隊のページでは兵士の下の **その他のオプション**、そこから **各兵士のモデル** | モデルのどこがゲームを止めたり見た目をおかしくしたりするか、その直し方 |
| ボーンのない点 | **ゲームで動きますか？** と同じ場所 | どのボーンにも付いていない点の数 |

## 上半身と下半身

ゲームは兵士に 2 つのアニメーションを同時に再生します：**上半身**（狙う、撃つ）に 1 つ、**下半身**（歩く、走る）に
1 つ。騎手は馬が走っている間に狙って撃ちます：騎手が上半身、馬が下半身です。

- ゲームの兵士のボーンに乗ったモデルは、ゲームの上半身と下半身をそのまま使います：ページには「選ぶものはありません」と
  出ます。
- 独自のボーンを持つモデルは **1 本のボーン** で分かれます：そのボーンとその下のすべてのボーンが上半身、それ以外が
  下半身です。

選び方：

1. ユニットのページの **見た目と動き** で、**サウンドとアニメーション** 行の **もっと見る** を押します。
2. **上半身と下半身** の下の **上半身の始まり** のリストに、まず Studio のおすすめが「（おすすめ）」付きで出ます。
   Studio は、騎手を乗せた馬なら騎手の最初のボーン（汎用騎馬分隊なら **bip01**）、なければ spine という名前の最初の
   ボーン（兵士の場合）、それもなければ骨格が最初に枝分かれするボーンをすすめます。
3. ほとんどのモデルはおすすめのままで大丈夫です。変えるには、リストで別のボーンを選びます。すぐに保存され、次のビルド
   （**ゲームでテスト**）からゲームに反映されます。
4. リストの下には各半分のボーンの数が表示され、**どの骨がどちらか** にはモデルのすべてのボーンが、上半身・下半身の印
   付きで並びます。
5. おすすめに戻すには、リストの最初の行をもう一度選びます。

おすすめ以外の分け方は、まだゲームで試していません。

## ウェイト：各点がどのボーンに付いて動くか

自分のモデル（またはヘルメット、背嚢、武器）を兵士のボーンに付けるとき、Blender は各点がどのボーンに付いて動くかを
知る必要があります。以下は Blender 自体の操作です。

**自分のモデルを兵士に付け、各点を近くのボーンに付けて動かす：**

1. 分隊カードの **Blenderで開く** を押します：兵士がそれぞれのボーンに乗った状態で Blender が開きます。
2. Blender で **File > Import** から自分のモデルを読み込み、兵士に重ねて置きます。
3. 自分のモデルをクリックしてから、**Shift+クリック** で兵士のボーンを選びます：ボーンを最後に。
4. **Ctrl+P** を押して **With Automatic Weights** を選びます。Blender がウェイトを計算します。
5. 残さないもの（自分のモデルで置き換えるならゲームの兵士の形）を消しますが、ボーンは残します。
6. Blender の 3D ビュー上部の **R.U.S.E. Studioへ送る** を押し、Studio で **変更を戻す** を押します。

**1 本のボーンにだけ付いて動く硬い部品（頭のヘルメット）：**

1. Blender でヘルメットをクリックしてから、**Shift+クリック** で兵士のボーンを選びます。
2. **Ctrl+Tab** で Pose Mode に入り、頭のボーンをクリックします。
3. **Ctrl+P** を押して **Bone** を選びます。ヘルメットは頭と一緒に動くようになり、変更を戻したときにその兵士だけが
   受け取ります。

**ボーンのない点。** Blender の自動ウェイトは、ときどきいくつかの点を取りこぼします。そのときページには「モデルの
{n}個の点に骨がないため、兵士の腰と一緒にしか動きません。」と出ます。直し方：

1. もう一度 **Blenderで開く**。
2. 自分のモデルをクリックし、Blender のモード（3D ビューの左上）を **Object Mode** から **Weight Paint** に切り替え
   ます。
3. モデルのプロパティ（緑の三角形）の **Vertex Groups** にはボーンごとのグループがあります：その点を付けたいボーンを
   選びます。
4. 点の上を塗ります。
5. **R.U.S.E. Studioへ送る**、続いて **変更を戻す**。

## ゲームで動きますか？

Studio は、ボーンに乗ったモデルを、それが再生するアニメーションと、コピー元のユニットの部品や射撃に照らして確認します。
MOD のビルドでも、すべての変更を含めてもう一度確認します。問題があっても作業が止められることはありません：何が起きるかと
直し方を教えてくれます。

**場所：** 新しいユニットのページの **見た目と動き**、**モデル** 行の **もっと見る**。分隊のページでは、兵士の下の
**その他のオプション** から **各兵士のモデル**。

問題がなければ「ゲームを止めるものは見つかりませんでした。」で始まる文が出て、アニメーションがモデルのボーンをすべて
持ち、部品と射撃に必要なボーンもそろっていることを伝えます。

### 各答えの意味

問題はそれぞれ 3 つのことを伝えます：何が合わないか、ゲームがそれをどう扱うか、どう直すか。真ん中の行は次のどれかです：

| ページの表示 | 意味 | すること |
|---|---|---|
| これでゲームが止まることがあります。テストで止まりました。 | 私たちのテストでこのとおりゲームが止まりました。 | テストの前に直します。 |
| これでゲームが止まることがあります（ゲームではまだ試していません）。 | ゲームが止まると考えられます。 | テストの前に直します。 |
| ゲームは再生しますが、見た目がおかしくなります（ゲームではまだ試していません）。 | 違うボーンが動きます。 | 直すか、テストして見てみます。 |
| ユニットは戦いますが、射撃が見えません。テストでそうなりました。 | ダメージは与えますが、射撃が見えません。 | ページが挙げるボーンを足します。 |
| ゲームではまだ試していません。ゲームが動かさないかもしれません。 | ゲームが動かすのを確認できた本数より多いボーン。 | ボーンをまとめるか消します。 |
| 動作はしますが、望んだ形ではないかもしれません。 | 上半身と下半身についての注意。 | **上半身と下半身** を確認します。 |

### 問題ごとの直し方

**モデルのボーンに合わないアニメーション。** ページは、いくつのアニメーションが、いくつの動作で、なぜ合わないかを伝えます：
「動かす骨は {a} 本で、モデルの骨は {b} 本です。」（または「{b} 本しかありません」）、数は同じでも「名前が違い」、
または「順番が違い」。これらのアニメーションは別のボーン用に作られています。

- ユニットがあなたのモデルでゲームのアニメーションを再生している場合：それらの動作にモデル独自のアニメーションを与えます。
  **モデルを読み込む…** はモデルのファイルにあるアニメーションをすべて取り込み、各動作が再生するものは **このユニットの
  アニメーション** で選べます（[[ユニットのアニメーション|ユニットのアニメーション]]）。
- 別のモデル用に作ったモデル自身のアニメーションの場合：Blender でこのモデルのボーンに作り直し、モデルをもう一度読み込み
  ます。

**ユニットに必要なボーン。** たとえば「小銃兵：射撃は Fx_Tir_01 という骨から出ますが、モデルにはその骨がありません。」
（ほかに、上半身がそこで目標へ向く、武器がそこで表示・非表示になる、部品がそこに持たれる、砲塔や車輪がそこで回る、
胴体がそこに乗る、牽引砲がそこにつながる）。Blender でボーンを足すには：

1. Blender でモデルを開きます：**骨** にチェックを入れて **Blenderで開く**（[[Blenderで開く|Blenderで開く]] を参照）、
   または自分の Blender ファイル。
2. ボーン（armature）をクリックし、**Tab** で Edit Mode に入ります。
3. **Shift+A** を押します：Blender の 3D カーソルの位置に新しいボーンができます。
4. **F2** を押し、ページが挙げる名前を正確に入力します（例：`Fx_Tir_01`）。モデルに別の名前で同じボーンがあるなら、
   そちらの名前を変えます。
5. ボーンのプロパティ（ボーンのアイコン）の **Relations** で、**Parent** に部品と一緒に動くボーンを設定します：射撃なら
   武器と一緒に動くボーン。
6. **G** を押して、新しいボーンを部品があるべき場所へ動かします：射撃なら武器の銃身の先。
7. もう一度 **Tab** を押し、**R.U.S.E. Studioへ送る**、続いて **変更を戻す** を押します（または自分のファイルを
   書き出して **別のモデルを読み込む…** を押します）。**ゲームで動きますか？** がモデルをもう一度確認します。

**ボーンが多すぎる。** 「モデルの骨は {n} 本です。骨が 64 本を超えるモデルをゲームが動かすのは確認されていません。」
Blender でボーンをまとめるか消して 64 本以下にし、モデルを戻します。

**分け目。** 「モデルの最初の骨 {bone} で分けると、すべての骨が上半身になり、下半身のアニメーション（歩く、走る）は
何も動かしません。」：**上半身と下半身** で、上半身が始まるもっと下のボーンを選びます。「分け目に選んだ骨 {bone} が
モデルにもうないため、{used} で分けています。」：ボーンを選び直します。

**分隊の 2 つ目のモデルが別のボーンの場合。** 「この兵士のモデルは小銃兵のモデルとは違う独自の骨を持っているため」で
始まる警告が出ます。重火器兵のモデルが小銃兵のアニメーションを再生するには、小銃兵のモデルと同じボーンに乗っている必要が
あります：Blender で小銃兵のモデルから作り、彼の行で読み込みます。小銃兵のモデルを外すと、彼のモデルも一緒に外れます。

## Blender で独自のボーンを持つモデルを作る

1. **ボーン：** 自分のボーン（名前は自由）を持つ armature にモデルを乗せ、ウェイトを付けます（上の **Ctrl+P > With
   Automatic Weights**）。
2. **アニメーション：** アニメーションごとに action を 1 つ（Blender の **Dope Sheet > Action Editor**）。それぞれ
   内容どおりに名前を付けます：最低でも **stand**（または **idle**）、**walk**、**run**（または **gallop**）。
   **fire**、**aim**、**reload**、**hit**、**death**、**crouch**、**look**、**flee**、**grenade** も認識されます。
   **t_fire**（または **hr_t_fire**）のような名前は上半身だけ、**b_run**（または **hr_b_run**）は下半身だけで再生
   されます：騎手と馬のものです。
3. **書き出し：** **File > Export > glTF 2.0**、形式は **glTF Binary (.glb)**、**Animation** にチェック。
4. 新しい分隊に **読み込みます**：[[モデルの取り込み|モデルの取り込み]] を参照。
5. **ページを確認します：** **ボーンとアニメーション**（すべてのアニメーションが届き、それぞれいくつの動作が再生するか）、
   **上半身と下半身**、**このユニットのアニメーション**、**ゲームで動きますか？**
6. **ゲームでテスト**。

あとで Blender で変えたら、もう一度読み込みます：同じ名前のアニメーションがファイルにある限り、各動作は自分の
アニメーションを保ちます。

## ゲームで試したこと

- この方法で作った汎用騎馬分隊（小銃兵とバズーカ兵が馬に乗った、独自のボーンを持つモデル）：射撃し、長距離の移動では
  自分の姿のまま進み、馬は騎手と一緒に倒れます（2026 年 11 月）。
- ゲームの兵士のボーンの上で Blender で変え、点にウェイトを付けた分隊の兵士（2026 年 11 月）。
- まだゲームで試していないもの：おすすめ以外の分け方と、ページが「ゲームではまだ試していません」と示す各問題。
