# マップ名

プレイヤーはマップをタイトルで覚えていますが、ゲームのファイルとMODのフォルダーでは **パック名** を使います。MODによるマップの変更は `maps/<pack name>/` に入ります。たとえば電撃戦（Blitz）なら `maps/SuperCrossRoads4/` で、`maps/Blitz/` ではありません。

Studio のマップリストには両方が表示されます。先にタイトル、点のあとにパック名です。1つのパックに複数のマップが入っていることもよくあります（バトルのマップと、同じ地形でプレイするオペレーション、または複数のキャンペーンの章）。
