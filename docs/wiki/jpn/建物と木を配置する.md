# 建物と木を配置する

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.7.2 とMOD（グリッド、範囲、経路、選択、やり直す: 0.9.8.7。自分のモデル:
> 0.9.8.8） · **ゲームで確認済み:** 配置した建物はどのズームでも表示され、元の大きさの8倍まで置け、ユニットはその周りを
> 回り込む。まだゲームでは試していないもの: グリッド、範囲、経路で配置したもの、動かした物体

## 配置する

1. バーで **建物** をクリックするか、**小物・樹木** をクリックしてその **小物** または **樹木** タブを選びます。
2. 画像から種類を選びます（検索ボックスに入力すると絞り込めます）。それぞれの画像はゲーム自身のモデルから描かれ、隅の数字はそのマップにすでにある数です。リストには、このマップ自身の種類が並びます。ゲームは、マップがすでに使っている種類しか受け付けないためです。
3. クリックでどう配置するかを選びます。
   - **1つ**: クリックした場所に1つ
   - **範囲**: ドラッグして、円の中に物体を散らす（**間隔** で物体どうしを離し、**範囲** で円を決める）
   - **列**: 始点、次に終点をクリックして1列に並べる（生け垣、通り、並木）。向きは列に沿う
   - **グリッド**: 物体を何列も並べる。最初の列の始点と終点をクリックし、外へ列を広げてクリックする（**列の間隔** で列どうしの間を決める）
   - **範囲**（四角形）: 地面の上で四角形をドラッグして離すと、その中が選んだ物体の列で埋まる
   - **経路**: 道に沿ってクリックしていき、ダブルクリックするか、**Enter** を押すか、**完了** を押す。物体はクリックした点を通るなめらかな曲線に沿って並ぶ（生け垣、並木）。幅を付けると、帯状に並ぶ。**Esc** で、作りかけのグリッド、列、経路を取りやめる
4. **道路に向ける:** 道路の近くでは、物体は道路の脇に置かれて道路の方を向き、列は道路に沿います。グリッドや四角形は道路をふさぎません。向きのスライダーでさらに回せます（家が裏側を見せていたら 180° を試してください）。
5. **向き** と **サイズ**（最大10倍）は右側のスライダーです。木は大きさと向きが自動で少しずつ変わるので、林がスタンプで押したようには見えません。

クリックする前に、その種類がポインターの下に半透明で、置かれるときの向きと大きさで表示されます。配置した物体はそれぞれのモデルで表示され、足もとに小さな金色の点が付くので、遠くからでも見分けられます。

## 選択、移動、回転、削除

**選択**（**建物** と **小物・樹木** のトレイにあります）で、マップに立っているものを選びます。MODが配置したものでも、マップ自身のものでもかまいません: 1つをクリックし、**Shift+クリック** で追加し、または複数をドラッグで四角く囲みます。そのあと、選んだものの1つをドラッグすると全部が動きます。**向き** と **サイズ** を使ったり、**削除** したりもできます。**マップ通りに戻す** で、マップ自身のものへの変更を元に戻します。**Esc** で何も選んでいない状態に戻ります。

## 自分のモデル

**モデルを読み込む…**（**小物・樹木** にあります）で、3D モデル（.glb、.gltf または .3ds）を、マップMOD独自の岩、小物、茂み、木にします。ゲーム自身のものと同じように、MODのどのマップにも配置でき、中距離と遠距離用の軽い版もそのために作られます。**サイズ** と **入手元** を付けてください: 他の人が作ったモデルは、CC0 か CC-BY のものだけを、作者の名前と一緒にMODに入れられます。**障害物：ユニットが迂回する** にチェックを入れると、ユニットはそれを避けて通ります。チェックしないと、ゲーム自身の小さな小物と同じように、ユニットはその中を走り抜けて倒します。あとから **自分のモデル…** で変更できます。ゲームで確認済み。

## 通れない建物

**通行不可**（デフォルトでオン）にすると、ユニットは配置した建物を通り抜けず、その周りを回ります。見るためだけの建物ならオフにしてください。

## 建物に隠れる

配置した建物は、それだけではユニットを隠しません。**遮蔽** を開き、**町** を選んで、作った町をクリックしてください。

## 元に戻すとやり直し

**元に戻す**（または **Ctrl+Z**）で、最後の物体、または範囲、列、グリッド、四角形、経路の全体と、最後の移動、回転、サイズ変更、削除を取り消します。**やり直す**（または **Ctrl+Y**、**Ctrl+Shift+Z**）で、それを元どおりにします。どのマップツールにも、この両方があります。

## マップ自身の木と小物を消す

1. バーで **撤去** をクリックします（Studio 0.8.1）。
2. 何を取り除くかを選びます: **樹木**、**小物**、**建物**（組み合わせは自由）。各円は、塗ったときに選んでいたものを覚えています。
3. マップの上をドラッグします。赤い円が取り除かれるものを示し、円が覆う部分は赤みがかります。**サイズ** で円の大きさを決めます。トレイには、MODをビルドしたときに円が取り除く数が表示されます。

木がなくなった場所では、地面がすべてのユニットに開かれ、森の遮蔽がなくなります（ゲームで確認済み: 切り開いた林に戦車が入れ、そこにいる歩兵は隠れない）。撤去した建物も、その地面がユニットに開かれます。**元に戻す**（**Ctrl+Z**）で最後のドラッグを取り消し、**やり直す** でマップ上のすべての円を消します。
