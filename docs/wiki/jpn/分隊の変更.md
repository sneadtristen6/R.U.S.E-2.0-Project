# 分隊の変更

> **対象:** モッダー · **必要なもの:** RUSE Studio、MOD、兵士をBlenderで変えるならBlender（無料） · **所要時間:** 数分

アメリカのGIを海兵隊のような見た目にしたり、兵士1人だけに独自の見た目を与えたり、分隊の兵士を増やしたり減らしたりできます。分隊のページは兵士から始まります：上に分隊カード、その下に兵士ごとの行です。

## 1. 自分の分隊

**ユニット** タブで分隊（たとえば米軍小銃分隊）を選びます。カードには分隊の構成が表示されます：「兵士5人：小銃兵4人（小銃）、バズーカ兵1人（バズーカ）」。ゲーム本来の分隊は変えられないので、カードの **このユニットから新しいユニット…** を押し、分隊に名前を付けて **作成** を押します。新しい分隊のページがカードから開きます。

## 2. 分隊全体をBlenderで

1. カードの **Blenderで開く** を押します。分隊の兵士全員が横に並んでBlenderに開きます。Blenderがない場合は **Blenderを入手（無料）** でインストールし、すでにある場合は **Blenderを選択…** で場所をStudioに教えます。
   一部だけの場合は、ボタンの横の **Blenderに送るもの** を押し、そのままにしたいもののチェックを外します。**変更を戻す** はそれを元のままにします。最初はすべてにチェックが入っています。
2. どの兵士でも変えられます：形、色、装備。兵士はそれぞれ自分の画像のコピーを持っているので、1人を塗っても変わるのはその兵士だけです。
3. 自分のヘルメットや背嚢、バズーカを1人の兵士に付けるには：**File > Import** で読み込み、兵士に付け、それをクリックしてから **Shift+クリック** で兵士の骨を選び、**Ctrl+P > With Automatic Weights** を押します。
4. Blender上部の **R.U.S.E. Studioへ送る** を押します。
5. Studioに戻ると、大きなボタンが **変更を戻す** になっています：押してください。兵士はそれぞれ自分に加えられた変更だけを受け取り、だれが変わり、だれが変わらなかったかがカードに表示されます。
6. **ゲームでテスト** を押して確認します。

Blenderでは兵士がそれぞれ別の人形です。ライフル兵を1人塗っても、変わるのはその兵士だけです。

## 3. 兵士1人

**兵士ごと** の下に、兵士ごとの行があります：その兵士の絵、番号と兵種（「兵士3：ライフル兵」）、使う武器。

- **モデルを読み込む…** で、ゲームの兵士の骨の上でBlenderで作ったファイル、または独自の骨を持つモデル（馬と騎手）を、その兵士に付けます。ほかの兵士はそのままです。
- **ゲームの見た目に戻す** で、その兵士だけをゲームの見た目に戻します。ほかの兵士の見た目はそのままです。
- **外す** で、確認したうえでその兵士を分隊から外します。後ろの兵士は1つずつ繰り上がり、彼専用の見た目はBlenderのファイルと一緒に保存されます。

## 4. 兵士を増やす・減らす

カードの大きなボタンの下にあります：

- **兵士 +1** で、Blenderを使わずにすぐライフル兵を1人増やします。バズーカ兵の前に入り、ほとんどのライフル兵と同じ見た目になります。
- **兵士 −1** で、最後のライフル兵をすぐに外します。バズーカ兵は最後のままです。
- **兵士を追加** では、加わる兵士を選べます：**この分隊の兵士のコピー**、**ほかのユニットの兵士**、**モデルファイル…**。Blenderがその兵士だけで開くので、変えても変えなくても **R.U.S.E. Studioへ送る** を押し、Studioで **変更を戻す** を押すと、バズーカ兵の前に加わります。

今のところ分隊の兵士は2人から8人までで、最後の兵士たちが持つバズーカ、火炎放射器、爆薬の数だけ兵士が残ります。これらのボタンがあるのは自分で作った分隊だけで、ゲーム本来の分隊の兵士は変わりません。

## 知っておくと便利なこと

- 兵士の下の **その他のオプション** に、各兵士のモデルとBlenderのファイルの保存場所が表示されます。**フォルダーで表示** でフォルダーを開けます。
- 変更を戻す前にBlenderを閉じてしまったら、大きなボタンの下の小さな **変更を戻す** で、最後に送ったものを取り込めます。
- 分隊の軍服は、値の横の **見た目と動き** にあります：**カスタム軍服** で分隊専用の軍服を付け、**Blenderで塗り替える** で全員の軍服をまとめて塗れます。分隊が使えるのは、あなたのモデルか軍服のどちらかです。
- ゲームではまだ試していません：8人や2人の分隊。

モデル、骨、アニメーションについて詳しくは：[[モデルの取り込み|モデルの取り込み]]。
