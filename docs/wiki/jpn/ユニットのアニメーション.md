# ユニットのアニメーション

> **必要なもの:** RUSE Studio 0.9.8.20 以降と MOD。新しいユニットのアニメーションを Blender で変えるなら Blender（無料） ·
> **所要時間:** 読むのに 10 分

ユニットの動き方（立つ、歩く、走る、狙う、撃つ、死ぬ）が、そのユニットの **アニメーション** です。このページでは、
ゲームのアニメーションが何のためにあるか、ユニットが動作ごとにどれを再生するか、アニメーションを変えるすべての方法
（1 ユニットだけ、全ユニット、選んだユニット、Blender）と、ゲームのものに戻す方法を説明します。

## アニメーションとは

- アニメーションは、モデルのボーンを時間に沿って動かします：走る 1 歩、肩に構えた小銃、倒れる動き
  （[[モデルとボーン|モデルとボーン]] を参照）。
- ユニットがゲームでする一つ一つのこと（**動作**：じっと立つ、歩く、走る、撃つ…）が、1 つのアニメーションを再生します。
  兵士は体の半分ごとに 1 つずつ、2 つを同時に再生します。
- 多くのユニットがゲームのアニメーションを共有しています：米軍の小銃兵はみな同じ走り方です。そのため、ほかを選ばない限り、
  アニメーションへの変更は、それを使うすべてのユニットへの変更になります。
- 戦車は砲塔と車輪をアニメーションなしで回すので、ここで変えるものはありません。

## ゲームのアニメーションとその役目

**RUSE Decoy**（Studio 上部のタブ）は、ゲームのすべてのアニメーションを左側の **アニメーション** の下に種類別に並べ
ます：

| 種類 | 中身 |
|---|---|
| **歩兵** | 小銃兵・バズーカ・空挺・運転手：立つ、歩く、走る、狙う、撃つ、装填、逃走、被弾、死亡（上半身と下半身で別々） |
| **砲兵** | 大砲の周りの兵士：待機、移動、展開、射撃、装填 |
| **車両と大砲** | 大砲の展開・撤収、待機・射撃などの可動部 |
| **司令部の人物** | ミッションの場面で司令部の机に立つ将校（ユニットでは使われません） |
| **動物と風景** | マップ上の牛・馬・ヤギ・鶏・カモメ・風車 |

それぞれ、ゲームでの呼び名と、使っているユニットの数が表示されます。ユニットのページでは、動作はユニットがすることの
名前で、次のようにまとめられています：

| グループ | 主な動作 |
|---|---|
| その場で | じっと立つ、しゃがむ、周りを見回す |
| 移動 | 歩く、後ろ向きに歩く、走る、右へ走る、後ろ向きに走る、逃げる |
| 照準と射撃 | 立って狙う、歩きながら狙う、撃つ、手榴弾を投げる、装填する |
| 重火器 | 重火器で狙う、重火器を撃つ、重火器を構える、重火器を下ろす |
| 被弾 | 被弾する、背後から被弾する、爆発で被弾する |
| 死亡 | 撃たれて死ぬ、爆発で死ぬ、倒れている |
| パラシュート降下 | 飛び降りる、落ちる、パラシュートで降りる、着地する |
| 乗員の動作 | 待機する、砲と前へ歩く、砲へ向かう、砲を据える、撃つ（乗員）、砲に装填する |

## このユニットのアニメーション：動作ごとにどれを再生するか

独自のアニメーションを持つユニット（独自のボーンを持つモデル：馬、騎手を乗せた馬、あらゆる生き物）のページには表があり
ます：**見た目と動き** の **サウンドとアニメーション** 行の **もっと見る**、その中の **このユニットのアニメーション**。

- **じっと立つ**、**歩く**、**走る** が最初に来ます：モデルに最低限必要なものです。どれかに専用のものがなければ、ページが
  そう伝え、代わりに何を再生するかを示します。
- 各動作には、モデルのアニメーションのリストがあります。1 つ選ぶか、最初の行 **最も近いもの** のままにします：その場合、
  モデルが持つ最も近いものを再生し、行にどれかが表示されます。最も近いものとは、順に：その動作の名前を付けたアニメー
  ション（stand または idle、walk、run または gallop、fire、death…）、なければ最も近い動作が再生するもの（歩くなら走る、
  撃つなら狙うか立つ）です。ゲームはページの表示どおりに再生します：ビルドも同じ規則を使います。
- **その他の動作** には残りがグループごとに並びます。
- **長距離の移動** が最後の行です。道路での長距離の移動では、ゲームは分隊をトラックに乗せます。独自のアニメーションを持つ
  ユニットは、代わりに自分の姿のまま、そのうちの 1 つをくり返し再生して進めます（最初の行のままなら走る動き）。速さは
  トラックと同じです。トラックのままにするなら **自分のトラックで** を選びます。

独自のアニメーションを持つユニットからコピーしたユニットは、同じものを再生します。

## RUSE Decoy でアニメーションを変える

1. ユニットのページの **見た目と動き** で、**サウンドとアニメーション** 行の **RUSE Decoyで変更** を押します。RUSE
   Decoy がそのユニットで開きます：サウンド、続いて再生するすべてのアニメーションが並ぶ **アニメーション**。（または
   **RUSE Decoy** タブを開き、**アニメーション** の下で種類を選びます。）
2. アニメーションの **見る・変更…** を押します。それを使うユニットの上で 3D 再生されます：ドラッグで回転、ホイールで
   拡大。3D 表示には一度だけインターネットが必要です。
3. ユニットのページから開いた場合、最初の行は **変更の対象** です：
   - **このユニットだけ**：このユニットが、変更を加えた自分専用のコピーを再生します。ほかのユニットはこれまでどおりです。
     アニメーションがまだ全ユニット向けに変えられていなければ、これが最初に選ばれています。
   - **これを使う全ユニット**：変更はアニメーションそのものに入り、それを使うすべてのユニットに及びます（数字はその数）。
   - **あなたのコピー** とその名前：このユニットがあなたのコピーを再生しているときに表示され（下記）、そのときは最初に
     選ばれています。
4. 変えます：
   - **速度**：100% がゲームの速さ、200% は 2 倍、50% は半分。離したときに保存されます。
   - **代わりに使う動き**：同じ体の別のアニメーションを代わりに（小銃兵を逃げるときの走り方で走らせるなど）。
   - **ボーン** と **大きさ**、**回転軸**、**回転**：アニメーションの間ずっと、体の一部を大きくしたり回したりします。
   - **モーションキャプチャ**：本物の人の動きを代わりに（[[音楽とサウンド|音楽とサウンド]] を参照）。
5. **完了** を押します。変更はすぐに MOD に保存され、テストや書き出しでゲームに入ります。

## 選んだユニット用のアニメーションのコピー

**このアニメーションをコピー…** は、チェックを入れたユニットと兵士だけが再生するコピーを作ります：たとえば自分の分隊 3 つ
用の走り方と、4 つ目の分隊のバズーカ兵だけ用の走り方。

1. アニメーションのウィンドウで **このアニメーションをコピー…** を押し、コピーに名前を付けて（見えるのはあなただけ）、
   **コピーを作る** を押します。今のアニメーションの状態から始まり、同じウィンドウで開きます。
2. 上と同じように変えます。
3. **再生するユニット** で、コピーを再生するユニットにチェックを入れます：まず **あなたのユニット**、次に **ゲームの
   ユニット**。複数の兵士や部品が再生するユニットでは、その一部だけにチェックを入れることもできます。**ユニットを探す**
   は名前や国で探します。
4. ユニットにチェックを入れるまで、コピーはどこでも再生されません：それまで名前の下の行に「まだどのユニットも再生しま
   せん」と出ます。

コピーはすべて RUSE Decoy の左側の **あなたのコピー** にあります：そこで開くか、**コピーを削除**。ユニット専用のコピー
（**このユニットだけ**）や Blender で変えたアニメーションは、そのユニットではコピーより優先されます：リストの横に
そう表示されます。

## 新しいユニットのアニメーションを Blender で変える

MOD で作った新しいユニットの場合（ゲームのユニットは、先にそこから新しいユニットを作ります）：

1. ユニットのページで **RUSE Decoyで変更** を押します。アニメーションの上の **アニメーションをBlenderで変更** を押し
   ます。ユニットと、それが再生するすべてのアニメーションが Blender で開きます。各アニメーションは、その中でしている
   ことの名前と、その後ろにゲームでの名前が付いています。
2. Blender の下部の Action Editor に並ぶので、1 つ選びます。**スペース** で再生します。
3. ボーンをクリックし、**Ctrl+Tab** で Pose Mode に入り、**R** で回し（**G** で動かす）、**I** でそのフレームの
   ポーズを記録します。変えるフレームごとにくり返します：記録したポーズの間は Blender が自動でつなぎます。
4. Blender の 3D ビュー上部の **R.U.S.E. Studioへ送る** を押します：変えたかどうかに関係なく、すべてのアニメーションが
   送られます。
5. RUSE Decoy で **変更を戻す** を押します。変わって戻ったものが表示されます：それらはこのユニット専用になりました。
   ほかのユニットと、触らなかったアニメーションはそのままです。

ボーンにはポーズを付けるだけにしてください：名前を変えたり、消したり、Edit Mode で動かしたりしないでください。そう
すると Studio は何も取り込まず、どのボーンかを伝えます。

独自のボーンを持つモデル（馬、あらゆる生き物）は、自分のアニメーションを自分の名前のまま送ります。変えたものは元の場所に
入り、それを再生していた動作はすべて変えたものを再生します。

## ゲームのアニメーションに戻す

| 取り消すもの | 押すボタン | 場所 |
|---|---|---|
| 全ユニット向けの変更 | **ゲームの動きに戻す** | RUSE Decoy のアニメーションの行、またはそのウィンドウ |
| このユニット専用のコピー（**このユニットだけ**） | **全ユニット共通のものに戻す** | ユニットのリストのアニメーションの行、またはそのウィンドウ |
| コピーの変更（名前とチェックは残る） | **ゲームのアニメーションに戻す** | コピーのウィンドウ |
| コピーそのもの | **コピーを削除** | **あなたのコピー** |
| Blender でした変更 | その Blender が開いている間に Blender で元に戻し、**変更を戻す**：MOD でも元に戻ります | Blender、次に RUSE Decoy |

上のボタンでは、Blender でした変更は取り消せません。

## 「変更を戻す」が伝えること

| 表示 | すること |
|---|---|
| 「Blenderで変えたもので、今このユニット専用です：…」 | 何もしなくて大丈夫です。**ゲームでテスト** で確認できます。 |
| 「どのアニメーションも送り出したときのまま戻りました。」 | 何も変わっていません。ポーズを **I** で記録しましたか？ |
| 「Blenderで作ったもので、まだどの動作にも使われていません：…」 | 新しいアニメーションは取り込まれません。残すには Blender で保存します（**File > Save**）。 |
| 「送り返されなかった（Blenderで削除または名前変更された）ので、これまでどおり再生されます：…」 | 変更を入れたいなら、Blender で名前を元に戻します。 |
| 「これらは体の半分（上半身か下半身）だけで再生されます。…」 | 動かしたボーンがもう半分にあります：それを再生する側の半分のボーンを動かします。 |
| 「Blenderで作った骨で、このユニットの骨格にはないため…」 | 新しいボーンは再生できません。それ以外は届いています。 |
| 「BlenderのNLAエディターはこれらを独自のタイミングで再生しますが…」 | ゲームは Action Editor に見えるとおりに再生します。 |
| 「Blenderのシーンは毎秒…フレーム、ゲームは毎秒30フレームです。…」 | ゲームの速さで見るには、Blender を毎秒 30 フレームにします。 |
| 「BlenderのシーンでTime Stretchingがオンになっています…」 | ゲームの速さで見るには、Old と New を同じ数にします。 |
| 「このユニットのどの動作もこれらを再生しないため…」 | ユニットのページの **このユニットのアニメーション** で、動作に選びます。 |
| 「前回変更を戻してから、Blenderから新しいものは届いていません。」 | 先に Blender で **R.U.S.E. Studioへ送る** を押します。 |

## うまくいかないとき

- **ゲームで何も変わらない：** **このユニットだけ** の変更はそのユニットだけ、コピーはチェックを入れたユニットだけで
  見えます。Blender でした変更は、そのユニットでは、あとから **このユニットだけ** やコピーで同じアニメーションに加えた
  変更より優先されます（Studio の規則。ゲームではまだ試していません）。
- **「独自のアニメーションを持てるのは、このMODで作った新しいユニットだけです」**：ゲームのユニットです。先にそこから
  新しいユニットを作ります（そのページの **このユニットから新しいユニット…**）。
- **ページに「このユニットのアニメーション」がない：** この表は、独自のアニメーションを持つユニット（独自のボーンを持つ
  モデル）にしかありません。ほかのユニットはゲームのものを再生します：RUSE Decoy で変えてください。
- **戻さなかった送信：** Blender を開き直すと取っておかれます。RUSE Decoy は **取っておいた送信を戻す** と **ごみ箱に
  移す** を付けて表示します（[[Blenderで開く|Blenderで開く]] を参照）。

## ゲームで試したこと

- 使っているすべてのユニットに対する RUSE Decoy のアニメーション変更（Studio 0.9.8.8）。
- **このユニットだけ**：ほかの分隊がそのまま立っている間、その場で踊る分隊（2026 年 11 月）。
- **このアニメーションをコピー…**：1 つの分隊と、別の分隊の兵士 1 人が再生するコピー（2026 年 11 月）。
- **アニメーションをBlenderで変更**：片腕を上げて立ち、走る分隊と、頭を高く上げた馬の汎用騎馬分隊（2026 年 11 月）。
- **最も近いもの** で選ばれた汎用騎馬分隊自身のアニメーションと、長距離の移動を自分の姿で進むこと（2026 年 11 月）。
- まだゲームで試していないもの：1 ユニットだけに対する速度・代わりの動き・ボーンの変更と、**このユニットのアニメー
  ション** で手で選んだ別のアニメーション。
