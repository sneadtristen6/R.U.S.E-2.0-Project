# 国を別の国に作り変える

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.9.8.1 以降とMOD · **所要時間:** 数分

**国家** タブでは、ゲームの7つの国の1つに新しい名前と旗を付けて、別の国にできます。たとえば、イタリアの代わりに中国です。ゲームの国は7つのままです。変えた国は、ロビーでの位置、生産メニュー、キャンペーンの章とオペレーションをそのまま保ちます。

## 名前と旗

1. **国家** タブを開き、その国の横の **変更…** をクリックします。
2. **ロビーでの名前**: ロビーの国のリストでの呼び名です。ゲームの10言語それぞれで付けられます。そのままにした言語では、ゲームの名前が使われます。
3. **軍の名前**: オペレーションでどの軍を使うかを尋ねられるときの、その国の軍の名前です。
4. **旗**: **画像を選ぶ…** を使うか、ボックスに画像をドロップします。旗の画像なら何でもかまいません。ゲームの旗に合わせて調整され、丸い形はゲームのままです。**ゲームの旗** で元に戻ります。
5. **ゲームでテスト** をクリックして確かめます。

**すべて元に戻す** で、その国はゲームのものに戻ります。

## ユニット

その国のユニットは、いつもどおり **ユニット** タブで変更します。**新しいユニット…** で、どのユニットのコピーでもその国の生産メニューに入れられ、[[他の時代のユニット|他の時代のユニット]] も加えられます。ユニットが話す言葉は、そのページの **音声** にあります（[[音楽とサウンド|音楽とサウンド]] を参照）。

**すべてのユニットを一度に**（国家 タブで）: **<nation>のユニットをすべて隠す** で、そのユニットを生産メニューから外します（建物は残ります）。**再表示する** で元に戻ります。また、別の国のある時代のユニットで、その国のメニューを一度に埋めることもできます（すべてのユニットにチェックが入り、建物も選ばれています。不要なもののチェックを外してから追加します）。隠したユニットから研究されるユニットは最初から購入できるようになり、ページにどれがそうなるかが表示されます。作るものがなくなった建物は名前が表示され、自分のユニットを戻す方法も示されます。ゲームで確認済みです（イタリアのユニットを隠し、そのメニューに中国の時代ユニット）。

## ゲームで確認できたこと

確認できたこと（イタリアを中国に）: ロビーの国のリストに新しい名前、試合中にプレイヤー名の横に新しい旗、クラッシュなし。ロビーの国のボタンは、ゲームのメニューファイルの中で旗を描くので、そこはゲームの旗のままです。まだ確認していないこと: ロード画面とリプレイでの新しい旗。
