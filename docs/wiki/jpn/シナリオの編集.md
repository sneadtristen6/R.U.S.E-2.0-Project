# シナリオの編集

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.9.8.4 とMOD · **所要時間:** 数分

**シナリオ** とは、マップが始まるときの状態です: 占領ゾーン、各陣営の開始地点、そして最初からフィールドにあるユニットと建物。1つのマップにはいくつかのシナリオがあり、ゲームがそのマップを遊ぶ方法ごとに1つずつです。

## ゲームがマップを遊ぶ3つの方法

R.U.S.E. のメインメニューにあるボタンです:

| ボタン | 内容 |
|---|---|
| **バトル** | 1つのマップで、選んだプレイヤーとともにコンピューターと戦う自由なゲーム（他のゲームではスカーミッシュと呼ばれます）。 |
| **チャレンジ** | 決まった目標のある短いミッション。用意された配置で遊びます。 |
| **キャンペーン** | ストーリーを、章ごとに。 |

Studio はどのシナリオにも、それを遊ぶボタンの名前を付けます。シナリオメニューの下の金色の行が、どこにあるかを正確に示します: たとえば **ゲーム内: バトル › Dデイ（6人）**。

## シナリオを選ぶ

マップ画面のバーの先頭で、**シナリオ** を選びます（**マップ** の隣）。マップそのもの（地面、建物、木、道路）は薄く表示され、うっかりつかむことはありません。それらを変えるには **マップ** に戻します。次に上のメニューからシナリオを選びます。開始地点は各陣営の色の柱、出現地点は白いひし形、ゾーンは色の付いた範囲で表示されます。

## 開始地点や出現地点を動かす

1. **シナリオ** 側で **移動** をクリックします。
2. 柱かひし形をクリックし、次に置きたい場所をクリックします。
3. ゲームの元の位置に戻すには、もう一度クリックして **元に戻す** を選びます。

## ユニットを加える: 1つでも、隊形ごとでも

1. **シナリオ** 側で **ユニット配置** をクリックします。
2. 種類（建物、地上、歩兵、航空）、次にタイプ、次にリストのユニットを選びます（国ごとにまとめられています）。
3. **誰のもの？** を選びます。チャレンジやキャンペーンの章では、リストはそのシナリオ自身の陣営で、そのミッションから取られます: **プレイヤー**（あなた: キャンペーンでは陣営0）と **コンピューター** の陣営（それぞれ国付き）、それに **中立**。かっこの中の数字が保存される値です。**バトル** のマップは中立のユニットしか受け付けません（ゲームはチームの一覧なしでマップを始めるので、そこに置いたプレイヤーのユニットは決して現れません）。
4. **数:** 1、2、4、6、8、10。
5. 2つ以上なら **隊形** を選びます: 横隊、縦隊、楔形、方陣、円陣。隊形は画面の上を向きます: 向きを合わせるには視点を回してください。**間隔** でユニット同士の間のメートル数を決めます。
6. 各ユニットが立つ位置が、マップ上に輪で表示されます。クリックして配置します。

追加したユニットは、ほかの出現地点と同じように動かしたり、**削除** で取り除いたりできます。

## マップのプレイヤーを増やす（最大8人）

各プレイヤーは、自分のチームの **開始地点** から始まります。1人に1つです: 3対3なら、チーム1とチーム2がそれぞれ位置1から3を持ちます。4対4には、両方に位置4が必要です。

1. ゲームがオンラインで遊ぶシナリオ（金色の行に **バトル** とあるもの）を選び、バーの **シナリオ** をクリックします。
2. **プレイヤー数**（右側）にマップの人数が表示され、ゲームの値には *(ゲーム)* の印が付きます。新しい人数（最大8）を選びます。その下の行に、まだ足りない開始地点が1つずつ表示されます。例: *チーム1、位置4*。
3. **司令部の開始地点を追加** をクリックし、**チーム** を選んでから、そのプレイヤーが始める開けた地面を、他のプレイヤーから離れたところでクリックします。チームの次の位置が割り当てられ、カメラとイントロはチームメイトのものを使います。
4. 行に **全プレイヤーに開始地点があります** と表示されたら、**ゲームでテスト** をして **バトル** を開きます: マップが新しい人数で並んでいます。例: *(8) Cotentin (4v4)*。

追加した開始地点は **移動** で動かし、**削除** で取り除けます。8人より多くはできません: ゲームのロビーの席は8つです（2026-10-02 に試しました）。

> [!NOTE]
> 新しい機能で、まだゲームでは確認していません: 8人のゲームがどうだったか、[Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) で教えてください。

## 空白マップ: 各プレイヤーの司令部を置く

**空白の地形** や **空白の海**（マップタブの **マップを複製**）で始めたマップには、コピー元のマップのものは何もなく、司令部もありません。**各プレイヤーの司令部**（シナリオ側）に、マップに必要な司令部がすべて並びます: **配置** をクリックし、次に置きたい地面をクリックします。**ゲームでテスト** は、全プレイヤーに司令部ができるまで待ちます。

**マップの大きさ**（Studio 0.9.8.7）で、新しい空白マップを、帯状の地面1本ずつ大きくしたり小さくしたりできます: ある辺の **+** を押すとその辺に沿って地面が1本加わり、**−** を押すと1本取り除かれます。それから **この大きさにする** を押します。まだゲームでは試していません。

> [!WARNING]
> 2つの空白マップには、まだバグがあります: 自己判断で使い、見つけたことを教えてください。

## セクター

**セクター**（シナリオ側）は、シナリオのセクター、つまり計略カードを使うゾーンを変えます。空白マップには最初は1つもないので、自分で作ります。
- **形:** 角の点をドラッグすると境界が動きます（その境界を共有するセクターも一緒に動きます）。境界をダブルクリックすると点が加わり、点を右クリックすると消えます。**新しいセクター:** 地面の上で四角形をドラッグします。**セクターなし:** セクターにしたくない場所で四角形をドラッグします。**セクターを削除** は、その地面をすべて周りのセクターに渡します。
- **ペイント:** セクターを選び、地面の上をドラッグして塗ります。「セクターなし」は、地面をどのセクターからも外します。
- **セクターなしから始める** または **マップのセクターから始める**。**元に戻す** で最後の変更を取り消します。
- **セクターを作る** で、マップ全体を、**セクターの幅 約** に書かれた幅くらいのセクターに切り分けます（ゲーム自身のマップのセクターは差し渡し1～3 km です）。境界は曲がりくねった線になります。**別の配置** で別の切り方になります。そのあと、角をドラッグしたり塗ったりして形を整えます。

ゲームで確認済み: 空白マップに塗ったセクター、Dデイに描いた新しいセクターが計略カードで単独で光ること、どのセクターにも属さない地面（マップテーブル上の、どの計略カードでも光らない隙間）。セクターが1つながりのままになるように Studio が切る細い線は、まだゲームでは試していません。

## このマップの補給デポ

補給デポを選ぶと、トラックを増やせます（トラックが増えれば、中の資金も増えます）。または **ここにあるすべての補給所** を使います: すべてのデポのトラックを掛け算する（**倍のトラック**）か、すべて同じ数にして（**台ずつ**）、**適用** します。**ゲームの値に戻す** で元に戻ります。すべてのマップを一度に変えるには、**AIとプレイヤーの設定** の **マップ上の補給所** を使います（[[経済、AIなど|経済AIなど]]）。1,000台を超えるトラックのデポには Launcher 0.4.8.4 以降が必要です。

## 独自のミッション

新しいチャレンジやキャンペーンの章では、目標、イベント、カメラ移動を持つ独自のミッションを遊べます: [[ミッションを作る|ミッションを作る]]。

## ゲームでユニットを見る

1. **ゲームでテスト**（Studio の上部）をクリックします。Studio はMODを、ゲームのMOD入りのコピー（ゲームのドライブの `RUSE-Instances\Modded game`、または設定で選んだフォルダー。PC全体で1つで、Launcher のものも同じです）にビルドし、そこから R.U.S.E. を起動します。下部のメッセージが、何を開けばよいかを教えてくれます。例: **バトル > Dデイ**。
2. ゲームのメインメニューでそのボタン（バトルなら **バトル**）をクリックし、マップ（**Dデイ**）を選びます。
3. いつもどおりゲームを設定して始めます。ユニットは置いた場所に現れます。

> [!NOTE]
> Steam から R.U.S.E. を起動すると、MODなしでゲームが始まります。**ゲームでテスト**（または Launcher の **プレイ**）を使ってください。

> [!NOTE]
> バトルで、ロビーの各プレイヤーにどの開始地点が割り当てられるかは、まだテスト中です。分かったことを [Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) で教えてください。
