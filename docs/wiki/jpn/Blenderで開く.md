# Blenderで開く

> **必要なもの:** RUSE Studio 0.9.8.20 以降、MOD、Blender（無料） · **所要時間:** 読むのに 5 分

**Blenderで開く** は、ユニットを無料の 3D ソフト Blender に持っていき、形やボーン、塗装を変えられるようにします。
**変更を戻す** は、そこでしたことを MOD に入れます。ユニット全体に対して 1 つのボタンです：横の **Blenderに送るもの**
が何を送るかを示し、チェックを外したものはそのまま残ります。このページで順を追って説明します。

アニメーションはこのボタンでは変えません：RUSE Decoy で変えます（[[ユニットのアニメーション|ユニットのアニメーション]]
を参照）。モデル自身のアニメーションは、モデルと一緒に Blender へ行き、一緒に戻ります。

## ボタンの場所

| ユニット | 場所 | 戻ってくるもの |
|---|---|---|
| 自分で作った分隊（MOD の新しいユニット） | ページ上部の分隊カードにある大きな **Blenderで開く** | 兵士それぞれ、と彼らの塗装 |
| 自分で作ったそのほかのユニット（戦車、航空機） | **見た目と動き** の **モデル** 行の **もっと見る**：**Blenderで変更** の欄 | モデル全体（独自のボーンならボーンも）と塗装 |
| ゲームのユニット（分隊以外） | 同じ欄 | 塗装だけ：上から塗れます。ほかはゲームのままです |
| ゲームの分隊 | カードに、先に新しいユニットを作るよう表示されます：**このユニットから新しいユニット…** | **カスタム軍服** だけ。**軍服** 行から塗ります（**Blenderで開く**、次に **戻す**） |

この PC に Blender がない場合、ページに **Blenderを入手（無料）**（Blender のダウンロードページを開きます）と
**Blenderを選択…**（すでにあるなら `blender.exe` の場所を Studio に教えます）が出ます。

## Blenderに送るもの

ボタンの横の **Blenderに送るもの ▾** を押します。最初はすべてにチェックが入っています。そのままにしたい部分のチェックを
外します：**変更を戻す** は、Blender で何をされても、その部分を元のままにします。

| 表示 | 意味 |
|---|---|
| **兵士**、続いて兵士 1 人ずつ（「ライフル兵 1」「バズーカ兵 5」…） | チェックした兵士が 1 つの Blender に横に並んで開きます。だれを変えてもよく、変わるのは変えた兵士だけです。 |
| **どのモデル：** **ライフル兵のモデル** または **重火器兵のモデル** | 独自のボーンを持つ分隊（汎用騎馬分隊）：ボーンとアニメーション付きで、1 度に 1 モデル。 |
| **モデル** | ユニットの形（分隊ではないユニット）。 |
| **骨** | そのボーン（独自のボーンを持つモデルだけ）。チェックを外すと、MOD のボーンが元どおりに戻されます。 |
| **塗装** | その画像。チェックを外すと、MOD の画像が元どおりに戻されます。 |

知っておくと便利なこと：

- **塗装だけ**（モデル、または兵士全員のチェックを外す）：画像を塗れる状態で Blender が開き、戻るのは塗装だけです。分隊の
  **カスタム軍服** はこうして兵士全員分を一度に塗ります。標準の軍服を着た分隊ではできません：「先に「専用の軍服」を選んで
  ください。」（標準の軍服はほかの分隊や乗員も着ています）。先に **見た目と動き** の **軍服** 行で **カスタム軍服** を
  選んでください。
- **骨** のチェックを外したのに Blender でボーンを足した、消した、名前を変えた場合：ボーンは保てないので Blender が送った
  とおりに戻り、Studio がそう伝えます。
- ゲームの兵士の分隊には **骨** がありません：兵士は Blender で何をされても、ゲームの兵士のボーンに乗って戻ります。
- 何もチェックしていない場合：Studio に「まずBlenderに送るものにチェックを入れてください：モデル、骨、塗装。」と出ます。

## 行って戻る、手順

1. **開く。** **Blenderで開く** を押します。チェックしたものと一緒に Blender が開きます（数秒かかります）。
2. **変える。** 塗る、形を変える、兵士のボーンに自分のモデルを付ける（[[モデルとボーン|モデルとボーン]] の「ウェイト」を
   参照）。知っておくべき少しのことが Blender の 3D ビュー上部に書かれています。
3. **送る。** Blender の 3D ビュー左上の **R.U.S.E. Studioへ送る** を押します。
4. **戻す。** Studio のボタンが **変更を戻す** になっています：押します。届いたものがページに出ます：分隊ならだれが変わり
   だれが変わらなかったか、ほかのユニットならモデルのファイル、そしてチェックを外して保たれたもの。
5. **ゲームでテスト** で確認します。

Blender を開いたまま、変える・送る・戻すをもう一度くり返せます。

## 変更を戻す

- **Blender がまだ開いている？** **変更を戻す** は先に Blender に送るよう頼み、待ちます（最長 1 分）。
- **Blender を閉じる？** 閉じる前に **R.U.S.E. Studioへ送る** を押してください：送らなかったものは Blender に残り、
  Studio には届きません。
- **送ってから閉じた？** ボタンは押すまで **変更を戻す** のままで、最後に送ったものを取り込みます。分隊カードでは、最後に
  戻したあと（または **兵士を追加** のあと）に送ったものは、Blender を閉じると大きなボタンの下に小さな **変更を戻す** と
  して出ます：最後に送ったものを取り込みます。
- **まだ何も送っていない：** 「Blenderからまだ何も戻っていません。Blender上部の「R.U.S.E. Studioへ送る」を押してから、
  ここで「変更を戻す」を押してください。」
- 1 つのユニットに Blender は 1 つずつ：Blender が開いている間、Studio のボタンは **変更を戻す** です。

## 取っておいた送信

**送信** とは、Blender が **R.U.S.E. Studioへ送る** で送ったものです。最後の送信を戻す前に Blender を開き直すと：

- **分隊：** その送信は MOD の Blender フォルダーの中の、`sent-not-brought-` と日付・時刻の名前のフォルダーに取っておかれ、
  新しい Blender は MOD の今の状態から始まります。何も失われませんが、カードはまだそれを伝えず、戻すボタンもありません：
  ファイルは `Documents\RUSE 2.0\Mods\<あなたのMOD>\blender\<ユニットの名前>\squad\` にあります。
- **そのほかのユニット（モデルにチェック）：** 何も取っておかれません：次の **Blenderで開く** は最後に送ったものから
  始まります。
- **RUSE Decoy のアニメーション：** 取っておいた送信は、ユニットのアニメーションの上に（「Blenderから送られたまま戻されず、
  …取っておいたものです」）**取っておいた送信を戻す**（取り込む）と **ごみ箱に移す** 付きで表示されます。

## Blender のファイルの場所

MOD のフォルダー `Documents\RUSE 2.0\Mods\<あなたのMOD>\blender\<ユニットの名前>\` の中です：分隊のものは `squad`、
RUSE Decoy のものは `animations`。MOD を書き出すときには含まれません。分隊のページでは **その他のオプション** に場所が
出て、**フォルダーで表示** で開けます。

## うまくいかないとき

| 起きたこと | 理由と対処 |
|---|---|
| Blender が空のまま開く | Blender のウィンドウでエラーを探し（**Window > Toggle System Console**）、Discord で知らせてください。 |
| 触っていない兵士が変わったことになっている | 少しでも違えば変更とみなされます（名前を変えたオブジェクトも）。見た目は元のままです。 |
| 「どの兵士にも付いていないため送っていません：…」 | Blender に持ち込んだものが、兵士のボーンにもコレクションにも入っていません：兵士に付けて、もう一度送ります。 |
| モデルの点が腰と一緒にしか動かない | ボーンがありません：[[モデルとボーン|モデルとボーン]] の「ボーンのない点」を参照。 |
| 部品のつやや陣営の色が消えた | ページが名前を挙げます：Blender で名前を変えた、または新しく作ったマテリアルは素の状態で戻ります。Blender が開いたときのマテリアル名を変えないでください。 |
| ゲームのユニットの新しい形が戻らない | ゲームのユニットでは塗装だけが戻ります。形を変えるには、そこから新しいユニットを作ります。 |

## ゲームで試したこと

- Blender で塗ったユニットの塗装（近くと遠くから確認）。
- Blender で開いた分隊で、兵士 1 人を変えてその兵士だけを戻したもの（2026 年 11 月）。
- まだゲームで試していないもの：戦車のモデル全体を Blender に通すことと、**Blenderに送るもの** が保つもの（Blender と
  Studio で、ゲームの外で確認済み）。
