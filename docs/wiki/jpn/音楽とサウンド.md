# 音楽とサウンド

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.9.8.8 以降、MOD。自分の音にはサウンドファイル（WAV、
> MP3、OGG または FLAC）、自分の動きにはモーションキャプチャファイル（.bvh） · **所要時間:** それぞれ数分

ここで説明することは、すべて Studio の中、サウンドとアニメーションのデザイナーである **RUSE Decoy** タブで行います（Studio 0.9.8.8 で 音楽 タブに代わりました）。ほかのプログラムをインストールする必要はありません。

## ゲームのすべての音

**RUSE Decoy** には、ゲームにあるすべての音が、種類ごとに左側に並んでいます: 近くと遠くの武器、着弾と破壊、エンジンと足音、周囲の音、マップの背景音、インターフェース、計略カード、ユニットの声、司令部と諜報、無線の会話、ミッションの会話（各セリフの内容付き）、音楽とジングル。検索ボックスでは、音の名前や、その中で話される言葉から音を探せます。

それぞれの音について:

- **再生** で聴けます。
- **音量:** ドラッグします。100% がゲームの音量で、最大 200% まで上げられます。
- **差し替え…** で下のエディターが開き、自分の音をその代わりに入れられます。

変更はMODに保存され、テストや書き出しのときにゲームに入ります。

## 音や曲を置き換える

1. サウンドファイルをエディターにドロップするか、選びます。長さは自由です: Studio がゲームの形式に変換します。
2. 2つのハンドルで切り取り、**フェードイン** と **フェードアウト**、**音量** を設定して、聴いてみます。
3. **これを使う** でMODに保存されます。あとで **変更…** を押すと再び開き、**削除** でゲームの音に戻ります。

## 曲を追加する

**音楽とジングル** の下には、曲が流れる場面ごとに並んでいます: メインメニュー、クレジット、バトルで流れる3つのリスト、試合の終わり、ミッション目標、そしてその曲を指定しているキャンペーンの章とチャレンジです。3つのバトルリストは、プレイヤーが戦力を整えている間の穏やかなリスト、弾が飛び交い始めてからの戦闘のリスト、そして計略カードが使われたときの計略の音楽です。

各バトルリストの下にある **曲を追加…** から、名前を付け、サウンドファイルをドロップし、切り取ってから **これを使う** を押します。その曲は、そのリストからゲームが流す曲に加わり、「新規」の印が付きます。

## アニメーション

**アニメーション** の下には、ユニットの動き方が並んでいます。走る、撃つ、弾を込めるといった動きから、倒れる動きや砲の操作員の作業までです。それぞれに、ゲームでの呼び名と、それを使うユニットの数が表示されます。**見る・変更…** で、それを使うユニットの上に 3D で表示されます（ドラッグで回し、ホイールでズーム。3D ビューには一度だけインターネットが必要です）:

- **速度:** 100% がゲームの速さ、200% で2倍の速さ、50% で半分の速さ。
- **代わりに使う動き:** 同じ体の別のアニメーションを、その代わりに使います（たとえば、ライフル兵を逃げるときの走り方で走らせるなど）。
- **ボーン** と、**大きさ** と **回転軸** / **回転**: 体の一部を、アニメーションの間ずっと大きくしたり、回したりします（そこに付いているものも一緒に大きくなります）。
- **ゲームの動きに戻す** で、そのアニメーションへの変更をすべて取り除きます。

## モーションキャプチャ

**モーションキャプチャ** の下で、実際の人の動きをアニメーションに付けられます: モーションライブラリから動きを選ぶ（CMU モーションキャプチャデータベースと 100STYLE の無料の動き3,205種。それぞれ選んだときにダウンロードされます）か、自分のファイルを **モーションキャプチャを選ぶ…** で選びます（.bvh。Mixamo、Blender、またはどのモーションキャプチャのプログラムからでも）。

1. 使う部分を選びます: **開始**（秒）と **長さ**。歩きや走りなら、左右それぞれの足でまるごと1歩ずつ。倒れる動きなら、倒れる少し前から始めます。
2. **その場に留める** で、歩きや走りを、ゲームがユニットを動かす位置に保ちます。**ループさせる** で、最後のポーズをなめらかに最初のポーズへつなげます。ゲームが繰り返し再生するアニメーション向けです。
3. **クレジット（動きの作者）:** ライブラリの動きでは入力済みです。ほかのファイルでは、作った人とそのライセンスを書いてください。MODがどこへ行っても一緒に付いていきます。
4. **確認する** を押してから、**使う** を押します。速度とボーンの変更は、その上にそのまま加わります。**ゲームの動きに戻す** で取り除きます。

## ユニットの音とアニメーション

ユニットのページには **サウンドとアニメーション** セクションがあります: そのユニット自身の声のセリフとエンジンの音、そしてアニメーションです。**RUSE Decoyで音を変更** で、そのユニットの音を表示した RUSE Decoy が開きます。ユニットは自分の国と種類のセリフを話すので、そこで変えたセリフは、それを共有するすべてのユニットから聞こえます。ユニットの砲の音や命中の音は、武器と着弾の種類の下にあります。

## マップの背景の音

**マップ** タブの **背景の音…** で、そのマップの背景の音が表示されます: 何をもとにしているかと、その3つのレイヤーで、どれも同じエディターで聴いたり置き換えたりできます。マップは、別のマップで流れる背景の音をもとにすることもできます。

## ゲームで確認できたこと

ゲームで確認済み: RUSE Decoy の音とアニメーション（Studio 0.9.8.8）、メインメニューの曲、バトルリスト1と2の曲、それらに追加した新しい曲、ユニットの声のセリフ。まだ試していないもの: マップの背景の音と、計略の音楽のリスト（ゲームの仕組みから分かっていること）。RUSE Decoy のエラーメッセージは、今のところ英語だけです。
