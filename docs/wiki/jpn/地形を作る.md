# 地形を作る

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.7.2 とMOD · **ゲームで確認済み:** ユニットは編集した地面の上を走り、
> そこで命令を受け付ける

## マップを開く

1. **マップ** タブで、左のリストからマップを選びます（**«** ボタンでリストを折りたたむと、広く使えます）。
2. 見回します。ドラッグで回転、右ドラッグで移動、ホイールでズームです（キー: [[マップ画面のキー|マップ画面のキー]]）。
3. 下のバーで **地形・水** をクリックします。ツールがバーの上に開き、最初は **地形** タブです。

## ツール

| ツール | 用途 | 使い方 |
|---|---|---|
| **丘** | 丸い丘 | 1回クリック |
| **上げる** / **下げる** | 少しずつ盛る、または削る | ドラッグ |
| **クレーター** | 縁のあるクレーター | 1回クリック |
| **台地** | 上が平らな丘 | 1回クリック |
| **平らにする** | でこぼこを1つの高さに近づける | ドラッグ |
| **高さをそろえる** | 始めた場所の高さで、地面を平らに塗る | ドラッグ |
| **なめらかにする** | とがった縁をやわらげる | ドラッグ |
| **スロープ** | 一定の傾斜（たとえば台地へ上る坂） | 始点、次に終点をクリック |

**サイズ** と **強さ** は右側のスライダーです（キー **[ ]** と **- =**）。

## 水

**水** タブ（**地形・水** の中）をクリックします。

- **水** は、ある高さより低い地面を水で満たします。その高さは、ドラッグを始めた場所の高さに 強さ を足したものです。谷に沿ってドラッグすれば川に、くぼみにドラッグすれば湖になります。
- **排水** は、水をマップの基本の高さに戻します。そこの川や湖は干上がります。

## 地面をテクスチャで塗る（Studio 0.9.8.5）

**まだバグがあります。自己責任で使ってください。** 下のバーで **マップペイント** をクリックし、次に **テクスチャ** をクリックします。テクスチャの取得元を選び、1つクリックして、地面の上をドラッグします。

- **ゲームのテクスチャ:** ゲーム自身のマップの地面テクスチャ（草、畑、砂、雪、岩、道路...）を、グループごとに、検索付きで。あなたのゲームから読み込まれ、MODには何も入りません。
- **マップから:** マップを選び、その上の1点をクリックします。そこの地面の320 m四方が、あなたのテクスチャになります。
- **自分の画像:** **画像を追加…** で、自分の画像をMODに保存します（`files/ground`）。
- **オンライン（無料）:** Poly Haven と ambientCG のテクスチャ（CC0）と、アメリカの航空写真（パブリックドメイン）。クリックすると、その1枚がクレジット付きでMODにダウンロードされます。まだ試していません。
- **このマップ:** 選んだ場所から、このマップ自身の地面をコピーします。

**サイズ** で、大きくも小さくも敷けます（4分の1から16倍まで）。ゲームのテクスチャでは、**近くでゲームの細部** を使うと、塗ったものの上に、そのテクスチャのゲーム自身のデカールも重ねます。ゲームではまだ確認していません。

## 元に戻す・やり直す

**元に戻す**（または **Ctrl+Z**）で、最後のストロークを取り消します。**やり直す** で、このマップのすべてのストロークを取り消します。

## ゲームで確かめる

**ゲームでテスト** を押し、ゲームのメインメニューで **バトル** をクリックして、そのマップを選びます。どのマップかは、Studio の下のメッセージに表示されます。

> [!TIP]
> 急な崖はギザギザに見えます。ゲームの地面は三角形のメッシュで、鋭い縁はその三角形の間に落ちてしまうからです。
> 幅が広く、なだらかな形がいちばんきれいに見えます。
