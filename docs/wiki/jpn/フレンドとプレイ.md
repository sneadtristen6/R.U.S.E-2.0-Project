# フレンドとプレイ

> **対象:** プレイヤー · **必要なもの:** RUSE Launcher と、フレンドと同じMOD · **所要時間:** 5分

全員が **同じMODを同じ順番で** 入れていないと、ゲームが一致しません。

1. ホストがMODセットを選んで **共有** をクリックします。セットのロード順がテキストとしてコピーされます。
2. ホストはそのテキストを（Discord やチャットなどで）送り、足りないMODファイルがある人にはそのファイルも送ります。
3. 各フレンドは足りないMODファイルを追加してから **ロード順をインポート…** をクリックし、テキストを貼り付けます。同じMODが同じ順番で入った新しいMODセットができます。
4. 全員が **プレイ** を押し、ホストはいつもどおりゲームを設定します。

> [!TIP]
> このテキストは RUSE-Mod-Manager がコピーして読み込むのと同じ形式なので、RUSE-Mod-Manager を使っているフレンドも参加できます。

## 同じゲームか確かめる：参加コード

**参加コード** は、MODを入れたあなたのゲームから作られる短いコードです：同じコードなら同じゲーム（同じゲームのバージョン、同じMOD、同じMODのバージョン）です。対戦の前にコードを比べれば、同期がずれないことがわかります。

1. MODセットで一度 **プレイ** を押します：MOD版コピーと一緒にコードができます。
2. Launcherの下の **参加コード** を押します。**RUSE Guard：あなたの参加コード** の画面にあなたのコードが出ます：**コピー** して、一緒に遊ぶ人に送ります。
3. 友達のコードを **友達の参加コードを貼り付け** に貼り付けて **比較** を押します：「同じゲームです。一緒に遊べます。」、または違う点の一覧付きで「同じゲームではありません。」。

知っておくと便利なこと：

- MODを変えるとコードも変わります：変えたら送り直してください。
- 「コードはありません。これらの MOD はゲームの遊び方を変えないので、誰とでも遊べます。」
- チートMODやテストツールを含むセットは、同じコードのプレイヤーとだけマルチプレイと協力プレイができ、それ以外の対戦は数秒で抜けます。
- **コピーの全ファイルを確認** は、MOD版コピーがビルドしたときのままかを確かめます。
