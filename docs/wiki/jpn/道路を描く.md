# 道路を描く

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.7.4 とMOD · **ゲームで確認済み:** 補給ルートが新しい道路を通り、
> 道路は地面に描かれる

## マップの道路を見る

マップ上部の **道路** にチェックを入れると、マップ自身の道路が金色で表示されます。地面の形を変えても、その地面の上に表示されます。

## 新しい道路を描く

1. 下のバーで **道路・橋** をクリックします（その **道路** タブが開きます）。マップの道路は金色、新しい道路は青で表示されます。
2. ツールを選びます。

| ツール | 使い方 |
|---|---|
| **直線** | 道路の始点、次に終点をクリックします。 |
| **曲線** | 始点、次に道路を引き寄せる曲がり目、最後に終点をクリックします。 |
| **自由** | 道に沿ってクリックしていきます。ダブルクリックするか、**Enter** を押すか、**完了** をクリックすると終わります。 |

3. 青い帯がポインターについて動き、その横に **道路の長さ** が表示されます（自由 では、最後のクリックからの部分も表示されます）。端がどこかの道路の近くにあると **その道路にスナップ** し（どこかは輪で表示）、新しい道路がその道路につながります。補給トラックは一方から他方へ走れます。道路ツールには、マップの新しい道路の数と、その合計の長さが表示されます。
4. **Esc** で描いている途中の道路を取りやめ、**元に戻す**（または **Ctrl+Z**）で最後の道路を取り消し、**やり直す**（または **Ctrl+Y**）でもう一度描きます。

新しい道路は、すぐにMODに保存されます（`maps/<map>/roads.toml`）。

## 新しい道路がゲームですること

- **補給ルートが使う**（確認済み: 補給デポのルートが、開けた畑を抜ける新しい近道を通った）。
- **地面に描かれる**: マップ自身の道路の色で描かれるので、プレイヤーに見えます（ゲームで確認済み）。高い所から見ても、地面すれすれで見ても、マップ自身の道路のように見えます。
- **歩兵がたどる**: 早く着くために道路を使います（ゲームで確認済み、Studio 0.8.0）。
- **水の上では橋になる**: マップ自身の種類の橋で（32マップ中24マップにあります）、ゲーム自身の橋と同じように1つの部品を岸から岸まで伸ばしたもので、ユニットが渡れます。マップ自身の橋の上を通る道路では、その場所に新しい橋が架かります。橋の種類がないマップでは、ビルドがそう知らせ、その水は閉じたままです。（ゲームで確認済み: 戦車、歩兵、補給トラックが橋の上を渡る。）
- 道路の通り道にある植物や小物は取り除かれます。**新しい道路の木を残す** で、木や茂みを残せます（木の下を通る道路）。

## マップ自身の道路と橋を取り除く

**道路** ツールで:

- **マップの道路を取り除く:** マップ自身の道路がなくなります。補給トラックがたどる道路網（トラックは代わりに野原を横切って走ります）と、地面に描かれた道路の両方です。自分の新しい道路は残ります。ゲームで確認済み: 道路はなくなります。補給トラックが野原を横切って走るところは、まだ試していません。
- **マップの橋を取り除く:** マップ自身の橋が、ユニットが乗っていた床ごとなくなります。次のボックスにもチェックを入れないかぎり、ユニットは橋があった場所を、その下の地面の上でこれまでどおり渡ります。自分の新しい橋は残ります。
- **旧橋の渡り口を塞ぐ**（橋を取り除いたとき。DomesticNukes より）: 古い橋が水の上に架かっていた地面がユニットに対して閉じられ、そこを通る道路のつながりが切られます。補給トラックも含めて何もそこを渡れず、ほかの道路網はそのまま残ります。同じ場所を渡る自分の新しい道路には、そこに専用の橋が架かります。閉じることで地面の一部がほかから切り離されてしまう場合は、ビルドの前に Studio がそう知らせます。

まだゲームでは試していないもの: 橋を取り除くことと、その渡り口を塞ぐこと。

## 自分の橋を置く

**橋** タブで、種類を選び、長さと向きを決めてから、橋の中央を置く地面をクリックします。両端は乾いた岸に載るようにしてください。ここでも **元に戻す** と **やり直す** が使えます。

**確認するには:** **ゲームでテスト** を押し、ゲームのメインメニューで **バトル** とそのマップを選びます。道路の近くに補給デポを置いて、そのルートを見てください。
