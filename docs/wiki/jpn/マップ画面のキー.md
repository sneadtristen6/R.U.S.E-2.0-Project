# マップ画面のキー

これらのキーは、Studio のマップ表示が開いていて、どのテキストボックスにもフォーカスがないときに使えます。どのキーも **設定 > マップ表示のキー** で変更できます（キーをクリックしてから、使いたいキーを押します）。ほかの操作がすでに使っているキーを選ぶと、まず確認されます: **入れ替える**（2つの操作がキーを交換します）、**奪う**（もう一方は、キーを割り当てるまでキーなしになります）、または **キャンセル**。キーはキーボード上の位置で決まるので、AZERTY キーボードでも W A S D は同じ位置のキーです。

| キー | 動作 |
|---|---|
| **W A S D** または矢印キー | 視点を動かす（**Shift** を押したままで3倍速く） |
| **Q** / **E** | 見ている点を中心に回る |
| **R** / **F** | ズームイン / ズームアウト |
| **1** ～ **0** | 最初の10個のブラシから1つを選ぶ |
| **B** | ブラシのオン / オフ |
| **P** | 配置のオン / オフ |
| **[** / **]** | 小さく / 大きく（ブラシと配置する物体） |
| **-** / **=** | 弱く / 強く（ブラシ）、または回転（配置する物体） |
| **Esc** | 見回す状態に戻る。作りかけの列、グリッド、経路を取りやめる。何も選んでいない状態にする |
| **Ctrl+Z** | 最後のストローク、配置した物体、移動、削除を元に戻す |
| **Ctrl+Y** または **Ctrl+Shift+Z** | 元に戻したことをやり直す |
| **Shift+クリック** | 選んでいるものに追加する（**選択**） |
| **Delete** | 選んでいるものを削除する |
| **Enter** | 経路や自由の道路を完了する |

## パネルの配置

マップパネル（左上）とツール（下）は、どこへでも動かせます。グリップ（⠿）をドラッグしてください。その横の矢印でパネルを折りたためます（マップパネルはタイトルだけに、ツールはバーだけに）。グリップをダブルクリックすると、そのパネルが元の位置に戻ります。配置は保存されます。

## マウスで

| マウス | 動作 |
|---|---|
| ドラッグ | 視点を回す（ツールがオンのときは、そのツールを使う） |
| 中ボタンでドラッグ | 視点を回す（ツールがオンのときも） |
| 右ドラッグ | 視点を動かす |
| ホイール | ズーム |
