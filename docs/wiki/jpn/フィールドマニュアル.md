# フィールドマニュアル

**RUSE Launcher** と **RUSE Studio** の手順ごとのガイドです。プロジェクトの紹介、ニュース、ダウンロードは [プロジェクトのページ](https://github.com/sneadtristen6/R.U.S.E-2.0-Project)をご覧ください。

## はじめての方は、ここから

- **MODで遊ぶには:** [[インストールとプレイ|インストールとプレイ]]。[Launcher のリリース](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=launcher)から **RUSE-Launcher-Setup** をダウンロードして実行し、**RUSE Launcher** を開いて **対応MOD** をクリック、MODにチェックを入れて **インストール** を押し、MODセットに入れたら **プレイ**。5分で済みます。
- **MODを作るには:** **RUSE Studio** をインストールし（同じページの最後）、次に [[はじめてのMOD|はじめてのMOD]] へ。
- **困ったら:** [[うまくいかないとき|うまくいかないとき]]、または [Discord](https://discord.gg/h54t5baNsC) で質問してください。
- **お手持ちのコピー:** どちらのアプリも、Steam で所有している R.U.S.E. でしか動きません。R.U.S.E. が Steam に来る前のパッケージ版や、アプリが確認できなかったコピーについては、[[うまくいかないとき|うまくいかないとき]] を見てください。
- **言語:** どちらのアプリもこのマニュアルも、11の言語で使えます: English、Français、Deutsch、Italiano、Español、Polski、Русский、Čeština、日本語、简体中文、فارسی（ペルシア語）。各アプリの右上に言語ボタンがあり、マニュアルのほかの言語はサイドバーのいちばん上の行にあります。

> [!WARNING]
> **まだバグがあります。自己判断でお使いください:** Map Paint のテクスチャと、2つの空白マップ（空白の地形と空白の海）。

## 2つのアプリ、2つの役割

| | **RUSE Launcher** | **RUSE Studio** |
|---|---|---|
| **対象** | MODで遊ぶすべての人 | MODを作る人 |
| **役割** | MODをゲームに読み込み、一緒に動くことを確かめます。遊ぶMODはすべてこれを通ります | MODを作ります: 新しいマップ、シナリオの編集、ユニット、町、軍隊 |
| **得られるもの** | ワンクリックで遊べるMOD入りのゲーム。Steam のインストールはそのまま | ゲームでテストでき、書き出して共有できるMOD |

Studio で作ったMODは Launcher で遊びます: 書き出して、追加して、プレイ。Studio の **ゲームでテスト** は、作業を確かめながら進めるために、手早いテスト用のコピーを単独で起動します。
