# 経済、AIなど: LittleGroove のツール

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.9.8.1 以降とMOD · **所要時間:** 好きなだけ

LittleGroove の RUSE-Mod-Manager には、Studio になかったツールがありました。それらは今では Studio に入っていて、どれも自分のMODの中で使います。変更はすぐにMODに保存され、ゲームのファイルには決して手を触れません。

## 「AIとプレイヤーの設定」タブ

3つの部分からなる1つのタブです: **プレイヤーの設定**、**ゲームのルール**、**コンピューター**。

### プレイヤーの設定

初期資金と収入、補給デポ（トラック1台あたりの資金、車列あたりのトラック数、車列の間隔）、生産の上限、そして各陣営が最初に持っている計略カード。変更はすべてのゲームモードに効きます。核戦争モードに独自の値がある場合は、そのための別のボックスがあります。補給デポと管理施設は建物なので、価格、建設時間、耐久は **ユニット** タブにあります。
ゲームで確認済み: 初期資金と、開始時の計略カード。

**マップ上の補給所**（補給デポの下）: すべての補給デポのトラックを増やします。つまり資金が増えます。対象は **すべてのマップ**、または **1つのマップ：** で選んだマップです。各デポのトラックを掛け算する（**倍のトラック**）か、すべて同じ数にします（**台ずつ**）。その上の行に、あなたの値でデポがどれだけ持つかが表示されます。マップタブで独自のトラック数を与えたデポは、その数を保ちます。1デポあたり1,000台を超えるトラックのMODは、Launcher 0.4.8.4 以降で遊んでください。ゲームで確認済み（Dデイのデポを500台に、他のマップは元の3倍に）。

### ゲームのルール

ゲームが全プレイヤー共通に持つ、その他のすべてのルールを、グループごとに並べています: 戦闘と降伏、人口、移動と道路、射撃と目標、単独で動くユニット、ダメージと制圧、森と視界、航空機、計略カードの効果、ゲームコントローラー、建物の配置、オンラインのランクマッチ、輪郭と矢印、画面上のエフェクト、陣営とセクターの色（それぞれにカラーピッカー）、そして最後に、用途がまだ分かっていないいくつかの値。どれにも、それが何をするかと、ゲームの値が書かれています。まだゲームでは試していません。

### コンピューター

コンピューターの遊び方です。コンピューターは3組の値を組み合わせます: **既定**、難易度、AIタイプ（どちらもゲームのロビーで選びます）。1つを選ぶと、その値を見て変えられます: いつ攻撃を始めるか、どれだけ強くなるまで待つか、どう守るか、好むユニット、計略カード。どの値も、どの組でも変えられます。組に載っていない値はゲームでは0として扱われ、数値を入れるとMODに加わります。その下には、すべてのコンピューターに共通するもの（攻撃を始める軍の価値、囮など）があります。
ゲームで確認済み: メニューから外した計略カード、メニューの中で動かした計略カード、カードの効果時間、「易しい」が攻撃を始めるタイミング。残りはまだゲームでは試していません。

**マップとミッションのスクリプト**（その下）: ゲームがマップ上で動かすスクリプト（キャンペーンの章、チャレンジ、オペレーション）を、読める Python として表示します。**コピー** で1つをコピーします。

## ユニットの「アップグレードと研究」ボックス

ユニットのページに: そのユニットが何のアップグレードか（**アップグレード元**）、そのユニット自身のアップグレード、研究の価格と時間があります。別のユニットを選ぶか、**なし：独立したユニット** を選びます。[[ユニットの編集|ユニットの編集]] を参照してください。

## 「すべての値とファイル」タブ

リストの上のスイッチで選ぶ、2つの部分があります。

**すべての値:** ゲームのどんなオブジェクトや値でも、MODの中で変えられます: 値を加えたり取り除いたり、オブジェクトを作ったり削除したり、テキストの値に独自の言葉を与えたり。まだゲームでは試していません。

**ファイル:** ゲームのパックの中のどんなファイルでも: パックを選び、次にファイルを選ぶと、その中身のとおりに表示されます（画像、テキストの表、ミッションのスクリプトなど）。**コピーを保存…** で外に保存し、**自分のファイルで置き換える…** で自分のファイルをMODに入れ、**このパックに自分のファイルを追加…** で新しいファイルを加えます。MODには変更した部分だけが残り、ゲームのファイルのコピーが入ることはありません。まだゲームでは試していません。

## ミッションとマップ

ミッションのスクリプトは変更できます。Studio は、それがメニューにあるか、必要なファイルがすべて読み込まれるか、そしてテキストを確認します。メニューの中で上下に動かすこともできます。マップでは: 町と丘の名前、名前付きの地点とゾーン、マップ上のアイテムの名前と向き。ユニット、値、コンピューターには **メモ** を残せます。まだゲームでは試していません。

## Launcher では: 古いMODを変換

ゲーム本体のパックの形で配られ、ゲームフォルダーにコピーして使う古いMODは、ライブラリで他のMODと並べて遊べるMODになります: [[インストールとプレイ|インストールとプレイ]] を参照してください。
