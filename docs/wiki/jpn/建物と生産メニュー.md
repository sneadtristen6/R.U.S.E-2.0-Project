# 建物と生産メニュー

> **対象:** モッダー · **必要なもの:** RUSE Studio 0.9.8.8 以降とMOD · **所要時間:** 数分

各国の建物、その生産メニューに何がどの順で並ぶか、そして自分の建物について。ゲームで確認済み。

## 建物ボード

**国家** タブを開きます: 各国の下の **建物とユニット** に、その国の建物が行として並び、各行には、その建物の生産メニューに並ぶユニットがゲームの順で並びます。新しいMODの **建物** の手順にも、同じボードが表示されます。

- **+** で建物にユニットを加えます: その国自身のユニット、ほかの国のユニットのコピー、または[[時代ユニット|他の時代のユニット]]。コピーはMODに入り、ゲームでの名前で呼ばれます。
- ユニットを行に沿って **ドラッグ** するとメニューでの位置が変わり、別の建物の上にドラッグすると、そこで生産されるようになります。
- **×** で、ユニットを生産メニューから取り出します。隠されるだけで、削除はされません: ユニットはゲームのファイルに残ります。
- **研究…** を押し、次にその前に来るユニットで **この下に置く** を押します: そのユニットから研究されるようになります（その国のどの建物にあっても）。**最初から生産可能** にすると研究は不要になります。**研究費** と **研究時間（秒）** はその横にあります。

各行には、そこにあるユニットの数が表示されます。生産するものが何もなくなった建物は、ゲームで選ぶと司令部の建物リストを表示します。1つの建物に10を超えるユニット、地上の建物に航空機、飛行場に車両: まだゲームでは試していません。

**ユニット** タブのユニットのページには、それがどこで生産されるかが表示され（「戦車工場で生産：6個中2番目。」）、**建物で表示** でその行が開きます。

## 建物を追加する

国のボードの下の **建物を追加…** で、コピーするゲームの建物を選び（**コピー元**）、**名前** を付けてから、次のどちらかを選びます:

- **コピー元の建物と同じユニットを生産**、または
- **独自のユニットを生産**: ゲームの生産バーに専用の行とタブを持ち、**+** で中身を入れます。1つの国に3つまで。

独自のユニットを持つ2つ目と3つ目の建物には、建物を増やすための小さなゲームパッチが必要です。Studio がそれを一度だけダウンロードし、MOD入りのゲームのコピーにだけ入れます。Steam フォルダーにあるゲームには決して入れません。

## 建物独自の見た目

新しい建物のページで **モデルを読み込む** を使うと、自分の 3D モデル（.glb、.gltf または .3ds）が、コピー元の見た目の一部の代わりに入ります: 工場や司令部の本体、または選んだ部分です。モデルはその部分の大きさに合わせられ、その部分があった場所に立ちます。見た目のほかの部分はそのままです。ゲーム自身の建物は今のままです: まずそれをもとに新しい建物を作ってください。

**建設メニューの画像:** 点線の枠の中でちょうどよく見えるまでモデルを回してズームし、その視点を使います。モデル全般については [[モデルの取り込み|モデルの取り込み]] を参照してください。

## ゲームで確認できたこと

確認済み: ボードでの変更（ユニットの追加、移動、取り出し、別のユニットからの研究）、コピーした建物、独自のユニットを持つ建物と生産バーのそのタブ、ゲームパッチを使った2つ目と3つ目の建物、建物独自のモデルと画像。
