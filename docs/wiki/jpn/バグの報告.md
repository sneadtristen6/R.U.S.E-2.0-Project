# バグの報告

> **必要なもの:** 無料の GitHub アカウント · **所要時間:** 5分

## アプリから（いちばん早い方法）

- **RUSE Studio:** 設定 > ヘルプとコミュニティ > **問題を報告**、またはエラーメッセージの横の **報告**。
- **RUSE Launcher:** 下のバーの **問題を報告**。

ブラウザーで新しいバグ報告が開き、アプリとそのバージョンが入力された状態になります（エラーの横の 報告 を押した場合は、そのエラーも）。自分で投稿するまで、何も送信されません。

## Webサイトから

[Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) > **🐞 Bug reports** > **New discussion**。短いフォームで詳しい内容を尋ねられます。

## 修正に役立つこと

1. **アプリとバージョン**（設定 に表示されます）。
2. **何をしたか**。こちらで同じことができるよう、手順を追って。
3. **何が起きたか**、そして何が起きると思っていたか。
4. **メッセージ**（出た場合）。選択してコピーし、貼り付けてください。
5. **スクリーンショット**。投稿にドラッグしてください。

> [!WARNING]
> ファイルへのパスには Windows のユーザー名が含まれます（`C:\Users\<you>\...`）。代わりに `%LOCALAPPDATA%\...` と書いてください。
> アプリの報告ボタンは、これを自動で行います。
