# 書き出しと共有

> **対象:** モッダー · **必要なもの:** RUSE Studio と完成したMOD · **所要時間:** 5分

## 1. 書き出す

1. **MOD** メニューを開き、**MODを書き出す…** を選びます。
2. **バージョン**（`1.0.0` のような3つの数字）、自分の名前、MODの内容を1行で入力します。
3. 保存場所を選びます。Studio はMODを一度ゲーム上でビルドし、作ったときのゲームのビルドと、その **フィンガープリント**（同じMODを入れた人なら誰でも同じになる短いコード）を記録してから、1つのファイルを保存します: `<your-mod>-<version>.rusemod`。

プレイヤーに必要なのはこのファイルだけです: RUSE Launcher で追加します（[[インストールとプレイ|インストールとプレイ]]）。

**大きなマップのMOD:** 全体を変えたマップでは、ビルドが計算に数分かかることがあります（たとえば、開いた地面のどこをユニットが通れるか）。それを待つのは一度だけです。書き出しでは、ビルドが計算した結果がファイルに入るので、プレイヤーの最初のビルドは短くなります。入っているのは私たち自身の数値だけで、ゲームのファイルは決して入りません。また、そのマップのゲーム自身のファイルで鍵がかかっているので、ゲームを持っている PC でしか開けません。今のところ移動だけです。まだゲームでは確認していません。

書き出しが終わると、Studio は **MODを共有する** を開き、ファイルのサイズ、SHA-256 チェックサム、リスト用のエントリを、コピーできる形で表示します。**MOD** メニュー（**MODを共有…**）から、いつでももう一度開けます。

## 2. 共有する: 対応MODに加える

MODを作りましたか？ リストに加えて、コントリビューターになりましょう。RUSE Launcher の **対応MOD** タブには、[sneadtristen6/Ruse-Mods](https://github.com/sneadtristen6/Ruse-Mods) のリストにあるMODが表示され、プレイヤーはワンクリックでインストールできます（新しいプレイヤーには、Launcher の初回起動時に勧められます）:

1. `.rusemod` をアップロードします（GitHub の Release がいちばん簡単です: 自分のリポジトリのものでも、リストのものでも）。
2. [sneadtristen6/Ruse-Mods](https://github.com/sneadtristen6/Ruse-Mods) に、`index.toml` へ自分のMODのエントリを加えるプルリクエストを出します: 「MODを共有する」に表示されたエントリを貼り付け、`download` にファイルのリンクを入れます。サイズと SHA-256 は、書き出しで表示されたものでなければなりません: 一致しないダウンロードを Launcher は拒否するので、誰もあなたのファイルを別のものにすり替えられません。
3. または、スクリーンショットと変更内容を添えて [Discussions > Mods & maps](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) に投稿すれば（`.rusemod` を投稿にドラッグします）、代わりにリストに加えてもらえます。

チートやテスト用ツール（無料のユニット、即時建設など）には `"cheat"` のタグが付きます: Launcher はそれを専用のグループ「チートとテスト用ツール（任意）」に表示し、プレイヤーが自分で選ばない限り、チェックを入れたりダウンロードしたりはしません。新しいバージョンは、新しいバージョン番号の新しいファイルです: 公開したファイルが変わることはありません。

エントリの正確な形式:
[MOD_FORMAT.md、セクション15](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/blob/main/docs/MOD_FORMAT.md#15-the-mod-index-supported-mods)。

## インストール済みのMODを編集する

Studio のMODメニューの **インストール済みのMODを編集…** には、Launcher にあるすべてのMODが並びます（検索ボックス付き）。自分のMODなら、そのプロジェクトが開きます。他の人のMODは、独自の名前を持つ自分用のコピーになります（元のMODの名前は使えません）: 変更はそのコピーに入り、元のMODが更新されても消えることはありません。RUSE Mod Manager のMOD（`.rmod`）はそのコピーの中で変換されるので、その値の変更は、Studio で変えられる Studio の変更になります。

## MODのフォルダーを表示する、MODを削除する

Studio のMODメニューの **このMODのフォルダーを表示** は、編集中のMODのフォルダーを開きます。**MODを削除…** には自分のMODとマップの変更が並びます: **削除** でごみ箱に移り（そこから元に戻せます）、チェックすれば Launcher のコピーも一緒に移ります。ほかの場所から開いたフォルダーはリストから外すだけです。**設定 → ファイルの保存場所** で、すべての保存場所がわかります（[[MODのフォルダーとファイル|MODのフォルダーとファイル]]）。RUSE Launcher でも **取り除く** でライブラリーのMODがごみ箱に移り、**フォルダーで表示** でそのフォルダーを開けます。

## MODに入れられるもの

データだけです: 数値、テキスト、マップ、モデル、テクスチャ。プログラム（`.exe`、`.dll`、PC 上で動くスクリプト）は、どちらのアプリでも拒否されます。例外は1つ: Studio が保存した形の、ゲーム自身のミッションスクリプトです。これはゲームの中で動き、ゲームができることは何でもできるので、信頼できる作者のものだけをインストールしてください（[SECURITY.md](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/blob/main/SECURITY.md)）。

## よいやり方

- MODのフォルダーは取っておきましょう: `.rusemod` はプレイヤー用で、Studio が編集するのはフォルダーのほうです。
- 自分のMODが必要とする他のMODや、ぶつかる他のMODを、投稿に書きましょう。
- 自分が土台にした作品の作者をクレジットしましょう。
