# Jouer entre amis

> **Pour :** les joueurs · **Il vous faut :** RUSE Launcher, et les mêmes mods que vos amis · **Durée :** 5 minutes

Chaque joueur a besoin des **mêmes mods dans le même ordre**, sinon les parties ne concorderont pas.

1. L'hôte choisit l'ensemble de mods et clique sur **Partager** : l'ordre de chargement de l'ensemble est copié sous
   forme de texte.
2. L'hôte envoie ce texte (Discord, messagerie...), avec les fichiers de mods qui manquent à certains.
3. Chaque ami ajoute les fichiers de mods manquants, puis clique sur **Importer un ordre de chargement…** et colle le
   texte : un nouvel ensemble de mods avec les mêmes mods dans le même ordre.
4. Tout le monde appuie sur **Jouer**, et l'hôte prépare la partie comme d'habitude.

> [!TIP]
> Le texte a le même format que celui que RUSE-Mod-Manager copie et lit, donc les amis qui l'utilisent peuvent aussi
> se joindre à vous.

**Bientôt :** des codes pour rejoindre, un code court qui vérifie que tout le monde a exactement les mêmes mods avant
le début de la partie.
