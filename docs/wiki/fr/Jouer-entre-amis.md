# Jouer entre amis

> **Pour :** les joueurs · **Il vous faut :** RUSE Launcher, et les mêmes mods que vos amis · **Durée :** 5 minutes

Chaque joueur a besoin des **mêmes mods dans le même ordre**, sinon les parties ne concorderont pas.

1. L'hôte choisit l'ensemble de mods et clique sur **Partager** : l'ordre de chargement de l'ensemble est copié sous
   forme de texte.
2. L'hôte envoie ce texte (Discord, messagerie...), avec les fichiers de mods qui manquent à certains.
3. Chaque ami ajoute les fichiers de mods manquants, puis clique sur **Importer un ordre de chargement…** et colle le
   texte : un nouvel ensemble de mods avec les mêmes mods dans le même ordre.
4. Tout le monde appuie sur **Jouer**, et l'hôte prépare la partie comme d'habitude.

> [!TIP]
> Le texte a le même format que celui que RUSE-Mod-Manager copie et lit, donc les amis qui l'utilisent peuvent aussi
> se joindre à vous.

## Vérifier que vous avez le même jeu : les codes de partie

Un **code de partie** est un code court fait à partir de votre jeu moddé : le même code veut dire le même jeu (la même
version du jeu, les mêmes mods et les mêmes versions de mods). Comparez vos codes avant une partie, et vous saurez
qu'elle ne se désynchronisera pas.

1. Appuyez une fois sur **Jouer** avec l'ensemble de mods : le code vient avec la copie moddée.
2. Cliquez sur **Code de partie** en bas du Launcher. La fenêtre **RUSE Guard : votre code de partie** montre le vôtre :
   **Copier**, puis envoyez-le à ceux avec qui vous jouez.
3. Collez le code d'un ami dans **Collez le code d'un ami** et cliquez sur **Comparer** : « Même jeu : vous pouvez jouer
   ensemble. », ou « Pas le même jeu. » avec ce qui diffère.

Bon à savoir :

- Le code change quand vos mods changent : renvoyez-le après un changement.
- « Pas de code : ces mods ne changent pas le jeu, n'importe qui peut jouer avec vous. »
- Un ensemble avec un mod de triche ou un outil de test ne joue en multijoueur et en coopération qu'avec des joueurs qui
  ont le même code, et quitte toute autre partie au bout de quelques secondes.
- **Vérifier chaque fichier de la copie** vérifie que votre copie moddée est exactement telle qu'elle a été construite.
