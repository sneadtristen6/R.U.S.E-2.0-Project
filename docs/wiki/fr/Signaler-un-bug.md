# Signaler un bug

> **Il vous faut :** un compte GitHub gratuit · **Durée :** 5 minutes

## Depuis l'application (le plus rapide)

- **RUSE Studio :** Réglages > Aide et communauté > **Signaler un problème**, ou **Signaler** à côté d'un message
  d'erreur.
- **RUSE Launcher :** **Signaler un problème** dans la barre du bas.

Votre navigateur ouvre un nouveau rapport de bug où l'application et sa version sont déjà remplies (et l'erreur, si
vous avez appuyé sur Signaler à côté de l'une d'elles). Rien n'est envoyé tant que vous ne le publiez pas vous-même.

## Depuis le site

[Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) > **🐞 Bug reports** > **New
discussion**. Un court formulaire demande les détails.

## Ce qui nous aide à le corriger

1. **L'application et sa version** (les Réglages l'affichent).
2. **Ce que vous avez fait**, étape par étape, pour que nous puissions faire de même.
3. **Ce qui s'est passé**, et ce que vous attendiez.
4. **Le message**, s'il y en avait un : sélectionnez-le, copiez-le, collez-le.
5. **Une capture d'écran** : faites-la glisser dans le message.

> [!WARNING]
> Les chemins de vos fichiers contiennent votre nom d'utilisateur Windows (`C:\Users\<you>\...`). Écrivez plutôt
> `%LOCALAPPDATA%\...`. Les boutons Signaler des applications le font pour vous.
