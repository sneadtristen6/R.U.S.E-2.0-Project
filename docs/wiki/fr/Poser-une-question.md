# Poser une question

Vous ne l'avez pas trouvé dans le manuel ? Demandez dans
[Discussions > ❓ Help](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) (il faut un compte GitHub
gratuit pour publier).

1. Cherchez d'abord dans Help : quelqu'un a peut-être déjà posé la question.
2. Dites ce que vous essayez de faire, ce que vous avez essayé, et quelle application et quelle version vous utilisez.
3. Quand une réponse règle le problème, cliquez sur **Mark as answer**, pour que la personne suivante la trouve.

## Questions résolues

Les questions qui reviennent plus d'une fois sont rassemblées ici, avec un lien vers l'endroit où on y a répondu.

*Aucune pour l'instant : soyez le premier à demander.*
