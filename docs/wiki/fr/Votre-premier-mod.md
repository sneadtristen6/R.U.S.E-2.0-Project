# Votre premier mod

> **Pour :** les nouveaux moddeurs · **Il vous faut :** R.U.S.E. sur Steam · **Durée :** 10 minutes

Un guide complet : installer le Studio, faire un mod où le M4 Sherman coûte 1 $, et le voir en jeu.

## 1. Installer RUSE Studio

1. Téléchargez l'installateur depuis les [versions du Studio](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=studio)
   et lancez-le (« Windows a protégé votre ordinateur » : **Informations complémentaires**, **Exécuter quand même**).
2. Le premier démarrage lit les fichiers du jeu dans un index : une minute ou deux, une fois par mise à jour du jeu.

## 2. Créer un mod

Le Studio s'ouvre sur **Que voulez-vous faire ?** : **Continuer un mod**, **Commencer un nouveau mod**, ou **Passer**
(cochez **Toujours passer cet écran** pour aller directement aux onglets dès lors ; les Réglages le font revenir).

1. Cliquez sur **Commencer un nouveau mod**.
2. Tapez un nom, par exemple `cheap-sherman` (le nom que les joueurs voient dans le Launcher), et cliquez sur
   **Créer**. Le Studio s'ouvre sur votre nouveau mod.

Déjà dans le Studio ? Le menu **Mod** de l'en-tête a aussi **Nouveau mod…** : tapez un nom et cliquez sur **Créer**.

Désormais, tout ce que vous changez est enregistré dans ce mod, jamais dans le jeu.

## 3. Modifier le Sherman

1. Ouvrez l'onglet **Unités** et tapez `sherman` dans la zone de recherche.
2. Cliquez sur **M4 Sherman**.
3. Trouvez son prix et tapez `1`. C'est enregistré tout de suite, et l'ancienne valeur s'affiche à côté. **Annuler**
   la remet.

## 4. Le tester

1. Cliquez sur **Tester en jeu** (dans l'en-tête). Le Studio vérifie le mod, construit la copie moddée (une pour tout le PC, `RUSE-Instances\Modded game` sur le disque du jeu, ou le dossier choisi dans les Réglages) et lance R.U.S.E.
2. Dans le menu principal du jeu, cliquez sur **BATAILLES** (une partie libre contre l'ordinateur), choisissez
   n'importe quelle carte, jouez les USA et ouvrez la **BASE DE BLINDES** : le Sherman coûte 1 $.

> [!TIP]
> Si une barre rouge apparaît à la place sous l'en-tête, la vérification du mod a trouvé une erreur dans un fichier de
> votre mod. Voir [[Quand quelque chose ne va pas|Quand-quelque-chose-ne-va-pas]].
