# Touches de la vue carte

Les touches fonctionnent quand la vue carte du Studio est ouverte et qu'aucune zone de texte n'a le focus. Changez-en
n'importe laquelle dans **Réglages > Touches de la vue carte** (cliquez sur une touche, puis appuyez sur celle que vous
voulez). Une touche qu'une autre action a déjà demande d'abord : **Échanger** (les deux échangent leurs touches),
**La prendre** (l'autre reste sans touche jusqu'à ce que vous lui en donniez une) ou **Annuler**. Les touches suivent
leur place sur le clavier : W A S D sont donc les mêmes touches sur un clavier AZERTY.

| Touche | Action |
|---|---|
| **W A S D** ou les flèches | déplacer la vue (maintenez **Shift** pour aller trois fois plus vite) |
| **Q** / **E** | tourner autour du point que vous regardez |
| **R** / **F** | zoomer / dézoomer |
| **1** à **0** | choisir l'un des dix premiers pinceaux |
| **B** | pinceau activé ou désactivé |
| **P** | placement activé ou désactivé |
| **[** / **]** | taille en moins / en plus (pinceaux et objets placés) |
| **-** / **=** | force en moins / en plus (pinceaux), ou rotation (objets placés) |
| **Esc** | revenir à la vue libre ; abandonner une ligne, une grille ou un tracé commencé ; ne plus rien choisir |
| **Ctrl+Z** | annuler le dernier trait, objet placé, déplacement ou suppression |
| **Ctrl+Y** ou **Ctrl+Shift+Z** | rétablir ce qu'Annuler a repris |
| **Shift+clic** | ajouter à ce qui est choisi (**Sélection**) |
| **Delete** | supprimer ce qui est choisi |
| **Enter** | terminer un tracé ou une route libre |

## Disposer les panneaux

Le panneau de la carte (en haut à gauche) et les outils (en bas) se déplacent n'importe où : faites-les glisser par
leur poignée (⠿). La flèche à côté replie un panneau (le panneau de la carte jusqu'à son titre, les outils jusqu'à leur
barre). Double-cliquez sur une poignée pour remettre ce panneau à sa place. Votre disposition est conservée.

## À la souris

| Souris | Action |
|---|---|
| glisser | tourner la vue (quand un outil est actif : utiliser l'outil) |
| glisser avec le bouton du milieu | tourner la vue (même avec un outil actif) |
| glisser avec le bouton droit | déplacer la vue |
| molette | zoomer |
