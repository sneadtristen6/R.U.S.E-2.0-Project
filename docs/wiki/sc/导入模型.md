# 导入模型

> **适用：** 模组作者 · **你需要：** RUSE Studio 0.9.6 或更新版本、一个模组，以及一个 3D 模型（.3ds、.glb 或 .gltf）
> · **用时：** 几分钟

给新单位一个它自己的 3D 模型，来自 Blender 或其他任何 3D 工具。
[M1 Abrams 模组](https://github.com/sneadtristen6/Ruse-Mods) 就是这样做出来的：这是第一个从另一个 3D 程序导入 R.U.S.E. 的模型，
已在游戏中看到。

模型也可以用在新建筑上，替换它外观中的一个部件（参见
[[建筑与建造菜单|建筑与建造菜单]]），或者作为你自己的岩石、物件、灌木或树木放到你的地图上
（参见 [[放置建筑和树木|放置建筑和树木]]）。两者都是 Studio 0.9.8.8，已在游戏中看到。

在单位页面上，这些都在 **外观与动作** 里：**导入模型…** 是 **模型** 行的按钮，模型的其余选项（大小、**移动**）在该行的 **更多** 里。模型的动画如何播放在 **声音与动画** 行的 **更多** 里。小队的页面则从小队卡片和它的士兵开始：见 [[修改小队|修改小队]]。

## 1. 准备一个模型

一个带图片（.tga 或 .png）的 **.3ds**，或者一个 **.glb** 或 **.gltf**（图片在它里面：PNG、JPG 或 WebP）。
导入器无法读取的模型（压缩网格、KTX2 图片）会说明这一点，以及如何在 Blender 中修复。

- **从 Blender：** File > Export > glTF 2.0，格式选 **glTF Binary (.glb)**。
- **从免费模型网站：** 很多坦克是 .3ds 格式，附带一个装着 .tga 图片的文件夹。保持文件夹原样：
  Studio 会在 .3ds 旁边或上一级文件夹中找到图片，即使它们用的是 .3ds 文件采用的缩短名称
  （`MAIN_DEF.TGA` 对应 `Main_Defuse.tga`）。
- 分享你的模组之前，先检查模型的许可证，并在你模组的 README 中为它的作者署名。

**有帮助的做法：** 按部件是什么来给部件命名。Studio 会让名称中带 *turret*（或 *tourelle*、
*tower*）的部件随炮塔转动，带 *barrel*、*gun* 或 *cannon* 的部件也一样。放在炮塔上的部件同样随它转动。
其余部分都随车体移动。炮管应该笔直朝前。

Abrams 的例子：**ags 制作的 "Tank Abrams"**，可在
[downloadfree3d.com](https://downloadfree3d.com/3d-models/vehicles/tank/tank-abrams/) 免费获取（一个 .3ds 和它的 .tga 图片，
部件名为 Main_Body、Main_Turre、Main_Barre……）。

## 2. 制作单位

在 **单位** 标签页中，点击顶部的 **新单位（导入模型）**，然后选择要作为起点的单位（坦克就选坦克：
Abrams 选的是 Sherman）。给它取个名字并点击 **创建**：新单位的页面会在
**导入模型…** 处打开。新单位的模型会像这个单位一样转动和行驶。游戏单位的页面也有同样的入口：**外观与动作** 的 **模型** 行里的 **以此单位制作新单位…**。（Studio 0.9.6 还没有这两个按钮：打开单位，
在它的页面上选择 **新单位…**。）

## 3. 导入

在新单位的页面上，**外观与动作** 的 **模型** 行里：

1. 点击 **更多**，设置 **大小**：它的长度与被复制单位长度之比。**1** 表示一样长；M1 Abrams 对 Sherman 是 **1.36**
   （按它们的真实长度）。
2. 点击 **导入模型…**（该行的按钮）并选择 .3ds 或 .glb。

Studio 会让它贴合单位：朝前（炮管所指的方向）、它的长度、放在被复制单位所在的位置、炮塔在你的模型上它所在的位置转动、立在地面上。它的图片会变成它自己的纹理。页面会以 3D 显示它，并标出哪些部件随炮塔转动。如果某张图片没找到，页面会说明是哪一张：把图片放到模型旁边，再导入一次。

它会保存到你的模组中，路径为 `files/models/<the unit's name>.glb`。**使用所复制单位的模型** 会再把它拿掉。

**它在你电脑上的位置：** **模型** 行的 **更多** 一开始就显示它（小队的页面在士兵下方的 **更多选项** 里显示）：完整路径 `Documents\RUSE 2.0\Mods\<你的模组>\files\models\<单位名>.glb`，以及打开这个文件夹的 **在文件夹中显示**。单位还没有自己的模型时，它会说明文件将保存在哪里。有自己模型副本的单位（**给它一份自己的模型副本**，或小队的 **自定义制服**）保存在同一个文件夹中，名为 `<单位名>.copy.toml`，涂装放在同名文件夹里。

**之后调整大小：** 大小框下方的滑块从 **极小** 到 **巨大**（0.05 到 20），上面标有 **游戏尺寸**（1），
时代单位还标有 **真实尺寸**；点击 **调整尺寸**，模型就会从它自己的文件重新贴合。如果有好几架新飞机（或地面单位），点一下就能把它们全部调整。游戏在加载时读取模型，所以新的大小从下一次构建开始显示。

**它放在哪里：** 新模型会放在它所复制的单位的正中，所以大多数模型在这里什么都不用做。如果你的模型位置不对，使用 **模型** 行 **更多** 里大小下方的 **移动**。它有三个数字：**向前**、**向右** 和 **向上**，以游戏单位计（页面会以这种单位说明被复制的单位有多长）。负数表示反方向，0, 0, 0 会把它放回贴合时的位置。点击 **移动**，模型就会从它自己的文件重新贴合，并移开这么远；它的炮塔和螺旋桨也随之移动，所以仍在正确的位置转动。在 3D 视图中，蓝色圆环是被复制单位所在的位置，圆环上的标记是前方。调整大小后，移动仍然保留。绑定在单位自身骨骼上的模型（士兵、炮组）会留在它的骨骼所在的位置：这种模型请在 Blender 中移动。Studio 0.9.8.17 之前导入的模型会保留原来的位置（它的炮塔在被复制单位的炮塔上），即使调整了大小也是如此，直到你重新导入或移动它；时代单位的模型也保留各自原来的位置。

**飞机：** 从 Studio 在 Blender 中打开、然后取回的飞机会朝向前方，并把螺旋桨保留在你的模型上它们所在的位置，模型有几个就保留几个，无论所复制的飞机原来是什么样：在地面上是桨叶，在空中是旋转的圆盘。已在游戏中看到。来自其他任何地方的模型会保留它画出的螺旋桨，静止不动：导入器还分辨不出它的哪些部件是螺旋桨。在 3D 视图中，飞机的圆盘显示为半透明，就像游戏绘制旋转螺旋桨的方式一样。

**士兵、炮组和更多飞机：** 士兵、炮组，以及 Studio 以前无法为其贴合模型的飞机（例如 P-47），只要模型绑定在单位自身的骨骼上，也都能有自己的模型：比如从 Studio 在 Blender 中打开、并在那里修改过的某个游戏模型。它会原样放到这些骨骼上，不移动也不缩放；小队里用同一个模型绘制的其他士兵也会穿上它。已在游戏中用一个步枪小队、一个炮组和 P-47 看到。游戏用他自己的模型绘制的重武器士兵（美军步枪小队的火箭筒兵）会保留那个模型，直到你在小队页面上他自己的那一行（下面）给他一个模型。

**你的玩家：** 含有用 Studio 0.9.8.17 或更新版本导入的模型的模组，需要 Launcher 0.4.8.17 或更新版本：旧版本会给模型套用被复制单位的骨架，导致它的炮塔绕着错误的点转动。0.4.8.17 是必需的更新，所以 Launcher 会自动安装它。

## 一步步做你自己的士兵

对于小队（步枪兵、伞兵、任何步兵），Studio 会和你一起完成 Blender 部分。小队的页面从小队卡片和每个士兵的一行开始；[[修改小队|修改小队]] 会逐一介绍。

1. **创建小队**：像上面第 2 步那样，从一个小队开始（比如美军步枪小队）。
2. **在 Blender 中打开小队。** 在小队卡片上点击 **在 Blender 中修改小队**。Blender 会打开小队的所有士兵，并排站好，每人都在自己的骨骼上，每人都有自己的一份图片副本。还没有 Blender？**获取 Blender（免费）** 会安装它；**选择 Blender…** 可以告诉 Studio 它在哪里。
3. **修改一个士兵，或把你自己的模型放到他的骨骼上。** 要修改，就在那里编辑他。要用你自己的模型：用 **File > Import** 把它导入同一场景并放在士兵身上；点击你的模型，**Shift+点击** 他的骨骼，然后按 **Ctrl+P > With Automatic Weights**。如果不保留游戏的士兵，就删除他。
4. **发送。** 点击 Blender 顶部的 **发送到 R.U.S.E. Studio**。
5. **带回。** 在小队卡片上点击 **带回我的修改**。每个士兵只得到对他做的修改，你没动过的士兵保持原样：卡片会说明谁变了、谁没变。**在游戏中测试** 即可看到。

值得知道：
- 美军步枪小队的四名步枪兵在 Blender 中是一个人物：游戏给他们的是同一个模型，所以你对它做的修改，四个人都会有。火箭筒兵是单独的人物。
- 你的 Blender 文件保存在模组文件夹里：`Documents\RUSE 2.0\Mods\<你的模组>\blender\<单位名>\squad\`。分享模组时不会打包进去。士兵下方的 **更多选项** 会说明它们在哪里，它的 **在文件夹中显示** 会打开它们所在的文件夹。
- 带回修改之前就关掉了 Blender？大按钮下面的小按钮 **带回我的修改** 会取你最后发送的内容。
- 如果模型的一些点没有骨骼（Blender 的自动权重会漏掉几个），页面会显示数量：它们只随士兵的髋部移动。在 **Weight Paint** 中把它们画到骨骼上，再发送一次。
- 有 **自定义制服** 的小队：你的模型会取代制服（它的涂装留在模组中）；当每个士兵都恢复游戏中的外观后（他那一行的 **恢复游戏中的外观**），制服会回来。
- 已经有在游戏士兵骨骼上做好的 .glb？那个士兵那一行的 **导入模型…** 会原样接收它。
- 你的模组把每个士兵的模型保存在 `files\models\` 中：步枪兵的为 `<单位名>.glb`，重武器士兵的为 `<单位名>@bazooka.glb`。**更多选项** 会说明每个模型保存在哪里（或将保存在哪里），以及小队的其他人物用它绘制：倒下的士兵，以及远处看到的小人（美军步枪小队的用火箭筒兵的模型绘制）。
- 整个小队在同一个 Blender 中、每个士兵单独带回：这是新功能，还没有在游戏中试过。

## 它的动画：每个动作播放哪个

带自己骨骼的模型（一匹马、一匹马和它的骑手、任何生物）会把自己的动画一起带进来。在单位页面上，**它的动画**显示单位在游戏
中做每件事时播放什么：

- **原地站立**、**行走**和**奔跑**排在最前：这是模型最少需要的。如果其中某个没有自己的动画，页面会说明，并显示它改为播放
  什么。
- 每个动作都是模型动画的一个列表。选一个，或保持**最接近的**：这时它播放模型里最接近的那个，列表会显示是哪个。最接近的依次
  是：以该动作命名的动画（stand 或 idle、walk、run 或 gallop、fire、death……），否则是最接近的动作所播放的（走路播放跑步，
  跑步播放走路，然后是站立；开火播放瞄准，然后是站立；任何阵亡播放普通阵亡）。构建遵循同一规则：页面说的就是游戏播放的。
- 名字以 t_ 或 b_ 开头的动画（hr_t_fire、hr_b_run）只在身体的上半身或下半身播放：骑手的在上，马的在下。
- **其他所有动作**列出其余部分，按种类：原地、移动、瞄准与开火、重武器、被击中、阵亡。
- **长途移动时**，游戏会让小队坐上卡车。有自己动画的单位改为自己移动，播放在那里选的动画（保持“最接近的”时是它的跑步），
  速度和它的卡车一样。选**坐自己的卡车**可保留卡车。

**副本保留动画：**从有自己动画的单位复制出的单位播放相同的动画。若只想为它修改某个动画，请在它的 **声音与动画** 行点击 **在 RUSE Decoy 中修改**，然后选择 **仅此单位**。

用这种方法在 Studio 中做的 Horse Squad 已在游戏中运行（2026 年 11 月）。
## 带有自己骨骼和动画的模型

一匹马、一匹带骑手的马、任何生物：带有自己骨骼的模型可以连同它的动画一起放到小队上。

1. **在 Blender 中制作**：把你的模型放在带有你自己骨骼（名称随意）的骨架上，并为每个动画做一个动作。按动作表现的内容命名：至少要有 **stand**（或 **idle**）、**walk** 和 **run**；**death**、**fire**、**reload**、**hit**、**crouch**、**aim**、**look**、**flee** 和 **grenade** 也能识别。
2. **导出**：**File > Export > glTF 2.0**，格式选 **glTF Binary (.glb)**，并勾选 **Animation**。
3. **制作小队**，与上面的第 2 步相同。在它的页面上，点击 **每个士兵** 下步枪兵那一行的 **导入模型…** 并选择你的 .glb。Studio 会看出它的骨骼不是士兵的，并连同它自己的骨骼和所有动画一起导入。页面会显示它有多少根骨骼、每个动画及其时长，以及小队有多少个动作播放它。
4. **在游戏中测试** 即可看到。

须知：
- 小队的每个动作都会播放以它命名的动画。没有任何动画以其命名的动作暂时没有动画：页面会显示数量。
- 在 Blender 中改过了？重新导入即可：只要文件中仍有同名动画，每个动作都保留它的动画。
- 你的模组会保存模型和每个动画：`files\models\<单位名称>.glb`，每个动画保存为 `files\anim\own\<单位名称>\<动画名称>.baf`。
- 那一行的 **恢复游戏中的外观** 会再次移除该模型及其动画。
- 有重武器士兵的小队：用他那一行的 **导入模型…** 给他自己的马和骑手，做在与步枪兵模型相同的骨骼上，他就会播放步枪兵的动画。在其他骨骼上，他播放所复制小队里的动画，页面会提醒你：这可能让游戏停止。移除步枪兵的模型时，他的模型也会一起移除。
- 用这种方法在 Studio 中做的 Horse Squad 已在游戏中运行（2026 年 11 月）；用这种方式做的其他东西还没有在游戏中试过。

## 他的动画，在 Blender 中修改

动画在 RUSE Decoy 中修改。在单位的页面上，点击 **声音与动画** 一行中的 **在 RUSE Decoy 中修改**，再点击它的动画下面的 **在 Blender 中修改它的动画**。Blender 会打开这个单位以及它播放的每个动画（站立、行走、奔跑、开火、死亡…），每个都以它在其中做的事命名，后面跟着游戏里的名字：`奔跑, 瞄准 (fusilier_course_vise)`。

1. **选一个。** Blender 底部的 Action Editor 列出了它们：选中要修改的那个。按 **Space** 播放。
2. **摆骨骼姿势。** 点击一根骨骼，按 **Ctrl+Tab** 进入 Pose Mode，**R** 旋转它（**G** 移动），然后按 **I** 在这一帧记下姿势。在你修改的每一帧都这样做：Blender 会自己从一个记下的姿势过渡到下一个。
3. **发送。** 点击 **发送到 R.U.S.E. Studio**：每个动画都会发出，改了没改都一样。
4. **带回来。** 在 RUSE Decoy 中点击 **带回我的修改**。它会说明哪些动画改动后回来了：它们现在是这个单位专属的，RUSE Decoy 在 **仅此单位** 下显示它们。其他每个单位，以及你没碰过的每个动画，都保持游戏原样。

小贴士：
- 游戏以每秒 30 帧播放动画，Blender 也按这个速度打开它们。动画打开时的长度和游戏里一样；在 Blender 中把它加长或缩短，它就以那个长度回来。
- 在 Blender 中做的动画（某个动画的副本，改了名）也会回来，但还没有任何动作播放它：Studio 会说明。改名的动画算作新的，原来那个照旧播放。
- 士兵身上没有任何点依附的骨骼（枪口的点、第二件武器的手）可以做动画，但 Blender 的自动权重不会用到它们。
- 只有你的模组中做的新单位才能有自己的动画：对于游戏自带的单位，请先以它制作一个新单位。
- 拥有自己骨骼的模型（马，任何生物）会以各自的名字送出它自己的动画。你修改的那个会放回原来的位置：每个播放它的动作都会播放修改后的版本，单位的 **声音与动画** 一行会把它和其他动画一起列出。
- 已用 Blender 4.5 和 Studio 自己的测试检查；还没有在游戏中试过。

## 4. 它的卡片，然后测试

旋转 3D 视图，直到新模型在虚线框里看起来合适，然后点击 **将此视角用作卡片**（参见
[[编辑单位|编辑单位]]）。然后点 **在游戏中测试**：在一场战斗中，单位就在它的工厂里。

## 在 Blender 中修改它

`files/models/<the unit's name>.glb` 能像任何 .glb 一样在 Blender 中打开。保留两个对象名称（车体是 `chassis`，
炮塔是 `tourelle_01`），然后导出并覆盖同一个文件（glTF Binary）：下一次构建就会使用它。

单位页面上的 **在 Blender 中打开** 会像游戏那样给每个部件的骨骼命名，所以游戏自带的坦克在
Blender 中打开再导入回来，炮塔仍会转动（Studio 0.9.8.8；之前导出的模型保留旧名称：请在
Blender 中重新打开它）。

**放错位置的模型**（Studio 0.9.8.7 及更早版本，在用 Panther 和另外 85 个 Studio 读错炮塔的单位制作的新单位上）：
在该单位上再次使用 **导入模型…**，它就会落在炮塔上。

## 尚在早期

- 履带和车轮还不会转动：它们随车体移动。
- 炮口火焰和残骸用的是被复制单位的。
- 图片最大做到 1024 宽，和游戏自己的单位图片一样。
- 已在游戏中用游戏自己的模型试过（Sherman、两架飞机、一个步枪小队、一个炮组）：还没有用来自其他地方的模型、另一辆带炮塔的坦克、能转一整圈的炮塔，或复制没有螺旋桨的单位的飞机试过。
- 从牵引火炮、FCM F1、Puma、半履带车、Bren Carrier、伞兵运输机、某些碉堡等单位复制的新单位，也能用来自其他地方的模型，不只是绑定在它骨骼上的模型；模型的绘制方式和那个单位一样。还没有在游戏中试过。

在命令行中：`ruse import-model "Tank Abrams.3ds" --like coc_shermanm4_tir --unit
Descriptor_Unit_R2_M1_Abrams --size 1.36 --mod <your mod folder>`。加上 `--move`，它就会像 Studio 那样贴合：`--move 50 0 -10` 会把它从贴合的位置向前移 50、向下移 10（向前、向右、向上），`--move 0 0 0` 则让它留在那里。不加 `--move`，命令仍按旧方式贴合：它的炮塔对准被复制单位的炮塔。
