# 塑造地形

> **适合：** 模组作者 · **你需要：** RUSE Studio 0.7.2 和一个模组 · **已在游戏中验证：** 单位可以在修改过的
> 地面上行驶，并在那里接受命令

## 打开地图

1. **地图** 标签页，在左侧选择地图（**«** 按钮可以把列表折叠起来，腾出更多空间）。
2. 四处看看：拖动来转动，右键拖动来移动，滚轮来缩放（按键：[[地图视图按键|地图视图按键]]）。
3. 在底部的工具栏中点击 **地形与水**。它的工具会在工具栏上方打开，最先显示 **地形** 标签页。

## 工具

| 工具 | 用途 | 用法 |
|---|---|---|
| **山丘** | 一座圆形的山丘 | 单击一次 |
| **抬高** / **降低** | 一点一点地堆高或削低 | 拖动 |
| **弹坑** | 一个带边缘的弹坑 | 单击一次 |
| **高台** | 顶部平坦的山丘 | 单击一次 |
| **压平** | 把起伏拉向同一高度 | 拖动 |
| **整平** | 按你开始处的高度把地面刷平 | 拖动 |
| **平滑** | 柔化尖锐的边缘 | 拖动 |
| **斜坡** | 一段均匀的坡，比如通向高台 | 点击起点，再点击终点 |

**大小** 和 **强度** 是右侧的滑块（按键 **[ ]** 和 **- =**）。

## 水

点击 **水** 标签页（在 **地形与水** 中）：

- **水** 会淹没某个水位以下的地面：水位是你开始拖动处的高度，再加上强度。沿着山谷拖动可以做出河流，
  拖进洼地可以做出湖泊。
- **排干** 把水恢复到地图的基准水位：那里的河流和湖泊会干涸。

## 用纹理绘制地面（Studio 0.9.8.5）

**仍有缺陷，请自行斟酌使用。** 在底部的工具栏中点击 **地图绘制**，然后点 **纹理**。选择纹理的来源，
点击一个纹理，然后在地面上拖动：

- **游戏纹理：** 游戏自带地图的地面纹理（草地、田地、沙地、雪地、岩石、道路……），按组排列，可以搜索。
  它们从你的游戏中读取；它们的任何内容都不会放进你的模组。
- **取自地图：** 选择一张地图，点击上面的一个点：那里 320 米见方的地面就成为你的纹理。
- **你的图片：** **添加图片…** 会把你自己的一张图片保存在你的模组中（`files/ground`）。
- **在线（免费）：** Poly Haven 和 ambientCG 的纹理（CC0）以及美国的航拍照片（公共领域）。点一下就会把那一张图片
  下载到你的模组中，并附上署名。尚未尝试。
- **本地图：** 从你选的位置复制本地图自己的地面。

**大小** 让它铺得更大或更小（四分之一到 16 倍）。使用游戏纹理时，**近景游戏细节** 还会在你绘制的内容上
铺上游戏自己的该纹理的贴花。尚未在游戏中看到。

## 撤销和重新开始

**撤销**（或 **Ctrl+Z**）撤回上一笔；**重新开始** 撤回这张地图上的所有笔画。

## 在游戏中查看

点 **在游戏中测试**，然后在游戏主菜单中点击 **战斗** 并选择那张地图。Studio 底部的消息会告诉你是哪一张。

> [!TIP]
> 陡峭的悬崖看起来会参差不齐：游戏的地面是由三角形组成的网格，尖锐的边缘会落在三角形之间。
> 宽阔、柔和的形状效果最好。
