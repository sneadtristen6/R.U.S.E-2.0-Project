# 提问

在手册里没找到？到
[Discussions > ❓ Help](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) 提问（发帖需要一个免费的 GitHub
账号）。

1. 先在 Help 里搜索：也许已经有人问过了。
2. 说清楚你想做什么、试过什么，以及你用的是哪个应用、哪个版本。
3. 某个回答解决了问题时，点击 **Mark as answer**，让下一个人也能找到它。

## 已回答的问题

被问到不止一次的问题会收集在这里，并附上回答它们的地方的链接。

*暂时还没有：来做第一个提问的人吧。*
