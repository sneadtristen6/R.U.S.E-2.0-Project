# 其他时代的单位

> **适用：** 模组作者 · **你需要：** RUSE Studio 0.9.8.2 或更新版本，以及一个模组 · **用时：** 每个单位一两分钟

从一战到今天的 366 个单位，就在 **单位** 标签页中游戏自己的单位旁边：一战、二战+、冷战和现代的坦克和飞机，
全在一个游戏里。每个都是另一位作者的免费 3D 模型（CC BY），已经适配好游戏，加上了它所属国家的标志，并且已署名。
在你添加之前，它们都不在你的模组里。

## 获取某个时代的单位

1. 在 **单位** 标签页中，在种类上方选择一个时代：**一战**、**二战+**、**冷战** 或 **现代**
   （**原版** 是游戏自己的单位，也就是一直以来的那个列表）。
2. 第一次时，Studio 会说明这个时代有多少单位、有多大，并提供 **下载一战单位**（或该时代的相应按钮）。
   它会从项目的 GitHub 下载这些单位，在使用前检查每个文件，然后把它们列出来。

   | 时代 | 单位 | 下载 |
   |---|---|---|
   | 一战 | 61 | 232 MB |
   | 二战+ | 32 | 198 MB |
   | 冷战 | 149 | 996 MB |
   | 现代 | 124 | 709 MB |

3. 已下载的时代在有更新的单位发布时会自己更新：Studio 会告诉你，并去获取它们。

时代单位的筛选方式和游戏单位一样：种类（地面或空中）、国家（也包括中国）、类型，以及搜索框。

## 把一个加入你的模组

1. 点击一个单位。它的页面会显示它的模型图片和作者：**模型作者** 和作者的名字、许可，以及一个指向作者分享它的地方的链接。
2. 填写表单：
   - **新单位的名称**（在每种语言中显示）。
   - **基于**：它的数值所基于的游戏单位（速度、装甲、武器、玩起来的方式）。推荐的那个排在第一；
     可以选择同种类的任何单位。
   - **价格**（每个战斗日期）。
   - **大小**：1 表示和起始单位一样长。推荐值是它的真实大小（它的真实宽度，飞机则是翼展，
     按游戏自己的比例）；可以是 0.05 到 20 之间的任何值。拖动滑块，或者点击它上面的一个命名点：
     **极小**、**游戏尺寸**（1：和起始单位一样长，也就是游戏绘制这类单位的大小）、**真实尺寸**
     和 **巨大**。按真实尺寸的现代飞机比游戏中的二战飞机大得多（一架 J-16 和一架
     Lancaster 一样长）。
   - **生产菜单**：国家，以及购买它的工厂。
   - **研究自**：它从哪个单位研究而来，或者 **无：开局即可购买**，并带有它的 **研究价格**
     和 **研究时间**（时间可以按秒或分钟输入：用旁边的选择器）。
3. 点击 **加入我的模组**。它现在是你模组中的一个新单位了：
   点 **打开其页面** 就能像修改任何单位一样修改它的任何数值、它的模型或它的卡片。**从我的模组中移除** 会再把它删除。

## 之后修改它的大小

在单位的页面上，**自己的模型** 有同样的滑块：选一个大小，然后点击 **调整尺寸**（模型会从它自己的文件重新贴合，
不需要选择任何东西）。**我的模组的所有飞机**（或地面单位）会一次处理所有这些单位：**游戏尺寸**、
**真实尺寸**、**变小**（五分之一）或 **变大**（四分之一）。
游戏在加载时读取单位的模型，所以玩的时候大小不会改变：新的大小从下一次构建（在游戏中测试）开始显示。

## 研究链

一个单位可以从它所属国家建造菜单中的任何单位研究而来，你模组自己的时代单位也可以：添加一辆冷战坦克，
然后添加一辆从它研究而来的现代坦克。一战和二战+ 的单位可以直接购买；
冷战和现代的单位一开始会设为从一个合适的单位研究而来（表单会说明它推荐哪一个，以及原因）。

当你拿掉一个有其他单位从它研究而来的单位时，**设置 > 研究** 决定会发生什么：

- **先提醒我**（默认）：Studio 会列出从它研究而来的单位，并提供 **仍然移除**。
- **拒绝**：这个单位保留，消息会说明如何先修改其他单位。
- **重新关联**：每个单位改为从被移除单位自己的上级单位研究而来，使用它自己的价格和时间
  （或者变成开局即可购买）。

如果一个单位仍然从一个已经不存在的单位研究而来，它的 **升级与研究** 框和检查栏中都会说明，
构建也会停在它上面，直到你另选一个单位，或者选择无。

## 通用骑兵小队

**二战+** 里也有 **通用骑兵小队**，作者是 sneadtristen6：步枪兵和一名重武器士兵，各骑一匹自己的马。它不需要下载任何东西，
所以无论你是否下载了二战+ 的单位，它都在那里。和时代单位一样，你添加之前它不在你的模组里。

1. 点击它。它的页面写着谁做了它，以及添加时会做什么。
2. 像时代单位一样填写表单：名称、价格、**生产菜单**、**组**，以及它的 **研究自** 单位。**基于** 始终是游戏里的 G.I.
   小队（美军步枪兵）：它的马和骑手是为这个小队的士兵制作的。
3. 点击 **加入我的模组**。Studio 会在你的电脑上用你自己的游戏副本制作它的马和骑手，制作单位，然后给它的步枪兵和重武器
   士兵配上马。每一步进行时都会显示在按钮下方，并附上已用时间。如果你的游戏给不出所需的东西，Studio 会说明原因，
   什么也不会添加。
4. 现在它是你模组的新单位：**打开其页面** 可像其他单位一样修改它的任何数值。**从模组中移除** 会把它连同两个模型及其
   动画一起移除。

它的作者 sneadtristen6 会写在你模组的 `CREDITS-era-units.md` 里，与时代单位的作者并列。

已在游戏中看到：用 **导入模型…** 在 G.I. 小队的副本上做出的、骑在马上的这些骑手。尚未在游戏中试过：从这个列表添加的通用骑兵小队。

## 署名

每个时代单位的作者都有署名：在它的页面上，以及你模组中的 `CREDITS-era-units.md` 里，这个文件由 Studio 在你添加单位时写入。
请把这个文件和你的模组放在一起：模型的许可要求这样做。完整的作者列表在
[时代单位发布页](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases/tag/era-units)。
