# 把一个国家改成另一个

> **适合：** 模组作者 · **你需要：** RUSE Studio 0.9.8.1 或更新版本和一个模组 · **用时：** 几分钟

**国家** 标签页给游戏七个国家中的一个换上新名称和新旗帜，把它变成另一个国家：比如用中国替代意大利。游戏仍然是七个国家：被修改的国家保留它在大厅中的位置、它的建造菜单，以及它的战役章节和行动。

## 名称和旗帜

1. 打开 **国家** 标签页，点击该国家旁边的 **修改…**。
2. **大厅中的名称**：大厅的国家列表对它的称呼，游戏的十种语言各有一个。保持不变的语言沿用游戏的名称。
3. **军队名称**：行动询问要带哪支军队时显示的它的军队名称。
4. **旗帜**：点 **选择图片…**，或把一张图片拖到框上。旗帜的任何图片都可以：它会被调整成游戏旗帜的样子，圆形的外形仍然是游戏的。**游戏原版旗帜** 会把它换回去。
5. 点击 **在游戏中测试** 查看效果。

**全部恢复** 会让该国家变回游戏原来的样子。

## 它的单位

它的单位照常在 **单位** 标签页中修改：**新单位…** 会把任意单位的副本放进它的建造菜单，
[[其他时代的单位|其他时代的单位]] 也可以加入。单位说的话在它的页面上的 **语音** 下（见
[[音乐与音效|音乐与音效]]）。

**一次处理它的所有单位**（在国家标签页上）：**隐藏 <nation> 的所有单位** 会把它们从它的建造菜单中拿掉（它的建筑保留），**重新显示** 会把它们放回去，你还可以一次用另一个国家某个时代的单位填满它的菜单（每个单位都已勾选，并选好了它的建筑；取消勾选任意一个，然后添加）。从被隐藏的单位研究而来的单位会变成开局就能购买，页面会说明是哪些。没有东西可建造的建筑会被点名，并提供让它重新拥有自己单位的方法。已在游戏中看到（意大利的单位被隐藏，中国的时代单位出现在它的菜单中）。

## 已在游戏中看到的

已看到（意大利改成中国）：大厅国家列表中的新名称、对局中玩家名称旁的新旗帜，没有崩溃。大厅自己的国家按钮是在游戏的菜单文件里绘制旗帜的，所以它仍然显示游戏的旗帜。尚未看到：加载画面和回放中的新旗帜。
