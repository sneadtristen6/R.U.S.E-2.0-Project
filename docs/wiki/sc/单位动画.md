# 单位动画

> **你需要：** RUSE Studio 0.9.8.20 或更新版本和一个模组；要在 Blender 中修改新单位的动画，还需要 Blender（免费） ·
> **用时：** 阅读约 10 分钟

单位的动作方式（站立、行走、奔跑、瞄准、射击、阵亡）就是它的 **动画**。本页说明游戏的动画各有什么用、单位做每件事时播放
哪个动画、修改动画的所有方法（只为一个单位、为所有单位、为你挑选的单位，或在 Blender 中），以及如何恢复游戏原有的动画。

## 什么是动画

- 动画随时间移动模型的骨骼：跑一步、把步枪举到肩上、倒下（见 [[模型与骨骼|模型与骨骼]]）。
- 单位在游戏中做的每件事（一个 **动作**：原地站立、行走、奔跑、开火……）都会播放一个动画。士兵会同时播放两个，身体每一半
  一个。
- 许多单位共用游戏的动画：每个美军步枪兵跑起来都一样。所以修改一个动画，除非你另选，就是修改所有使用它的单位。
- 坦克转动炮塔和车轮不用动画：这里没有需要为它们修改的。

## 游戏的动画及其用途

**RUSE Decoy**（Studio 顶部它的标签页）在左侧 **动画** 下按种类列出游戏的每个动画：

| 种类 | 包含什么 |
|---|---|
| **步兵** | 步枪兵、火箭筒、伞兵和驾驶员：站立、行走、奔跑、瞄准、射击、装填、溃逃、中弹和阵亡（上身和下身各有各的） |
| **炮组** | 火炮周围的士兵：待命、推炮、展开、射击和装填 |
| **车辆与火炮** | 火炮的展开与收拢、待命与射击，以及其他活动部件 |
| **司令部人物** | 任务场景中司令部桌旁的军官（不由单位播放） |
| **动物与场景** | 地图上的牛、马、山羊、鸡、海鸥和风车 |

每个动画都会显示游戏对它的叫法，以及有多少单位播放它。在单位页面上，动作按单位所做的事命名，分组如下：

| 分组 | 其中的动作（部分） |
|---|---|
| 原地 | 原地站立、蹲下、环顾四周 |
| 移动 | 行走、向后走、奔跑、向右跑、向后跑、逃跑 |
| 瞄准与开火 | 站立瞄准、边走边瞄准、开火、投掷手榴弹、装弹 |
| 重武器 | 用重武器瞄准、用重武器开火、举起重武器、放下重武器 |
| 被击中 | 被击中、背后被击中、被爆炸击中 |
| 阵亡 | 中弹阵亡、在爆炸中阵亡、倒地 |
| 跳伞 | 跳出、下落、乘伞下降、着陆 |
| 乘员的动作 | 待命、推炮前进、走向火炮、架设火炮、开火（乘员）、给火炮装弹 |

## 它的动画：每个动作播放哪个

有自己动画的单位（有自己骨骼的模型：马、带骑手的马、任何生物）的页面上有一个表：**外观与动作**，**声音与动画** 行的
**更多**，然后是 **它的动画**。

- **原地站立**、**行走** 和 **奔跑** 排在最前：这是模型最起码需要的。如果其中某个没有自己的动画，页面会说明，以及它改为
  播放什么。
- 每个动作都有一个模型动画的列表。选一个，或保留第一行 **最接近的**：这时它播放模型拥有的最接近的动画，并在这一行显示是
  哪个。最接近的依次是：以该动作命名的动画（stand 或 idle、walk、run 或 gallop、fire、death……），否则是最接近的动作所
  播放的（行走播放奔跑，开火播放瞄准或站立）。游戏按页面所示播放：构建时使用同样的规则。
- **其他所有动作** 按分组列出其余的。
- **长途移动时** 是它的最后一行。沿道路长途移动时，游戏会让小队坐上它的卡车。有自己动画的单位可以改为以自身形象前进，
  循环播放其中一个动画（保留第一行时是它的奔跑），速度和它的卡车一样。要保留卡车，就选 **坐自己的卡车**。

从有自己动画的单位复制出的单位，播放同样的动画。

## 在 RUSE Decoy 中修改动画

1. 在单位页面的 **外观与动作** 中，点击 **声音与动画** 行的 **在 RUSE Decoy 中修改**。RUSE Decoy 会打开这个单位：先是它
   的声音，然后是 **它的动画**，列出它播放的每个动画。（也可以打开 **RUSE Decoy** 标签页，在 **动画** 下选一个种类。）
2. 在某个动画上点击 **观看并修改…**。它会在播放它的单位上以 3D 播放：拖动可旋转，滚轮可缩放。3D 视图需要联网一次。
3. 从单位页面打开时，第一行会问 **修改范围**：
   - **仅此单位**：这个单位播放它自己的动画副本，带着你的修改；其他所有单位照旧播放。如果这个动画还没有为所有单位修改，
     一开始选中的就是它。
   - **所有使用它的单位**：修改作用于动画本身，影响所有使用它的单位（数字表示有多少个）。
   - **你的副本** 及其名称：当这个单位播放你的某个副本时显示（见下文）；这时一开始选中的就是它。
4. 修改它：
   - **速度**：100% 是游戏的速度，200% 快一倍，50% 慢一半。松开时保存。
   - **改用**：用同一身体的另一个动画代替它（步枪兵可以用逃跑的方式奔跑）。
   - **骨骼**，以及 **大小**、**旋转轴** 和 **旋转**：在整个动画中把身体的某个部位放大或转动。
   - **动作捕捉**：用真人的动作代替它（见 [[音乐与音效|音乐与音效]]）。
5. 点击 **完成**。每次修改都会立即保存到你的模组中，在测试或导出时进入游戏。

## 动画副本：只给你挑选的单位

**复制此动画…** 会制作一个只有你勾选的单位和士兵才播放的副本：比如给你的三个小队用一种自己的跑法，再只给第四个小队的
火箭筒兵用。

1. 在动画窗口中点击 **复制此动画…**，给副本起个名字（只有你能看到），然后点击 **制作副本**。它从动画当前的样子开始，并在
   同一窗口中打开。
2. 像上面那样修改它。
3. 在 **谁播放它** 中，勾选播放这个副本的单位：先是 **你的单位**，然后是 **游戏中的单位**。如果一个单位里有多个士兵或部件
   播放它，可以只勾选其中一部分。**查找单位** 按名称或国家查找。
4. 在你勾选单位之前，没有任何单位播放这个副本：在那之前，副本名称下面的那一行会显示“还没有单位播放它”。

每个副本都在 RUSE Decoy 左侧的 **你的副本** 下：在那里打开它，或 **删除副本**。对一个单位来说，它自己的副本（**仅此
单位**）或在 Blender 中修改的动画优先于副本：列表会在旁边注明。

## 在 Blender 中修改新单位的动画

适用于你在模组中做的新单位（游戏的单位要先以它为基础做一个新单位）：

1. 在单位页面上点击 **在 RUSE Decoy 中修改**。在它的动画上方，点击 **在 Blender 中修改它的动画**。Blender 会打开这个
   单位和它播放的每个动画，每个动画都以它在其中做的事命名，后面跟着游戏中的名字。
2. Blender 底部的 Action Editor 列出了它们：选一个。按 **空格键** 播放。
3. 点击一根骨骼，按 **Ctrl+Tab** 进入 Pose Mode，按 **R** 旋转（**G** 移动），然后按 **I** 记下这一帧的姿势。在你修改
   的每一帧都这样做：Blender 会自动从一个记下的姿势过渡到下一个。
4. 点击 Blender 3D 视图顶部的 **发送到 R.U.S.E. Studio**：每个动画都会送出，无论改没改。
5. 在 RUSE Decoy 中点击 **带回我的修改**。它会告诉你哪些修改后回来了：这些现在是这个单位专属的。其他所有单位，以及你
   没碰过的每个动画，都保持原样。

只给骨骼摆姿势：不要给它们改名、删除它们，也不要在 Edit Mode 中移动它们。否则 Studio 什么也不会收入，并告诉你是哪些骨骼。

有自己骨骼的模型（马、任何生物）会以自己的名字发送自己的动画。你修改的那个会回到原位：每个播放它的动作都会播放修改后的。

## 恢复游戏原有的动画

| 要去掉的 | 点击 | 位置 |
|---|---|---|
| 对所有单位的修改 | **恢复游戏原样** | RUSE Decoy 中该动画的那一行，或它的窗口 |
| 这个单位自己的副本（**仅此单位**） | **恢复为所有单位共用的版本** | 单位列表中该动画的那一行，或它的窗口 |
| 副本的修改（名称和勾选保留） | **恢复为游戏原动画** | 副本的窗口 |
| 整个副本 | **删除副本** | **你的副本** |
| 在 Blender 中做的修改 | 趁那个 Blender 还开着，在 Blender 中撤销，然后点击 **带回我的修改**：你的模组中也会撤销 | Blender，然后 RUSE Decoy |

上面的按钮不会去掉在 Blender 中做的修改。

## “带回我的修改”可能告诉你的

| 它显示 | 该怎么做 |
|---|---|
| “在 Blender 中修改的，现在是这个单位专属的：……” | 无需操作：成功了。**在游戏中测试** 可以看到。 |
| “每个动画都和送出时一样回来了。” | 什么都没改。你是否用 **I** 记下了每个姿势？ |
| “在 Blender 中制作、还没有任何动作播放的：……” | 新动画不会被收入。要保留，请在 Blender 中保存（**File > Save**）。 |
| “没有送回（在 Blender 中被删除或改名），所以照旧播放：……” | 如果想让你的修改进来，在 Blender 中把名字改回去。 |
| “这些只在身体的一半上播放（上半身或下半身）……” | 你移动的骨骼在另一半：请移动播放它的那一半的骨骼。 |
| “在 Blender 中制作的骨骼，这个单位的骨架里没有……” | 新骨骼无法播放；其余部分已收到。 |
| “Blender 的 NLA 编辑器以自己的时间安排播放这些……” | 游戏按 Action Editor 中显示的样子播放它们。 |
| “Blender 的场景以每秒 …… 帧播放，而游戏是每秒 30 帧……” | 把 Blender 设为每秒 30 帧，就能看到游戏中的速度。 |
| “Blender 的场景开启了 Time Stretching……” | 把 Old 和 New 设为同一个数，就能看到游戏中的速度。 |
| “这个单位没有任何动作播放这些……” | 在单位页面的 **它的动画** 中，为某个动作选择它。 |
| “送到 Blender 之后在 Studio 中改过、而从 Blender 送回时没有改动的，所以保留 Studio 中的修改……” | 无需操作：你在 RUSE Decoy 中的修改会保留。 |
| “送到 Blender 之后在 Studio 中也改过的：Blender 的修改取代了 Studio 的修改……” | 如果你要的是 Blender 的修改，无需操作；否则请在 RUSE Decoy 中再改一次。 |
| “自上次带回你的修改以来，Blender 没有发来任何新内容。” | 先在 Blender 中点击 **发送到 R.U.S.E. Studio**。 |

## 可能出的问题

- **游戏里什么都没变：** **仅此单位** 的修改只在那个单位上可见，副本只在为它勾选的单位上可见。对那个单位来说，在 Blender
  中做的修改优先于之后用 **仅此单位** 或副本对同一动画做的修改（Studio 的规则；尚未在游戏中试过）。
- **“只有在这个模组中做的新单位才能有自己的动画”**：这是游戏的单位。先以它为基础做一个新单位（它页面上的 **以此单位
  制作新单位…**）。
- **页面上没有“它的动画”：** 这个表只出现在有自己动画的单位（有自己骨骼的模型）上。其他单位都播放游戏的动画：在
  RUSE Decoy 中修改。
- **从未带回的发送：** 再次打开 Blender 会把它另存。RUSE Decoy 会显示它，并带有 **带回另存的发送** 和 **移到回收站**
  （见 [[在 Blender 中打开|在-Blender-中打开]]）。

## 已在游戏中试过的

- RUSE Decoy 对所有播放它们的单位所做的动画修改（Studio 0.9.8.8）。
- **仅此单位**：一个小队原地跳舞，而其他所有小队照旧站着（2026 年 11 月）。
- **复制此动画…**：一个副本由一个小队和另一个小队的一名士兵播放（2026 年 11 月）。
- **在 Blender 中修改它的动画**：一个举起一只手臂站立和奔跑的小队，以及马匹抬着头的通用骑兵小队（2026 年 11 月）。
- 通用骑兵小队自己的动画（由 **最接近的** 选出），以及长途移动时以自身形象前进（2026 年 11 月）。
- 尚未在游戏中试过：只为一个单位修改速度、替代动画或骨骼，以及在 **它的动画** 中手动选择另一个动画。
