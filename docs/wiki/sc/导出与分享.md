# 导出与分享

> **适用：** 模组作者 · **你需要：** RUSE Studio 和一个做好的模组 · **用时：** 5 分钟

## 1. 导出

1. 打开 **模组** 菜单，选择 **导出模组…**。
2. 填写 **版本**（三个数字，比如 `1.0.0`）、你的名字，以及一行介绍模组做什么的文字。
3. 选择保存位置。Studio 会在你的游戏上构建一次模组，以记录制作它时所用的游戏版本和它的
   **指纹**（一段简短的代码，对使用相同模组的每个人都一样），然后保存一个文件：
   `<your-mod>-<version>.rusemod`。

玩家只需要这个文件：他们在 RUSE Launcher 中添加它（[[安装与游玩|安装与游玩]]）。

**大型地图模组：** 一张到处都改过的地图，构建时可能要花几分钟来计算（例如，单位能在你开辟的地面上去哪里）。
这只需要你等一次。导出会把构建算出的结果放进文件里，所以玩家的第一次构建会更短。它只包含我们自己的数字，
从不包含游戏的文件，并且和游戏中那张地图自己的文件锁在一起：它只能在装有这款游戏的电脑上打开。
目前只有移动数据；尚未在游戏中看到。

导出完成后，Studio 会打开 **分享你的模组**，显示文件的大小、它的 SHA-256 校验值，以及它在列表中的条目，
可以直接复制。你随时可以从 **模组** 菜单（**分享你的模组…**）再次打开它。

## 2. 分享：把它加入支持的模组

做了一个模组？把它加入列表，成为贡献者。RUSE Launcher 的 **支持的模组** 标签页会显示
[sneadtristen6/Ruse-Mods](https://github.com/sneadtristen6/Ruse-Mods) 列表上的模组，玩家点一下就能安装它们
（新玩家在 Launcher 第一次启动时就会看到推荐）：

1. 上传 `.rusemod`（用 GitHub Release 最简单：你自己仓库的，或者列表仓库的）。
2. 向 [sneadtristen6/Ruse-Mods](https://github.com/sneadtristen6/Ruse-Mods) 提交一个 pull request，
   把你模组的条目加入 `index.toml`：粘贴 分享你的模组 显示的条目，并把文件的链接填进 `download`。大小和
   SHA-256 必须是导出时显示的那些：Launcher 会拒绝不匹配的下载，所以没人能把你的文件换成别的。
3. 或者把它发到 [Discussions > Mods & maps](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions)，附上一张截图和它改了什么（把 `.rusemod` 拖进帖子里），就会有人替你把它加入列表。

作弊或测试工具（免费单位、瞬间建造……）会带上 `"cheat"` 标签：Launcher 会把它放在单独的分组
“作弊和测试工具（可选）”中，除非玩家自己勾选，否则永远不会勾选或下载它。新版本就是一个带新版本号的新文件：已发布的文件永远不会改变。

条目的确切格式：
[MOD_FORMAT.md，第 15 节](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/blob/main/docs/MOD_FORMAT.md#15-the-mod-index-supported-mods)。

## 编辑已安装的模组

在 Studio 的模组菜单中，**编辑已安装的模组…** 会列出 Launcher 中的每个模组（带一个搜索框）。你自己的模组会打开它的项目。别人的模组会变成你自己的一份副本，带它自己的名称（不能沿用原版的名称）：你的修改都进入这份副本，
原版的更新永远不会抹掉它们。RUSE Mod Manager 的模组（`.rmod`）会在它的副本中被转换，所以它对数值的修改会变成你可以再修改的 Studio 修改。

## 显示模组的文件夹，或删除模组

在 Studio 的模组菜单中，**显示此模组的文件夹** 会打开正在编辑的模组的文件夹，**删除模组…** 会列出你的模组和地图修改：**删除** 会把它移到回收站（可从那里找回），勾选的话，它在 Launcher 中的副本也会一起移过去。从别处打开的文件夹只会从列表中移除。**设置 → 你的文件在哪里** 显示所有内容的保存位置（[[模组的文件夹和文件|模组的文件夹和文件]]）。在 RUSE Launcher 中，**移除** 同样会把库中的模组移到回收站，**在文件夹中显示** 会打开它的文件夹。

## 模组可以包含什么

只有数据：数字、文本、地图、模型、纹理。程序（`.exe`、`.dll`、在电脑上运行的脚本）会被两个应用拒绝。
有一个例外：游戏自己的任务脚本，以 Studio 保存它们的形式。它们在游戏内部运行，能做游戏能做的任何事，
所以只安装你信任的作者的这类模组（[SECURITY.md](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/blob/main/SECURITY.md)）。

## 好习惯

- 保留你的模组文件夹：`.rusemod` 是给玩家的，文件夹才是 Studio 编辑的东西。
- 在你的帖子里说明你的模组需要哪些其他模组，或与哪些模组冲突。
- 为你借用其成果的人署名。
