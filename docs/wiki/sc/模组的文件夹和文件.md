# 模组的文件夹和文件

> **参考** · 你永远不需要手动去动这些：Studio 会写好它们。本页用于看起来出了问题的时候，
> 或者给直接编辑文件的模组作者看。

## 东西都在哪里

| 什么 | 在哪里 |
|---|---|
| Studio 的模组 | `%LOCALAPPDATA%\RUSE Mod Platform\mods\<mod>`（把它粘贴到文件资源管理器的地址栏） |
| Launcher 已安装的模组 | `%LOCALAPPDATA%\RUSE Mod Platform\library` |
| 游戏的模组版副本 | 你在 设置 中选择的文件夹（**模组版副本的保存位置**，两个应用里都有）；推荐的位置是与游戏在同一驱动器上的 `RUSE-Instances`（例如 `D:\RUSE-Instances`），这样副本会共用游戏的文件。放在另一个驱动器上时，每个副本都是游戏的完整副本：更慢，也更大。游戏的干净备份（`RUSE-Backup`）放在它旁边。 |
| 游戏本身 | 永远不会被改动 |

## 模组内部

```
my-mod/
  mod.toml                    the mod's name, id, version, author (required)
  src/studio.rndf             unit changes made in the Studio
  text/studio.baseunite.csv   names of new units
  files/replace/gen/...png    a unit's paint (from Blender) or a unit's card, under the game texture it changes
  files/cards/<unit>.png      a new unit's own card in the build menu, named after the new unit
  files/models/<unit>.glb     a new unit's own 3D model (Import model), named after the new unit
  maps/<map pack name>/       one folder per map the mod changes:
    terrain.toml                ground brushes (also water, cover and block brushes)
    scenery.toml                buildings, props and trees placed
    scenario.toml               starting points and spawns moved, units added
    cover.toml, movement.toml   cover and movement written by hand
    map.toml                    how many players; or, for a new map, the map it copies and its name
```

## 地图文件夹的名称是地图的包名，不是它的标题

玩家通过标题认识一张地图（**闪电战**）；游戏的文件使用它的包名（**SuperCrossRoads4**）。
地图文件夹必须使用包名：`maps/SuperCrossRoads4/`，而不是 `maps/Blitz/`。每张地图的这一对名称都在 [[地图名称|地图名称]] 中，
Studio 的地图列表也会把两个都显示出来：标题在前，包名在点号之后。

## 新地图

模组可以向“战斗”添加一张它自己的地图：一张自带地图的副本，或者一个空白的开始，用它自己的名称，
然后由模组的其他文件来重塑它。它的文件夹名称就是新地图的包名（字母、数字和 `_`），
它的 `map.toml` 会说明它复制的是哪张地图，以及菜单里怎么称呼它：

```toml
copy_of = "SuperCrossRoads4"   # the shipped map it starts from (its pack name: Blitz)

[name]
us = "Blitz Twin"              # English, used where a language is left out
fr = "Blitz jumeau"
```

随后 `maps/BlitzTwin/terrain.toml` 和其他文件会编辑这份副本，而 闪电战 保持原样。
“战斗”列出的任何地图都可以复制；战役和行动的地图不行。和任何模组一样，两名玩家需要相同的模组才能一起玩它。
新地图可以在游戏中玩（2026-10-03），Studio 的 **复制地图** 会为你制作这个文件夹。

## 常见错误

| 错误 | 会发生什么 | 解决办法 |
|---|---|---|
| zip 里是文件夹套文件夹 | Launcher 会往下找一层文件夹，能找到它。往下两层或更多，它会说没找到模组。 | 压缩包含 `mod.toml` 的那个文件夹。 |
| 地图文件夹用了地图的标题来命名 | 构建会说它不是地图的包名。 | 把它重命名为包名。 |
| 手动编辑的文件有拼写错误 | 模组检查会指出是哪个文件、哪一行。 | 改正它，或者在 Studio 中点 **搁置**。 |
| 模组里有 `.exe`、`.dll` 或电脑脚本 | 被拒绝：模组只携带数据（游戏自己的任务脚本，以 Studio 保存它们的形式，是唯一的例外）。 | 把它拿掉。 |

如果某个文件无法读取，Studio 永远不会覆盖它：你的工作永远不会丢失。
**搁置** 会把它重命名为原文件旁边的 `<name>.broken.toml`。
