# 在 Blender 中打开

> **你需要：** RUSE Studio 0.9.8.20 或更新版本、一个模组，以及 Blender（免费） · **用时：** 阅读约 5 分钟

**在 Blender 中打开** 会把一个单位带进免费的 3D 软件 Blender，让你修改它的外形、骨骼或涂装；**带回我的修改** 会把你在
那里做的修改放进你的模组。这是整个单位的一个按钮：旁边的 **要送到 Blender 的内容** 说明哪些内容会送出，你取消勾选的
部分都保持原样。本页一步一步讲解。

动画不用这个按钮修改：动画在 RUSE Decoy 中修改（见 [[单位动画|单位动画]]）。模型自己的动画会随模型一起送到 Blender，
也会随它一起回来。

## 按钮在哪里

| 单位 | 位置 | 会带回什么 |
|---|---|---|
| 你做的小队（你模组中的新单位） | 页面顶部小队卡片上的大按钮 **在 Blender 中打开** | 它的士兵，各自独立；以及他们的涂装 |
| 你做的其他单位（坦克、飞机） | **外观与动作** 的 **模型** 行，**更多**：**在 Blender 中修改** 方框 | 它的整个模型（骨骼是它自己的时也包括骨骼），以及它的涂装 |
| 游戏中的单位（不是小队） | 同一个方框 | 只有涂装：在上面涂画，其余保持游戏原样 |
| 游戏中的小队 | 它的卡片会提示先以它为基础做一个新单位：**以此单位制作新单位…** | 只有它的 **自定义制服**，从它的 **制服** 行涂装（**在 Blender 中打开**，然后 **带回**） |

这台电脑上没有 Blender？页面会显示 **获取 Blender（免费）**（打开 Blender 的下载页面）和 **选择 Blender…**（如果你已经
有了，告诉 Studio `blender.exe` 在哪里）。

## 要送到 Blender 的内容

点击按钮旁边的 **要送到 Blender 的内容 ▾**。开始时全部勾选。取消勾选某个部分即可保持原样：**带回我的修改** 会让它保持
原来的样子，不管 Blender 对它做了什么。

| 你看到的 | 意思 |
|---|---|
| **它的士兵**，然后是每个士兵（“步枪兵 1”“火箭筒兵 5”……） | 勾选的士兵会并排在同一个 Blender 中打开。随便改哪个：只有你改的那个会变。 |
| **哪个模型：** **步枪兵的模型** 或 **重武器士兵的模型** | 有自己骨骼的小队（通用骑兵小队）：一次一个模型，带着它的骨骼和动画。 |
| **它的模型** | 单位的外形（不是小队的单位）。 |
| **它的骨骼** | 它的骨骼（仅限有自己骨骼的模型）。取消勾选时，你模组中的骨骼会恢复原样。 |
| **它的涂装** | 它的图片。取消勾选时，你模组中的图片会恢复原样。 |

小提示：

- **只要涂装**（取消勾选它的模型或所有士兵）：Blender 打开时带着可以涂画的图片，带回的只有涂装。小队的 **自定义制服** 就是
  这样一次为所有士兵涂装的。穿默认制服的小队不行：“请先选择“自定义制服””（默认制服也由其他小队和乘员穿着）。请先在
  **外观与动作** 的 **制服** 行中选择 **自定义制服**。
- 取消勾选了 **它的骨骼**，但在 Blender 中添加、删除或重命名了骨骼：骨骼无法保持原样，会按 Blender 发送的样子带回，
  Studio 会说明。
- 由游戏士兵组成的小队没有 **它的骨骼**：不管 Blender 对他们做了什么，士兵都会回到游戏士兵的骨骼上。
- 什么都没勾选：Studio 会显示“请先勾选要送到 Blender 的内容：模型、骨骼或涂装。”

## 往返的每一步

1. **打开。** 点击 **在 Blender 中打开**。Blender 会带着你勾选的内容打开（需要几秒钟）。
2. **修改。** 涂画、改外形、把你自己的模型放到士兵的骨骼上（见 [[模型与骨骼|模型与骨骼]] 的“权重”）。需要知道的几件事写在
   Blender 3D 视图的顶部。
3. **发送。** 点击 Blender 3D 视图左上方的 **发送到 R.U.S.E. Studio**。
4. **带回。** 在 Studio 中，按钮现在显示 **带回我的修改**：点击它。页面会说明收到了什么：小队会说明谁变了、谁没变，其他
   单位会显示模型文件，还有哪些因未勾选而保持原样。
5. **在游戏中测试** 可以看到效果。

可以让 Blender 一直开着，再来一轮：修改、发送、带回。

## 带回我的修改

- **Blender 还开着？** **带回我的修改** 会先请它发送，并等待（最多一分钟）。
- **要关闭 Blender？** 先点击 **发送到 R.U.S.E. Studio**：没有发送的内容会留在 Blender 中，Studio 永远看不到。
- **发送后关掉了？** 在你点击之前，按钮一直显示 **带回我的修改**，它会取你最后发送的内容。在小队卡片上，上次带回之后（或
  **添加士兵** 之后）做的发送，会在 Blender 关闭后以大按钮下方一个小的 **带回我的修改** 显示：它会取你最后发送的内容。
- **还什么都没发送：** “还没有从 Blender 带回任何内容：在 Blender 中点击顶部的“发送到 R.U.S.E. Studio”，再在这里点击
  “带回我的修改”。”
- 一个单位同时只能有一个 Blender：Blender 打开着这个单位时，Studio 的按钮显示 **带回我的修改**。

## 另存的发送

**发送** 是 Blender 通过 **发送到 R.U.S.E. Studio** 送出的内容。如果你在带回最后一次发送之前又打开了 Blender：

- **小队：** 那次发送会另存到你模组的 Blender 文件夹中一个名为 `sent-not-brought-` 加日期时间的文件夹里，新的 Blender 从你
  模组现有的内容开始。什么都不会丢，但卡片目前不会提示，也没有带回它的按钮：文件在
  `Documents\RUSE 2.0\Mods\<你的模组>\blender\<单位名称>\squad\` 中。
- **其他单位（勾选了模型）：** 不会另存任何东西：下一次 **在 Blender 中打开** 会从你最后发送的内容开始。
- **RUSE Decoy 的动画：** 每次另存的发送都会列在单位的动画上方（“从 Blender 发送后从未带回，于 …… 重新打开它的动画时
  另存。”），带有 **带回另存的发送**（收入）或 **移到回收站**。

## 你的 Blender 文件在哪里

在你模组的文件夹 `Documents\RUSE 2.0\Mods\<你的模组>\blender\<单位名称>\` 中：小队的在 `squad`，RUSE Decoy 的在
`animations`。导出模组时不会打包它们。在小队页面上，**更多选项** 会显示它们的位置，并有 **在文件夹中显示**。

## 可能出的问题

| 发生了什么 | 原因和处理 |
|---|---|
| Blender 打开后是空的 | 在 Blender 的窗口中查找错误（**Window > Toggle System Console**），并在 Discord 上告诉我们。 |
| 我没碰过的士兵显示为已修改 | 只要有不同就算修改，改名的对象也算。他的外观保持原样。 |
| “不在任何士兵身上，因此未发送：……” | 你带进 Blender 的东西既不在士兵的骨骼上，也不在他的集合里：把它放到他身上，再发送一次。 |
| 我模型上的点只随髋部移动 | 它没有骨骼：见 [[模型与骨骼|模型与骨骼]] 的“没有骨骼的点”。 |
| 部件失去了光泽或阵营色 | 页面会列出它们：在 Blender 中改名或新建的材质会以普通状态回来。请保留 Blender 打开时的材质名称。 |
| 我的游戏单位的新外形没有回来 | 游戏单位只会带回涂装。要改外形，请以它为基础做一个新单位。 |
