# 模型与骨骼

> **你需要：** RUSE Studio 0.9.8.20 或更新版本、一个含有新单位的模组，以及修改骨骼所需的 Blender（免费） ·
> **用时：** 阅读约 10 分钟

R.U.S.E. 中的士兵、马匹和各种生物之所以能动，是因为它们的 3D 模型里有 **骨骼**。本页说明什么是骨骼、游戏如何使用骨骼，
以及单位页面上每个与骨骼有关的方框是什么意思、该怎么做。坦克转动炮塔和车轮不用动画，所以本页主要讲士兵、马匹和生物。

## 什么是骨骼

- **模型** 是由点组成的外壳，上面画着图片。
- 外壳里面像骨架一样有 **骨骼**：上臂、前臂、手、头、马的每条腿。每根骨骼挂在另一根上（手挂在前臂上，前臂挂在上臂上），
  一直连到第一根骨骼。
- 外壳上的每个点跟随一根或几根骨骼移动：袖子上的点跟着手臂动。一个点跟随每根骨骼的程度就是它的 **权重**。
- **动画** 一帧一帧地移动骨骼，外壳跟着骨骼动。士兵就是这样行走、瞄准和倒下的。
- 在 Blender 中，模型的骨骼是一个对象，叫做 **armature**。

## 游戏如何使用骨骼

- 游戏按骨骼 **在骨骼列表中的位置** 移动模型的骨骼，而不是按名字。因此为一个模型做的动画，只适合骨骼相同、顺序也相同的
  模型。
- 有些骨骼有专门的用途：射击从武器枪口处的骨骼发出，上身在脊椎的一根骨骼处转向目标，武器在某根骨骼上显示和隐藏，
  炮塔或车轮绕某根骨骼转动。单位页面会逐个列出你的模型缺少的骨骼（见下面的 **能在游戏中正常运行吗？**）。
- 士兵会 **同时播放两个动画**：一个在身体上半部（瞄准、射击），一个在下半部（行走、奔跑）。马和骑手也是这样：见下面的
  **上下两半**。
- 尚未见过游戏让超过 64 根骨骼的模型动起来。

## 两种模型

| | 使用游戏士兵的骨骼 | 有自己的骨骼 |
|---|---|---|
| **是什么** | 在 Blender 中修改过的士兵，或放到士兵骨骼上的你自己的模型 | 马、带骑手的马、任何生物，在 Blender 中用你自己的骨骼做成 |
| **怎么做** | 小队卡片上的 **在 Blender 中打开**：每个士兵都带着骨骼打开（见 [[在 Blender 中打开|在-Blender-中打开]]） | 在 Blender 中做好，再在小队卡片上点 **导入模型…**（见 [[导入模型|导入模型]]） |
| **它的动画** | 游戏的动画，和士兵一样 | 它自己的，来自它的文件 |
| **上下两半** | 游戏自己的：无需选择 | 由你选择（Studio 会建议一根骨骼） |
| **大小和位置** | 和你在 Blender 中做的一样，在士兵的骨骼上 | 和它的文件中一样 |

页面会告诉你是哪一种。使用游戏士兵骨骼的模型会显示：“你的模型使用游戏士兵的骨骼，因此沿用游戏自己的上下两半：无需
选择。”有自己骨骼的模型会显示：“它有自己的骨骼：”以及根数。**通用骑兵小队**（**单位** 标签页，**二战+**）就是
有自己骨骼的小队：见 [[其他时代的单位|其他时代的单位]]。

## 页面在哪里显示它们

在新单位的页面上，和骨骼有关的内容都在 **外观与动作** 中：

| 方框 | 位置 | 告诉你什么 |
|---|---|---|
| **它的骨骼和动画** | **声音与动画** 行的 **更多** | 模型有多少根骨骼，以及每个动画的长度和有多少个单位动作播放它（有自己骨骼的模型） |
| **上下两半** | **声音与动画** 行的 **更多** | 模型在哪里分成上半身和下半身 |
| **它的动画** | **声音与动画** 行的 **更多** | 单位的每个动作播放哪个动画：见 [[单位动画|单位动画]] |
| **能在游戏中正常运行吗？** | **模型** 行的 **更多**；小队页面上是士兵下方的 **更多选项**，然后是 **每个士兵的模型** | 模型中哪些地方可能让游戏停止或看起来不对，以及怎么修正 |
| 没有骨骼的点 | 和 **能在游戏中正常运行吗？** 在同一处 | 模型有多少个点不跟随任何骨骼 |

## 上下两半

游戏会在士兵身上同时播放两个动画：一个在他的 **上半身**（瞄准、射击），一个在他的 **下半身**（行走、奔跑）。骑手在马
奔跑时瞄准和射击：骑手是上半身，马是下半身。

- 使用游戏士兵骨骼的模型沿用游戏的上下两半：页面会显示“无需选择”。
- 有自己骨骼的模型在 **一根骨骼** 处分开：这根骨骼及其下方的所有骨骼是上半身，其他骨骼是下半身。

选择方法：

1. 在单位页面的 **外观与动作** 中，点击 **声音与动画** 行的 **更多**。
2. 在 **上下两半** 下，**上半身起始于** 列表首先显示 Studio 的建议，标有“（建议）”。Studio 的建议是：带骑手的马选骑手的
   第一根骨骼（通用骑兵小队是 **bip01**），否则选第一根名为 spine 的骨骼（士兵的方式），否则选骨架第一次分叉处的骨骼。
3. 大多数模型用建议就好：保持不变。要修改，在列表中选另一根骨骼。它会立即保存，下次构建（**在游戏中测试**）后在游戏中
   生效。
4. 列表下方会统计每一半的骨骼数，**每根骨骼属于哪一半** 列出模型的每根骨骼，并标出上半身或下半身。
5. 要回到建议，再选一次列表的第一行。

除建议之外的其他分法尚未在游戏中试过。

## 权重：每个点跟随哪根骨骼

当你把自己的模型（或头盔、背包、武器）放到士兵的骨骼上时，Blender 需要知道它的每个点跟随哪根骨骼。以下是 Blender
本身的操作步骤。

**把你的模型放到士兵身上，每个点跟随最近的骨骼：**

1. 在小队卡片上点击 **在 Blender 中打开**：Blender 打开，每个士兵都在自己的骨骼上。
2. 在 Blender 中用 **File > Import** 导入你的模型，放到士兵身上。
3. 先点击你的模型，再按住 **Shift** 点击士兵的骨骼：骨骼要最后选。
4. 按 **Ctrl+P**，选择 **With Automatic Weights**。Blender 会替你算出权重。
5. 删除你不保留的东西（如果你的模型取代游戏士兵，就删除游戏士兵的外形），但保留他的骨骼。
6. 点击 Blender 3D 视图顶部的 **发送到 R.U.S.E. Studio**，然后在 Studio 中点击 **带回我的修改**。

**只跟随一根骨骼的硬部件（戴在头上的头盔）：**

1. 在 Blender 中点击头盔，再按住 **Shift** 点击士兵的骨骼。
2. 按 **Ctrl+Tab** 进入 Pose Mode，点击头部的骨骼。
3. 按 **Ctrl+P**，选择 **Bone**。头盔现在随头部移动，带回修改时只有这个士兵会得到它。

**没有骨骼的点。** Blender 的自动权重有时会漏掉几个点。这时页面会显示“你的模型有 {n} 个点没有骨骼，所以它们只随士兵的
髋部移动。”修正方法：

1. 再次 **在 Blender 中打开**。
2. 点击你的模型，把 Blender 的模式（3D 视图左上角）从 **Object Mode** 切换到 **Weight Paint**。
3. 在模型的属性（绿色三角形）中，**Vertex Groups** 里每根骨骼有一个组：选择这些点应该跟随的骨骼。
4. 在这些点上涂抹。
5. **发送到 R.U.S.E. Studio**，然后 **带回我的修改**。

## 能在游戏中正常运行吗？

Studio 会对照使用骨骼的模型所播放的动画，以及所复制单位的部件和射击，来检查这个模型。构建模组时会连同你的所有修改再
检查一次。问题从不会阻止你：它会告诉你会发生什么，以及怎么修正。

**位置：** 新单位页面的 **外观与动作**，**模型** 行，**更多**。小队页面上：士兵下方的 **更多选项**，然后是 **每个士兵的
模型**。

一切正常时显示：“没有发现会让游戏停止的问题：它播放的每个动画都有它的骨骼，部件和射击需要的每根骨骼也都在。”（附带
骨骼数）。

### 每种回答的意思

每个问题都说明三件事：哪里不匹配、游戏会怎样处理、怎么修正。中间那一行是下面之一：

| 页面显示 | 意思 | 该怎么做 |
|---|---|---|
| 这可能让游戏停止：测试中发生过。 | 在我们的某次测试中，游戏就这样停止了。 | 测试前先修正。 |
| 这可能让游戏停止（尚未在游戏中试过）。 | 预计会让游戏停止。 | 测试前先修正。 |
| 游戏会播放它，但看起来会不对（尚未在游戏中试过）。 | 会移动错误的骨骼。 | 修正，或测试后看看。 |
| 单位仍会作战，但看不到它的射击：测试中发生过。 | 能造成伤害，但看不到射击。 | 添加页面列出的骨骼。 |
| 尚未在游戏中试过：游戏可能不会让它动起来。 | 骨骼数超过了见过游戏能动起来的数量。 | 合并或删除骨骼。 |
| 仍然可用，但可能不是你想要的效果。 | 关于上下两半的提示。 | 检查 **上下两半**。 |

### 每个问题及其修正

**与模型骨骼不匹配的动画。** 页面会说明有多少个动画、用于多少个动作，以及为什么不匹配：“它们驱动 {a} 根骨骼，而你的
模型有 {b} 根。”（或“只有 {b} 根”），或骨骼数相同但“名字不同”，或“顺序不同”。这些动画是为别的骨骼做的。

- 如果单位在你的模型上播放的是游戏的动画：给这些动作配上你模型自己的动画。**导入模型…** 会带入你模型文件中的每个动画，
  每个动作播放哪个，在 **它的动画** 中选择（[[单位动画|单位动画]]）。
- 如果是你模型自己的动画、但为另一个模型做的：在 Blender 中按这个模型的骨骼重做，然后重新导入模型。

**单位需要的骨骼。** 例如：“步枪兵：射击从名为 Fx_Tir_01 的骨骼发出，而你的模型没有这根骨骼。”（或：上身在那里转向
目标，武器在那里显示和隐藏，部件挂在那里，炮塔或车轮在那里转动，身体靠在那里，牵引炮在那里挂接）。在 Blender 中添加
这根骨骼：

1. 在 Blender 中打开模型：勾选 **它的骨骼** 后点击 **在 Blender 中打开**（见 [[在 Blender 中打开|在-Blender-中打开]]），
   或打开你自己的 Blender 文件。
2. 点击骨骼（armature），按 **Tab** 进入 Edit Mode。
3. 按 **Shift+A**：在 Blender 的 3D 光标处出现一根新骨骼。
4. 按 **F2**，准确输入页面给出的名字（例如 `Fx_Tir_01`）。如果你的模型有这根骨骼但名字不同，就改那根骨骼的名字。
5. 在骨骼属性（骨头图标）的 **Relations** 中，把 **Parent** 设为部件随之移动的骨骼：射击的话，就是武器随之移动的骨骼。
6. 按 **G**，把新骨骼移到部件应在的位置：射击的话，移到武器枪管的末端。
7. 再按 **Tab**，点击 **发送到 R.U.S.E. Studio**，然后点击 **带回我的修改**（或导出你自己的文件，点击 **导入另一个…**）。
   **能在游戏中正常运行吗？** 会重新检查模型。

**骨骼太多。** “你的模型有 {n} 根骨骼。尚未见过游戏让超过 64 根骨骼的模型动起来。”在 Blender 中合并或删除骨骼，直到
不超过 64 根，然后把模型带回。

**分法。** “在模型的第一根骨骼 {bone} 处分开，会把所有骨骼都放进上半身，因此下半身的动画（行走、奔跑）什么也不动。”：
在 **上下两半** 中选更靠下、上身开始处的骨骼。“你为分法选择的骨骼 {bone} 已不在模型中，因此改在 {used} 处分开。”：
重新选择骨骼。

**小队的第二个模型用了别的骨骼。** 会出现以“他的模型有自己的骨骼，但与你的步枪兵模型的骨骼不同”开头的警告。重武器
士兵的模型要和步枪兵的模型使用相同的骨骼，才能播放他们的动画：在 Blender 中用步枪兵的模型改出他的模型，再在他的那一行
导入。移除步枪兵的模型时，他的模型也会一起移除。

## 在 Blender 中制作有自己骨骼的模型

1. **骨骼：** 把模型放在一个带你自己骨骼（名字随意）的 armature 上，并设好权重（上面的 **Ctrl+P > With Automatic
   Weights**）。
2. **动画：** 每个动画一个 action（Blender 的 **Dope Sheet > Action Editor**）。按内容给每个命名：至少要有 **stand**
   （或 **idle**）、**walk** 和 **run**（或 **gallop**）；**fire**、**aim**、**reload**、**hit**、**death**、
   **crouch**、**look**、**flee** 和 **grenade** 也能识别。像 **t_fire**（或 **hr_t_fire**）这样的名字只在上半身播放，
   **b_run**（或 **hr_b_run**）只在下半身播放：分别是骑手和他的马的。
3. **导出：** **File > Export > glTF 2.0**，格式选 **glTF Binary (.glb)**，并勾选 **Animation**。
4. 在新小队上 **导入**：见 [[导入模型|导入模型]]。
5. **检查它的页面：** **它的骨骼和动画**（每个动画都进来了，以及各有多少动作播放）、**上下两半**、**它的动画**、
   **能在游戏中正常运行吗？**
6. **在游戏中测试**。

之后在 Blender 中改过？重新导入：只要文件中还有同名的动画，每个动作就保持原来的动画。

  每匹马都和骑手一起倒下（2026 年 11 月）。
- 在 Blender 中按游戏士兵骨骼修改、并在那里设了权重的小队士兵（2026 年 11 月）。
- 尚未在游戏中试过：建议之外的其他分法，以及页面标为“尚未在游戏中试过”的每个问题。
