# 和朋友一起玩

> **适合：** 玩家 · **你需要：** RUSE Launcher，以及和朋友相同的模组 · **用时：** 5 分钟

每位玩家都需要 **相同的模组、相同的顺序**，否则游戏无法匹配。

1. 房主选好模组组合，点击 **分享**：该组合的加载顺序会以文本形式复制下来。
2. 房主把这段文本发出去（Discord、聊天……），连同其他人缺少的模组文件一起。
3. 每位朋友先添加缺少的模组文件，然后点击 **导入加载顺序…** 并粘贴文本：就会得到一个新的模组组合，模组相同、顺序也相同。
4. 大家都按下 **开始游戏**，房主像平常一样创建游戏。

> [!TIP]
> 这段文本的格式与 RUSE-Mod-Manager 复制和读取的格式相同，所以用它的朋友也能加入。

## 确认你们是同一个游戏：加入代码

**加入代码** 是由你装了模组的游戏生成的一段短码：同样的代码就是同一个游戏（同样的游戏版本、同样的模组和同样的模组版本）。
对战前比较一下代码，就知道对局不会不同步。

1. 用这个模组组合按一次 **开始游戏**：代码会随模组副本一起生成。
2. 点击 Launcher 底部的 **加入代码**。**RUSE Guard：你的加入代码** 窗口会显示你的代码：**复制** 并发给和你一起玩的人。
3. 把好友的代码粘贴到 **粘贴好友的加入代码**，然后点击 **比较**：“同一个游戏：你们可以一起玩。”，或带着差异列表的
   “不是同一个游戏。”。

小提示：

- 你的模组变了，代码也会变：改动后请重新发送。
- “没有代码：这些模组不改变游戏玩法，任何人都能和你一起玩。”
- 含有作弊模组或测试工具的组合，只能和代码相同的玩家进行多人和合作游戏，其他对局几秒后就会退出。
- **检查副本的每个文件** 会确认你的模组副本和构建时完全一样。
