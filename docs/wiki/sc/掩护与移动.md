# 掩护与移动

> **适合：** 模组作者 · **你需要：** RUSE Studio 0.7.2 和一个模组 · **已在游戏中验证：** 站在绘制的掩护上的步兵
> 会被隐藏；单位会绕开被封锁的地面规划路线

两层看不见的图层决定了一张地图怎么打：**掩护**（单位隐蔽的地方）和 **通行**（单位能去的地方）。

## 掩护：做一个单位能隐蔽其中的城镇或树林

1. 在工具栏中点击 **掩护与通行**（它的 **掩护** 标签页）。地图上单位目前会被隐藏的地方（地图的树林和城镇）会变成绿色。
2. 选择一个工具：
   - **掩护** 绘制可以隐蔽的地面（拖动）；
   - **移除掩护** 去掉掩护（拖动）：它经过的地面会显示白色条纹，即使那里本来没有掩护可去掉；
   - **城镇** 在你点击的城镇的每座建筑周围加上掩护。先把指针指向一个城镇：它将覆盖的每座建筑上会显示一个圆环，指针旁边会显示数量。**大小** 设置每座建筑周围的范围。
3. 每画一笔之后，指针旁的一行文字会说明它对单位改变了什么（“已移除 12,000 平方米的掩护”，
   或“这里没有可移除的掩护”）。
4. 勾选地图顶部的 **掩护**，使用其他工具时绿色也会一直显示。

> [!NOTE]
> 放置的建筑和树木本身不会隐藏单位。放置好一个城镇之后，用 **城镇** 点击它。

## 通行：对单位封闭地面

1. 勾选地图顶部的 **单位可达**：
   - **红色**：任何单位都不能去（水、悬崖、地图外）；
   - **黄色**：只有步兵能去（树林）；
   - **紫色**：只有车辆能去。
2. 在工具栏中点击 **掩护与通行**，然后点 **通行** 标签页，再拖动：
   - **封锁**：任何单位都过不去（一堵墙、一片雷区、你做出的悬崖）；
   - **封锁步兵**：车辆仍然可以通过；
   - **封锁车辆**：步兵仍然可以通过，就像在树林里；
   - **开放**、**对步兵开放**、**对车辆开放**：让单位进入地图原本不让它们进入的地面（与封锁相反）。
3. 封锁或开放笔画经过的地面会显示条纹：单位能去的地方是蓝色，封闭的地方是红色、黄色或紫色。每一笔都会在指针旁说明它封闭或开放了多少，或者那里没有任何变化。

单位会绕开被封锁的地面规划路线。你放置的建筑也会挡住单位（见
[[放置建筑和树木|放置建筑和树木]]）。
