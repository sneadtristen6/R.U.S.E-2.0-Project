# 地图名称

玩家通过标题认识一张地图；游戏的文件和你模组的文件夹则使用它的 **包名**。模组对一张地图的修改放在
`maps/<pack name>/` 中，例如 Blitz（闪电战）用 `maps/SuperCrossRoads4/`，绝不是 `maps/Blitz/`。

Studio 的地图列表两者都会显示：先是标题，点号后面是包名。一个包里常常有好几张地图
（一张战斗地图和在同一片地面上进行的行动，或者几个战役章节）。
