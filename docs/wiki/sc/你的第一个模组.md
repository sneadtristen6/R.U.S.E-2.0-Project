# 你的第一个模组

> **适合：** 新手模组作者 · **你需要：** Steam 上的 R.U.S.E. · **用时：** 10 分钟

一份完整的上手教程：安装 Studio，做一个让 M4 Sherman 只卖 $1 的模组，并在游戏中看到它。

## 1. 安装 RUSE Studio

1. 从 [Studio 发布页](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=studio) 下载安装程序并运行
   （“Windows 已保护你的电脑”：**更多信息**，**仍要运行**）。
2. 第一次启动时会把游戏的文件读进一个索引：需要一两分钟，每次游戏更新后读一次。

## 2. 制作模组

Studio 打开时显示 **你想做什么？**：**继续制作模组**、**开始新模组** 或 **跳过**（勾选
**总是跳过此画面** 后，以后会直接进入各个标签页；在 设置 中可以把它找回来）。

1. 点击 **开始新模组**。
2. 输入一个名称，例如 `cheap-sherman`（玩家在 Launcher 中看到的名称），然后点击 **创建**。Studio 会在你的新模组上打开。

已经在 Studio 里了？顶栏的 **模组** 菜单也有 **新建模组…**：输入一个名称，然后点击 **创建**。

从现在起，你改动的一切都保存在这个模组里，绝不会改到游戏本身。

## 3. 修改 Sherman

1. 打开 **单位** 标签页，在搜索框中输入 `sherman`。
2. 点击 **M4 Sherman**。
3. 找到它的价格，输入 `1`。它会立即保存，旧数值显示在旁边。**撤销** 可以把它改回去。

## 4. 测试

1. 点击 **在游戏中测试**（顶栏）。Studio 会检查模组，构建模组版副本（整台电脑共用一份，位于游戏所在驱动器上的 `RUSE-Instances\Modded game`，或你在设置中选择的文件夹），然后启动 R.U.S.E.
2. 在游戏主菜单中点击 **战斗**（与电脑的自由对战），任选一张地图，选择美国，
   打开 **装甲基地**：Sherman 只要 $1。

> [!TIP]
> 如果顶栏下方出现的是一条红色横条，说明模组检查在你模组的某个文件中发现了错误。请看
> [[出问题时|出问题时]]。
