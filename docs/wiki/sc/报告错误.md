# 报告错误

> **你需要：** 一个免费的 GitHub 账号 · **用时：** 5 分钟

## 从应用中报告（最快）

- **RUSE Studio：** 设置 > 帮助与社区 > **报告问题**，或错误消息旁边的 **报告**。
- **RUSE Launcher：** 底部栏中的 **报告问题**。

你的浏览器会打开一份新的错误报告，应用和它的版本已经填好（如果你按的是某条错误旁边的“报告”，那条错误也会填好）。在你自己发布之前，什么都不会发送出去。

## 从网站报告

[Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) > **🐞 Bug reports** > **New
discussion**。一个简短的表单会询问详细信息。

## 什么能帮我们修好它

1. **应用和版本**（设置 中会显示）。
2. **你做了什么**，一步一步写，好让我们照着做一遍。
3. **发生了什么**，以及你原本期望发生什么。
4. **消息**，如果有的话：选中它、复制、粘贴。
5. **截图**：把它拖进帖子里。

> [!WARNING]
> 你的文件路径里有你的 Windows 用户名（`C:\Users\<you>\...`）。请改写成 `%LOCALAPPDATA%\...`。
> 应用里的“报告”按钮会替你做这件事。
