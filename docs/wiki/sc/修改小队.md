# 修改小队

> **适用：** 模组作者 · **你需要：** RUSE Studio、一个模组，以及在 Blender 中修改士兵所需的 Blender（免费） · **用时：** 几分钟

让美军 GI 看起来像海军陆战队，给某一名士兵他自己的外观，或者让小队的士兵多一些或少一些。小队的页面从它的士兵开始：上面是小队卡片，下面是每个士兵的一行。

## 1. 你自己的小队

在 **单位** 标签页中选一个小队（比如美军步枪小队）。它的卡片会说明它由什么组成：“5 名士兵：4 名步枪兵（步枪），1 名火箭筒兵（火箭筒）”。游戏自带的小队不能修改：点击卡片上的 **以此单位制作新单位…**，给你的小队起个名字，然后点击 **创建**。它的页面会在它的卡片处打开。

## 2. 在 Blender 中修改整个小队

1. 点击卡片上的 **在 Blender 中修改小队**。Blender 会打开小队的所有士兵，并排站好。还没有 Blender？**获取 Blender（免费）** 会安装它；**选择 Blender…** 可以告诉 Studio 它在哪里。
2. 想改哪个士兵就改哪个：他的形状、颜色、装备。每个士兵都有自己的一份图片副本：涂一个，只有他会变。
3. 给一名士兵装上你自己的头盔、背包或火箭筒：用 **File > Import** 导入，放到他身上，点击它，按住 **Shift+点击** 他的骨骼，然后按 **Ctrl+P > With Automatic Weights**。
4. 点击 Blender 顶部的 **发送到 R.U.S.E. Studio**。
5. 回到 Studio，大按钮现在显示 **带回我的修改**：点击它。每个士兵只得到对他做的修改，卡片会说明谁变了、谁没变。
6. 点击 **在游戏中测试** 查看他们。

在 Blender 中每个士兵都是单独的人物：给一名步枪兵涂装，只有他会变。

## 3. 修改一名士兵

在 **每个士兵** 下，每个士兵都有一行：他的图片、编号和兵种（“第 3 名士兵：步枪兵”），以及他使用的武器。

- **导入模型…** 用一个文件给他模型：在 Blender 中于游戏士兵骨骼上做的，或有自己骨骼的模型（马和骑手）。其他士兵保留他们的模型。
- **恢复游戏中的外观** 只让他恢复游戏中的外观；其他士兵保持各自的外观。
- **移除** 在你确认后把他移出小队：他后面的士兵依次前移一位，他自己的外观会和你的 Blender 文件保存在一起。

## 4. 增加或减少士兵

在卡片上，大按钮下面：

- **士兵 +1** 不用 Blender，立刻多加一名步枪兵。他排在火箭筒兵前面，外观和你大多数步枪兵一样。
- **士兵 −1** 立刻移除最后一名步枪兵。火箭筒兵仍排在最后。
- **添加士兵** 让你选择谁加入：**复制这个小队里的一名士兵**、**来自另一个单位的士兵** 或 **模型文件…**。Blender 只打开他一个人：改不改都行，点击 **发送到 R.U.S.E. Studio**，再在 Studio 中点击 **带回我的修改**，他就会排在火箭筒兵前面加入小队。

小队目前有 2 到 8 名士兵，并且最后几名士兵携带的每个火箭筒、火焰喷射器或炸药都各留一名士兵。只有你自己做的小队才有这些按钮：游戏自带的小队保留它们的士兵。

## 值得知道

- 士兵下方的 **更多选项** 会说明你的模组把每个士兵的模型和你的 Blender 文件保存在哪里；**在文件夹中显示** 会打开文件夹。
- 带回修改之前就关掉了 Blender？大按钮下面的小按钮 **带回我的修改** 会取你最后发送的内容。
- 小队的制服在数值旁边的 **外观与动作** 里：**自定义制服** 给小队一套自己的制服，**在 Blender 中重新涂装** 会一次给所有士兵涂装。小队要么使用你的模型，要么使用制服。
- 还没有在游戏中试过：8 名或 2 名士兵的小队。
