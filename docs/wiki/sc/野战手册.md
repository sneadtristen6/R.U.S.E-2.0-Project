# 野战手册

**RUSE Launcher** 和 **RUSE Studio** 的分步指南。想了解这个项目是什么、新闻和下载，请看
[项目页面](https://github.com/sneadtristen6/R.U.S.E-2.0-Project)。

## 第一次来？从这里开始

- **玩模组：** [[安装与游玩|安装与游玩]]。从
  [Launcher 发布页](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=launcher) 下载 **RUSE-Launcher-Setup**，运行它，打开
  **RUSE Launcher**，点击 **支持的模组**，勾选一个模组并按 **安装**，把它放进一个模组组合，然后点 **开始游戏**。五分钟。
- **做模组：** 安装 **RUSE Studio**（同一个页面，在最后），然后看 [[你的第一个模组|你的第一个模组]]。
- **卡住了？** 看 [[出问题时|出问题时]]，或者在
  [Discord](https://discord.gg/h54t5baNsC) 上提问。
- **你的副本：** 两个应用都只能配合你在 Steam 上拥有的 R.U.S.E. 副本使用。R.U.S.E. 上架 Steam 之前的盒装版，
  或应用无法确认的副本：请看 [[出问题时|出问题时]]。
- **你的语言：** 两个应用和这本手册都有十一种语言：English、Français、Deutsch、Italiano、
  Español、Polski、Русский、Čeština、日本語、简体中文 和 فارسی（波斯语）。每个应用的右上角都有一个语言按钮；
  手册的其他语言在侧边栏的第一行。

> [!WARNING]
> **仍有错误，使用时请自行斟酌：** 地图绘制 的纹理，
> 以及两种空白地图（空白地形和空白海洋）。

## 两个应用，两种用途

| | **RUSE Launcher** | **RUSE Studio** |
|---|---|---|
| **适用于** | 每个玩模组的人 | 制作模组的人 |
| **作用** | 把模组加载进你的游戏，并确保它们能一起运行：你玩的每个模组都要经过它 | 制作模组：新地图、剧本编辑、单位、城镇、军队 |
| **你得到** | 一个装好模组的游戏，点一下就能玩，你的 Steam 安装不受影响 | 一个可以在游戏中测试、然后导出和分享的模组 |

在 Studio 中做的模组通过 Launcher 来玩：导出它、添加它、开始玩。Studio 中的 **在游戏中测试**
会自己启动一个快速测试副本，让你边做边检查。
