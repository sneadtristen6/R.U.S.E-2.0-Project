# 安装与游玩

> **适用：** 玩家 · **你需要：** 已安装的 Steam 版 R.U.S.E. · **用时：** 5 分钟

**简短版本：** 从发布页下载 **RUSE-Launcher-Setup**，运行它，打开 **RUSE Launcher**，点击
**支持的模组**，勾选一个模组并按 **安装**，把它放进一个模组组合，然后点 **开始游戏**。
下面每一步都会准确说明要点哪里。

玩模组只需要 **RUSE Launcher**。**RUSE Studio** 是用来制作模组的（见本页末尾）。

## 第 1 步：下载 Launcher

1. 打开 [Launcher 发布页](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=launcher)。
2. 最新的版本在最上面，标有 **Latest**（例如 *RUSE Launcher 0.4.8.9*）。
3. 向下滚动到它下方的 **Assets**，点击 **RUSE-Launcher-Setup-0.4.8.9.exe**
   （版本号会变；选择以 `RUSE-Launcher-Setup` 开头的 `.exe`）。你的浏览器会下载它。

那里的其他文件（`RUSE-Launcher-notes.json`、*Source code*）都不需要。

## 第 2 步：安装

1. 打开你下载的文件（通常在你的 **下载** 文件夹中）。
2. **出现“Windows 已保护你的电脑”？** 点击 **更多信息**，然后点 **仍要运行**。
   这个应用对 Windows 的信誉检查来说还是新面孔；它的代码在这个 GitHub 上公开。
3. 一路点击完成安装程序。保持 **保留一份我的游戏文件的干净副本** 为勾选状态：这些应用从不修改你的游戏文件夹，
   但其他模组管理器和手动修改可能会改，而每个模组版游戏都是用这些文件构建的。
   副本会在应用第一次启动时制作（需要几分钟，占用的磁盘空间和游戏差不多）。
4. 启动 **RUSE Launcher**（开始菜单，或桌面快捷方式）。第一次启动时会显示 **选择你的语言**：十一种语言任选，
   即游戏的十种语言加上波斯语（فارسی）；顶部的语言按钮随时可以更改它。它会自己通过 Steam 找到 R.U.S.E.。
   如果它说找不到：**设置 > 游戏文件夹 > 选择文件夹…**，然后选择包含 `RUSE.exe` 的文件夹
   （通常是 `C:\Program Files (x86)\Steam\steamapps\common\R.U.S.E`）。

> [!IMPORTANT]
> **R.U.S.E. 2.0 只能配合你在 Steam 上拥有的游戏副本使用。** 在模组版游戏启动之前，Launcher 和
> Studio 会检查游戏文件夹：Steam 对安装在那里的 R.U.S.E. 的记录、里面 Steam 自己的文件，以及没有
> 让游戏不经 Steam 就能运行的文件。如果它们无法确认，会有一个框说明原因和该怎么做（在那之前 开始游戏
> 保持不可用）：参见 [[出问题时|出问题时]]。

## 第 3 步：获取模组

**从我们的列表（最简单）：** 点击 **支持的模组**，勾选你想要的模组，然后按 **安装**。每个文件在进入你的库之前，
都会被下载并对照列表进行检查。

**从别人分享的文件：** 点击 **添加模组文件…** 并选择文件，或者把它拖到窗口上。Launcher
接受：
- `.rusemod`：用 RUSE Studio 制作；
- `.rmod`：为 LittleGroove 的 RUSE Mod Manager 制作；
- `.zip`：压缩成 zip 的模组文件夹。

它会先检查文件：不是模组的文件，或含有程序的文件，会被拒绝并说明原因。

**以游戏自身文件形式提供的旧模组**（别人让你复制到游戏文件夹里的 `.dat` 包）：点击
**转换旧模组…**，选择它的文件夹，给它取个名字，然后点击 **转换并添加到库**。
你的游戏文件夹不会被动到。

## 第 4 步：选择要玩的内容

1. **模组组合** 就是你一起玩的那些模组，按顺序排列。点击 **新建模组组合…**，添加模组并把它们排好顺序
   （当两个模组修改同一样东西时，排在下面的那个生效）。
2. 如果两个模组不能一起玩，Launcher 会在你开始玩之前说明是哪两个以及原因。

## 第 5 步：开始游戏

选择你的模组组合，然后按 **开始游戏**。第一次时，Launcher 会构建一份模组版的游戏副本（大约一分钟）；
之后只处理有变化的部分。然后 R.U.S.E. 会带着你的模组启动。

你的模组版游戏会显示 **金色的 R.U.S.E. 2.0**：它以一段战斗场景开场，主菜单、各个菜单和加载
画面都带有金色标题。它第一次会在你的电脑上用你自己游戏的文件制作（需要几分钟，只做一次）。
要保留游戏自己的标题，请在 **设置** 中取消勾选 **游戏标题**。

> [!NOTE]
> 从 **Steam** 启动 R.U.S.E. 会启动 **没有** 模组的游戏，和以前一样。要带模组玩，请从
> Launcher 的 **开始游戏** 启动。你的 Steam 安装永远不会被改动。

## 更新

Launcher 每次启动时都会检查有没有新版本：有新版本时点击 **更新**。如果更新失败，
提示“certificate verify failed”，请在浏览器中从第 1 步下载最新的 `RUSE-Launcher-Setup` 并运行它：
它会覆盖安装旧版本，并保留你的模组。

**必需的更新：** 标记为必需的更新（重要的更新，例如安全修复）无法跳过。一个窗口会盖住 Launcher，更新会自动安装，然后 Launcher 重新打开；安装完成前，**开始游戏** 无法使用。没有联网时，窗口会说明这一点：请联网后点 **重试**。Studio 也一样，**在游戏中测试** 会无法使用。

## 遇到问题？

| 你看到的 | 怎么办 |
|---|---|
| “Windows 已保护你的电脑” | **更多信息**，然后 **仍要运行**（第 2 步）。 |
| Launcher 找不到 R.U.S.E. | **设置 > 游戏文件夹 > 选择文件夹…**，选择包含 `RUSE.exe` 的文件夹。 |
| “certificate verify failed: unable to get local issuer certificate” | 获取 Launcher 0.4.8.4 或更新版本（第 1 步）；参见 [[出问题时|出问题时]]。 |
| 安装模组时出现“unable to get issuer certificate”或“此电脑不信任该网站的安全证书” | 获取 Launcher 0.4.8.9 或更新版本（第 1 步），或者在浏览器中下载模组，然后使用 **添加模组文件…**；参见 [[出问题时|出问题时]]。 |
| 游戏启动了，却没有我的模组 | 用 Launcher 的 **开始游戏** 启动它，而不是从 Steam 启动。 |
| 朋友无法加入我的游戏 | 每个人都需要相同的模组，并且顺序相同：[[和朋友一起玩|和朋友一起玩]]。 |
| 其他任何问题 | 看 [[出问题时|出问题时]]，或者在 [Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) 或 [Discord](https://discord.gg/h54t5baNsC) 上提问。 |

## Linux 和 Steam Deck（通过 Proton）

当应用自己的窗口无法显示它的页面时（在 Proton 下窗口会一直是蓝色的，因为 Microsoft 的 WebView2 在那里无法启动），
应用会改为在你的网页浏览器中打开，并有一个小窗口说明这一点：玩的时候请保持这个小窗口开着，关闭它就会关闭应用。
尚未在 Linux 上测试：请在 [Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions)
告诉我们情况如何。

## 制作模组：RUSE Studio

1. 打开 [Studio 发布页](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=studio)。Studio
   是预览版，所以它的发布标有 **Pre-release**：选择最新的那个。
2. 在 **Assets** 下，点击 **RUSE-Studio-Setup-0.9.8.9.exe**（最新版本），像第 2 步那样运行它。
3. 启动 **RUSE Studio**，然后按照 [[你的第一个模组|你的第一个模组]] 操作（10 分钟）。
