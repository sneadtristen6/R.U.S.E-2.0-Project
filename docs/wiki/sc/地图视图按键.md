# 地图视图按键

这些按键在 Studio 的地图视图打开、并且没有文本框获得焦点时起作用。任何一个都可以在 **设置 >
地图视图按键** 中修改（点击一个按键，再按下你想要的键）。如果另一个操作已经在用这个键，会先问你：**交换**（两个
操作互换按键）、**占用**（另一个操作会没有按键，直到你给它一个）或 **取消**。按键按它们在键盘上的位置来算，所以在 AZERTY 键盘上，W A S
D 也是同样位置的那几个键。

| 按键 | 作用 |
|---|---|
| **W A S D** 或方向键 | 移动视角（按住 **Shift** 速度快三倍） |
| **Q** / **E** | 绕着你注视的点转动 |
| **R** / **F** | 放大 / 缩小 |
| **1** 到 **0** | 选择前十个画笔之一 |
| **B** | 开启或关闭画笔 |
| **P** | 开启或关闭放置 |
| **[** / **]** | 减小 / 增大大小（画笔和放置的物体） |
| **-** / **=** | 降低 / 提高强度（画笔），或旋转（放置的物体） |
| **Esc** | 回到四处查看；丢弃做了一半的直线、网格或路径；取消所有选中 |
| **Ctrl+Z** | 撤销上一笔、上一个放置的物体、上一次移动或删除 |
| **Ctrl+Y** 或 **Ctrl+Shift+Z** | 重做被撤销的操作 |
| **Shift+click** | 添加到已选中的东西（**选择**） |
| **Delete** | 删除选中的东西 |
| **Enter** | 完成一条路径或一条自由道路 |

## 排列面板

地图面板（左上）和工具（底部）可以移到任何地方：拖动它们的手柄（⠿）。手柄旁边的箭头可以折叠面板（地图面板折叠到只剩标题，工具折叠到只剩工具栏）。双击手柄可以把那个面板放回原处。你的布局会被保留。

## 用鼠标

| 鼠标 | 作用 |
|---|---|
| 拖动 | 转动视角（开启工具时：使用工具） |
| 中键拖动 | 转动视角（开启工具时也一样） |
| 右键拖动 | 移动视角 |
| 滚轮 | 缩放 |
