# 经济、AI等：LittleGroove 的工具

> **适用：** 模组作者 · **你需要：** RUSE Studio 0.9.8.1 或更新版本，以及一个模组 · **用时：** 随你

LittleGroove 的 RUSE-Mod-Manager 有一些 Studio 没有的工具。现在它们都在 Studio 里了，每一项都作用于你自己的模组：
修改会立即保存在模组里，游戏的文件永远不会被改动。

## AI 与玩家设置标签页

一个标签页，分三部分：**玩家设置**、**游戏规则** 和 **电脑玩家**。

### 玩家设置

起始资金和收入、补给站（每辆卡车的资金、每个车队的卡车数、车队之间的间隔时间）、生产上限，以及各方开局时的计谋卡。
一处修改对所有游戏模式都有效；核战争模式有自己数值的地方，会有它自己的输入框。补给站和行政建筑都是建筑：
它们的价格、建造时间和耐久度在 **单位** 标签页上。
已在游戏中看到：起始资金和开局时的计谋卡。

**地图上的补给站**（在“补给站”下）：给每个补给站更多卡车，也就是更多资金，范围是 **所有地图** 或 **一张地图：**，
由你选择。把每个补给站的卡车数乘上一个倍数（**倍的卡车**），或者给它们全都同样的数量（**辆（每个）**）。
上方那一行会说明按你的数值一个补给站里有多少。在 地图 标签页上单独设定过卡车数的补给站会保留它们。
每个补给站超过 1,000 辆卡车的模组，请用 Launcher 0.4.8.4 或更新版本来玩。
已在游戏中看到（D日 的补给站有 500 辆卡车；其他地图是原来的三倍）。

### 游戏规则

游戏为所有玩家保存的其他每一条规则，分组列出：战斗与投降、人口、移动与道路、射击与目标、单位的自主行为、伤害与压制、
树林与视野、飞机、计谋卡的效果、手柄、放置建筑、在线排位赛、轮廓和箭头、屏幕上的效果、阵营和扇区的颜色（每个都有取色器），
最后是几项用途尚不清楚的数值。每一项都会说明它做什么，以及游戏中的值是多少。尚未在游戏中测试。

### 电脑玩家

电脑玩家怎么玩。一个电脑玩家混合了三组数值：**默认**、它的难度和它的档案（两者都在游戏大厅中选择）；
选一组就能查看和修改它的数值：何时开始进攻、等到多强才出手、如何防守、偏好哪些单位，以及它的计谋卡。
每个数值在每一组上都能修改：某组没有列出的数值在游戏中算作 0，给它一个数字就会把它加入你的模组。
下面是对所有电脑玩家都适用的内容（让它发动进攻的军队价值、它的诱饵……）。
已在游戏中看到：从菜单中拿掉一张计谋卡、在菜单中移动一张、一张卡的持续时间，以及“简单”难度何时开始进攻。
其余尚未在游戏中测试。

**地图与任务脚本**（在其下方）：游戏在其地图上运行的脚本（战役的章节、挑战、行动），以 Python 形式显示，供你阅读。
**复制** 可以复制其中一个。

## 单位的升级与研究框

在单位的页面上：它是哪个单位的升级（**升级自**）、它自己的升级，以及它的研究价格和时间。
选择另一个单位，或者 **无：独立单位**。参见 [[编辑单位|编辑单位]]。

## 所有数值和文件标签页

分两部分，用列表顶部的切换来选择。

**所有数值：** 游戏的任何对象和数值，都可以在你的模组中修改：添加或拿掉一个数值，创建或删除一个对象，
给文本数值写上它自己的文字。尚未在游戏中测试。

**文件：** 游戏包里的任何文件：选一个包，再选一个文件，按它本来的样子查看（图片、文本表格、任务脚本……）。
**保存副本…** 把它另存出来；**用我的文件替换…** 把你的文件放进你的模组；**向此包添加我的文件…** 添加一个新文件。
你的模组只保存你修改的内容，从不保存游戏文件的副本。尚未在游戏中测试。

## 任务和地图

任务的脚本可以修改，Studio 会检查它是否出现在菜单中、它需要的每个文件是否都能加载，以及它的文本；
它还可以在所在的菜单中上移或下移。在地图上：城镇和山丘的名称、命名的点和区域，以及地图物件的名称和朝向。
可以在单位、数值或电脑玩家上记 **备注**。尚未在游戏中测试。
