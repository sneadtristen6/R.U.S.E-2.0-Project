# Play with friends

> **For:** players · **You need:** RUSE Launcher, and the same mods as your friends · **Takes:** 5 minutes

Every player needs the **same mods in the same order**, or the game won't match.

1. The host picks the mod set and clicks **Share**: the set's load order is copied as text.
2. The host sends that text (Discord, chat...), along with the mod files anyone is missing.
3. Each friend adds the missing mod files, then clicks **Import a load order...** and pastes the text: a new mod set
   with the same mods in the same order.
4. Everyone presses **Play**, and the host sets up the game as usual.

> [!TIP]
> The text is the same format RUSE-Mod-Manager copies and reads, so friends using it can join too.
