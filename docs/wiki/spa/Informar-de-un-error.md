# Informar de un error

> **Necesitas:** una cuenta gratuita de GitHub · **Lleva:** 5 minutos

## Desde la aplicación (lo más rápido)

- **RUSE Studio:** Ajustes > Ayuda y comunidad > **Informar de un problema**, o **Informar** junto a un mensaje de
  error.
- **RUSE Launcher:** **Informar de un problema** en la barra de abajo.

Tu navegador abre un nuevo informe de error con la aplicación y su versión ya rellenadas (y el error, si pulsaste
Informar junto a uno). No se envía nada hasta que lo publicas tú mismo.

## Desde la web

[Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) > **🐞 Bug reports** > **New
discussion**. Un formulario corto te pide los detalles.

## Lo que nos ayuda a arreglarlo

1. **La aplicación y su versión** (Ajustes la muestra).
2. **Lo que hiciste**, paso a paso, para que podamos hacer lo mismo.
3. **Lo que pasó**, y lo que esperabas.
4. **El mensaje**, si lo hubo: selecciónalo, cópialo, pégalo.
5. **Una captura de pantalla**: arrástrala al mensaje.

> [!WARNING]
> Las rutas de tus archivos contienen tu nombre de usuario de Windows (`C:\Users\<you>\...`). Escribe
> `%LOCALAPPDATA%\...` en su lugar. Los botones Informar de las aplicaciones lo hacen por ti.
