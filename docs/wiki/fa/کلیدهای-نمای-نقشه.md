# کلیدهای نمای نقشه

این کلیدها وقتی کار می‌کنند که نمای نقشهٔ استودیو باز باشد و هیچ جعبهٔ متنی در حال نوشتن نباشد. هر کدام را می‌توانید در **تنظیمات >
کلیدهای نمای نقشه** تغییر دهید (روی یک کلید کلیک کنید، بعد کلیدی را که می‌خواهید بزنید). اگر کار دیگری از قبل آن کلید را داشته باشد، اول می‌پرسد:
**جابه‌جایی** (دو کار کلیدهایشان را با هم عوض می‌کنند)، **بگیرش** (کار دیگر بی‌کلید می‌ماند تا وقتی که به آن کلیدی بدهید)
یا **لغو**. کلیدها بر اساس جایشان روی صفحه‌کلید کار می‌کنند، پس W A S
D روی صفحه‌کلید AZERTY هم همان کلیدها هستند.

| کلید | کار |
|---|---|
| **W A S D** یا کلیدهای جهت‌نما | جابه‌جا کردن نما (**Shift** را نگه دارید تا سه برابر سریع‌تر برود) |
| **Q** / **E** | چرخیدن دور نقطه‌ای که به آن نگاه می‌کنید |
| **R** / **F** | بزرگ‌نمایی / کوچک‌نمایی |
| **1** تا **0** | انتخاب یکی از ده قلم‌موی اول |
| **B** | روشن یا خاموش کردن قلم‌مو |
| **P** | روشن یا خاموش کردن گذاشتن |
| **[** / **]** | کوچک‌تر / بزرگ‌تر (قلم‌موها و اشیای گذاشته‌شده) |
| **-** / **=** | شدت کمتر / بیشتر (قلم‌موها)، یا چرخاندن (اشیای گذاشته‌شده) |
| **Esc** | بازگشت به نگاه کردن به اطراف؛ رها کردن خط، شبکه یا مسیرِ نیمه‌کاره؛ انتخاب نکردن هیچ چیز |
| **Ctrl+Z** | واگرد آخرین ضربهٔ قلم‌مو، شیء گذاشته‌شده، جابه‌جایی یا حذف |
| **Ctrl+Y** یا **Ctrl+Shift+Z** | ازنو کردن آنچه واگرد برگردانده |
| **Shift+click** | افزودن به آنچه انتخاب شده (**انتخاب**) |
| **Delete** | حذف آنچه انتخاب شده |
| **Enter** | تمام کردن یک مسیر یا یک جادهٔ آزاد |

## چیدن پنل‌ها

پنل نقشه (بالا سمت چپ) و ابزارها (پایین) را می‌توانید هر جا ببرید: آن‌ها را از دستگیره‌شان (⠿) بکشید. پیکان کنار دستگیره
یک پنل را جمع می‌کند (پنل نقشه تا عنوانش، ابزارها تا نوارشان). روی یک دستگیره دوبار کلیک کنید تا آن
پنل سر جای خودش برگردد. چیدمان شما نگه داشته می‌شود.

## با ماوس

| ماوس | کار |
|---|---|
| کشیدن | چرخاندن نما (وقتی ابزاری روشن است: کار با ابزار) |
| کشیدن با دکمهٔ وسط | چرخاندن نما (وقتی ابزاری روشن است هم) |
| کشیدن با دکمهٔ راست | جابه‌جا کردن نما |
| چرخ ماوس | بزرگ‌نمایی و کوچک‌نمایی |
