# Názvy map

Hráči znají mapu podle jejího názvu; soubory hry a složky vašeho modu používají její **název balíku**. Změny mapy v modu
patří do `maps/<pack name>/`, například `maps/SuperCrossRoads4/` pro Blitz, nikdy `maps/Blitz/`.

Seznam map ve Studiu ukazuje obojí: nejdřív název, za tečkou název balíku. Jeden balík často obsahuje několik map
(mapu Bitev a Operace hrané na stejném terénu, nebo několik kapitol Kampaně).
