# Klávesy zobrazení mapy

Klávesy fungují, když je ve Studiu otevřené zobrazení mapy a žádné textové pole nemá fokus. Kteroukoli z nich změníte
v **Nastavení > Klávesy zobrazení mapy** (klikněte na klávesu, pak stiskněte tu, kterou chcete). Klávesa, kterou už má
jiná akce, se nejdřív zeptá: **Prohodit** (obě si klávesy vymění), **Převzít** (ta druhá zůstane bez klávesy, dokud jí
nějakou nedáte) nebo **Zrušit**. Klávesy se řídí tím, kde na klávesnici leží, takže W A S D jsou stejné klávesy i na
klávesnici AZERTY.

| Klávesa | Co dělá |
|---|---|
| **W A S D** nebo šipky | posun pohledu (podržte **Shift** pro trojnásobnou rychlost) |
| **Q** / **E** | otáčení kolem bodu, na který se díváte |
| **R** / **F** | přiblížení / oddálení |
| **1** až **0** | výběr jednoho z prvních deseti štětců |
| **B** | štětec zapnout nebo vypnout |
| **P** | umisťování zapnout nebo vypnout |
| **[** / **]** | zmenšit / zvětšit (štětce a umisťované objekty) |
| **-** / **=** | síla dolů / nahoru (štětce), nebo otočení (umisťované objekty) |
| **Esc** | zpět k rozhlížení; zahodí rozdělanou řadu, mřížku nebo trasu; zruší výběr |
| **Ctrl+Z** | vrátit poslední tah, umístěný objekt, přesun nebo smazání |
| **Ctrl+Y** nebo **Ctrl+Shift+Z** | znovu provést, co Zpět vrátilo |
| **Shift+klik** | přidat k vybranému (**Výběr**) |
| **Delete** | smazat vybrané |
| **Enter** | dokončit trasu nebo volnou silnici |

## Uspořádání panelů

Panel mapy (vlevo nahoře) a nástroje (dole) můžete přesunout kamkoli: přetáhněte je za úchyt (⠿). Šipka vedle něj
sbalí panel (panel mapy na jeho název, nástroje na jejich lištu). Dvojklikem na úchyt vrátíte ten panel na původní
místo. Vaše rozložení se zachová.

## Myší

| Myš | Co dělá |
|---|---|
| tažení | otáčení pohledu (když je zapnutý nástroj: použití nástroje) |
| tažení prostředním tlačítkem | otáčení pohledu (i se zapnutým nástrojem) |
| tažení pravým tlačítkem | posun pohledu |
| kolečko | přiblížení |
