# Hraní s přáteli

> **Pro:** hráče · **Potřebujete:** RUSE Launcher a stejné mody jako vaši přátelé · **Zabere:** 5 minut

Každý hráč potřebuje **stejné mody ve stejném pořadí**, jinak si hry nebudou odpovídat.

1. Hostitel vybere sadu modů a klikne na **Sdílet**: pořadí načítání sady se zkopíruje jako text.
2. Hostitel pošle tento text (Discord, chat...) spolu se soubory modů, které někomu chybějí.
3. Každý přítel přidá chybějící soubory modů, pak klikne na **Importovat pořadí načítání…** a vloží text: vznikne
   nová sada modů se stejnými mody ve stejném pořadí.
4. Všichni stisknou **Hrát** a hostitel založí hru jako obvykle.

> [!TIP]
> Text má stejný formát, jaký kopíruje a čte RUSE-Mod-Manager, takže se mohou přidat i přátelé, kteří ho používají.

**Připravujeme:** kódy pro připojení, krátký kód, který před začátkem hry ověří, že všichni mají přesně stejné mody.
