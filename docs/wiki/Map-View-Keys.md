# Map view keys

The keys work while the Studio's map view is open and no text box has the focus. Change any of them in **Settings >
Map view keys** (click a key, then press the one you want). A key another action already has asks first: **Swap** (the
two trade keys), **Take it** (the other is left without one until you give it one) or **Cancel**. The keys follow
where they are on the keyboard, so W A S D are the same keys on an AZERTY keyboard.

| Key | Does |
|---|---|
| **W A S D** or the arrows | move the view (hold **Shift** to go three times faster) |
| **Q** / **E** | turn around the point you look at |
| **R** / **F** | zoom in / out |
| **1** to **0** | pick one of the first ten brushes |
| **B** | brush on or off |
| **P** | place on or off |
| **[** / **]** | size down / up (brushes and placed objects) |
| **-** / **=** | strength down / up (brushes), or turn (placed objects) |
| **Esc** | back to looking around; drops a line, grid or path half made; picks nothing |
| **Ctrl+Z** | undo the last stroke, placed object, move or delete |
| **Ctrl+Y** or **Ctrl+Shift+Z** | redo what Undo took back |
| **Shift+click** | add to what's picked (**Select**) |
| **Delete** | delete what's picked |
| **Enter** | finish a path or a freeform road |

## Arrange the panels

The map panel (top left) and the tools (bottom) move anywhere: drag them by their grip (⠿). The arrow next to it
folds a panel (the map panel down to its title, the tools down to their bar). Double-click a grip to put that
panel back. Your layout is kept.

## With the mouse

| Mouse | Does |
|---|---|
| drag | turn the view (while a tool is on: use the tool) |
| middle-drag | turn the view (with a tool on too) |
| right-drag | move the view |
| wheel | zoom |
