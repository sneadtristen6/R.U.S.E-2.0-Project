# Map view keys

The keys work while the Studio's map view is open and no text box has the focus. Change any of them in **Settings >
Map view keys** (click a key, then press the one you want). The keys follow where they are on the keyboard, so W A S
D are the same keys on an AZERTY keyboard.

| Key | Does |
|---|---|
| **W A S D** or the arrows | move the view (hold **Shift** to go three times faster) |
| **Q** / **E** | turn around the point you look at |
| **R** / **F** | zoom in / out |
| **1** to **0** | pick one of the first ten brushes |
| **B** | brush on or off |
| **P** | place on or off |
| **[** / **]** | size down / up (brushes and placed objects) |
| **-** / **=** | strength down / up (brushes), or turn (placed objects) |
| **Esc** | back to looking around |
| **Ctrl+Z** | undo the last stroke or placed object |

## With the mouse

| Mouse | Does |
|---|---|
| drag | turn the view (while a tool is on: use the tool) |
| middle-drag | turn the view, while a tool is on |
| right-drag | move the view |
| wheel | zoom |
