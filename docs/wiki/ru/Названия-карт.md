# Названия карт

Игроки знают карту по её названию; файлы игры и папки вашего мода используют её **имя пакета**. Изменения мода для
карты идут в `maps/<pack name>/`, например `maps/SuperCrossRoads4/` для карты «Блиц», но никогда не `maps/Blitz/`.

Список карт в Studio показывает и то, и другое: сначала название, после точки — имя пакета. Один пакет часто содержит
несколько карт (карту Битв и операции, сыгранные на той же земле, или несколько глав кампании).
