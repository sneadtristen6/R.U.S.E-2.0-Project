# Клавиши вида карты

Клавиши работают, пока в Studio открыт вид карты и ни одно текстовое поле не в фокусе. Любую из них можно изменить в
**Настройки > Клавиши вида карты** (нажмите на клавишу, затем нажмите нужную). Если клавиша уже занята другим действием, Studio
сначала спрашивает: **Поменять** (два действия меняются клавишами), **Забрать** (другое действие остаётся без клавиши,
пока вы не дадите ему новую) или **Отмена**. Клавиши определяются по своему месту на клавиатуре, так что W A S D — те же
самые клавиши и на клавиатуре AZERTY.

| Клавиша | Действие |
|---|---|
| **W A S D** или стрелки | двигать вид (удерживайте **Shift**, чтобы втрое быстрее) |
| **Q** / **E** | поворот вокруг точки, на которую вы смотрите |
| **R** / **F** | приблизить / отдалить |
| от **1** до **0** | выбрать одну из первых десяти кистей |
| **B** | кисть вкл./выкл. |
| **P** | размещение вкл./выкл. |
| **[** / **]** | меньше / больше (кисти и размещаемые объекты) |
| **-** / **=** | сила меньше / больше (кисти) или поворот (размещаемые объекты) |
| **Esc** | назад к осмотру; бросает недоделанную линию, сетку или путь; снимает выделение |
| **Ctrl+Z** | отменить последний мазок, поставленный объект, перемещение или удаление |
| **Ctrl+Y** или **Ctrl+Shift+Z** | повторить то, что отменила кнопка «Отменить» |
| **Shift+щелчок** | добавить к выделенному (**Выбор**) |
| **Delete** | удалить выделенное |
| **Enter** | закончить путь или произвольную дорогу |

## Расположение панелей

Панель карты (вверху слева) и инструменты (внизу) можно передвинуть куда угодно: тяните их за ручку (⠿). Стрелка рядом
с ней сворачивает панель (панель карты — до её заголовка, инструменты — до их полосы). Двойной щелчок по ручке
возвращает эту панель на место. Ваше расположение сохраняется.

## Мышью

| Мышь | Действие |
|---|---|
| перетаскивание | поворот вида (когда включён инструмент — работа инструментом) |
| перетаскивание средней кнопкой | поворот вида (и при включённом инструменте) |
| перетаскивание правой кнопкой | перемещение вида |
| колесо | масштаб |
