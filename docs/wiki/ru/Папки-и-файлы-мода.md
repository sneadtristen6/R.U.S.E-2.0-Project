# Папки и файлы мода

> **Справка** · Вам никогда не нужно трогать это вручную: Studio записывает эти файлы сам. Эта страница — для случаев,
> когда что-то выглядит неправильно, или для моддеров, которые правят файлы напрямую.

## Где что лежит

| Что | Где |
|---|---|
| Моды Studio | `%LOCALAPPDATA%\RUSE Mod Platform\mods\<mod>` (вставьте это в адресную строку Проводника) |
| Установленные моды лаунчера | `%LOCALAPPDATA%\RUSE Mod Platform\library` |
| Копии игры с модами | Папка, которую вы выбираете в настройках (**Куда идут копии с модами**, в любом из приложений); рекомендуемое место — `RUSE-Instances` на том же диске, что и игра (например, `D:\RUSE-Instances`), где копия использует файлы игры совместно с ней. На другом диске каждая копия — полная копия игры: медленнее и больше. Чистая резервная копия игры (`RUSE-Backup`) лежит рядом. |
| Сама игра | Никогда не меняется |

## Внутри мода

```
my-mod/
  mod.toml                    the mod's name, id, version, author (required)
  src/studio.rndf             unit changes made in the Studio
  text/studio.baseunite.csv   names of new units
  files/replace/gen/...png    a unit's paint (from Blender) or a unit's card, under the game texture it changes
  files/cards/<unit>.png      a new unit's own card in the build menu, named after the new unit
  files/models/<unit>.glb     a new unit's own 3D model (Import model), named after the new unit
  menu_groups.toml            the group of its building's build list each new unit stands in (the Studio writes it)
  maps/<map pack name>/       one folder per map the mod changes:
    terrain.toml                ground brushes (also water, cover and block brushes)
    scenery.toml                buildings, props and trees placed
    scenario.toml               starting points and spawns moved, units added
    cover.toml, movement.toml   cover and movement written by hand
    map.toml                    how many players; or, for a new map, the map it copies and its name
```

## Имя папки карты — это имя пака карты, а не её название

Игроки знают карту по её названию (**Блиц**); файлы игры используют имя её пака (**SuperCrossRoads4**). Папка карты
должна использовать имя пака: `maps/SuperCrossRoads4/`, а не `maps/Blitz/`. Пара для каждой карты есть в
[[Названия карт|Названия-карт]], а список карт в Studio показывает оба: сначала название, после точки — имя пака.

## Новая карта

Мод может добавить в БИТВЫ собственную карту: копию карты из игры или пустую основу, под собственным названием, которую затем меняют остальные
файлы мода. Имя её папки — имя пака новой карты (буквы, цифры и `_`), а её `map.toml` говорит, какую карту она копирует
и как её называют меню:

```toml
copy_of = "SuperCrossRoads4"   # the shipped map it starts from (its pack name: Blitz)

[name]
us = "Blitz Twin"              # English, used where a language is left out
fr = "Blitz jumeau"
```

Затем `maps/BlitzTwin/terrain.toml` и остальное правят копию, а Блиц остаётся таким, как был. Можно скопировать любую
карту из списка БИТВЫ; карты кампании и операций — нельзя. Чтобы играть в неё вместе, двум игрокам нужен один и тот же
мод, как и для любого мода. Новые карты работают в игре (2026-10-03), а **Дублировать карту** в Studio создаёт эту папку
за вас.

## Частые ошибки

| Ошибка | Что происходит | Как исправить |
|---|---|---|
| В архиве zip папка внутри папки | Лаунчер заглядывает на одну папку вглубь и находит мод. Если на две или больше — он говорит, что не нашёл мода. | Упакуйте в zip ту папку, в которой лежит `mod.toml`. |
| Папка карты названа по названию карты | Сборка говорит, что это не имя пака карты. | Переименуйте её в имя пака. |
| В файле, отредактированном вручную, опечатка | Проверка мода называет файл и строку. | Исправьте её или нажмите **Отложить** в Studio. |
| `.exe`, `.dll` или скрипт для ПК внутри мода | Отклоняется: моды несут только данные (собственные скрипты миссий игры в том виде, в каком их сохраняет Studio, — единственное исключение). | Уберите его. |

Если файл не удаётся прочитать, Studio никогда не записывает поверх него: ваша работа никогда не теряется. **Отложить**
переименовывает его в `<name>.broken.toml` рядом с оригиналом.
