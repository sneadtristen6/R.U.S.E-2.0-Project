# Segnalare un bug

> **Ti serve:** un account GitHub gratuito · **Tempo:** 5 minuti

## Dall'app (il modo più rapido)

- **RUSE Studio:** Impostazioni > Aiuto e comunità > **Segnala un problema**, oppure **Segnala** accanto a un messaggio di
  errore.
- **RUSE Launcher:** **Segnala un problema** nella barra in basso.

Il tuo browser apre una nuova segnalazione di bug con l'app e la sua versione già inserite (e l'errore, se hai premuto
Segnala accanto a uno). Non viene inviato nulla finché non la pubblichi tu.

## Dal sito

[Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) > **🐞 Bug reports** > **New
discussion**. Un breve modulo ti chiede i dettagli.

## Cosa ci aiuta a correggerlo

1. **L'app e la versione** (la mostra Impostazioni).
2. **Cosa hai fatto**, passo per passo, così possiamo rifare lo stesso.
3. **Cosa è successo**, e cosa ti aspettavi.
4. **Il messaggio**, se ce n'era uno: selezionalo, copialo, incollalo.
5. **Uno screenshot**: trascinalo nel post.

> [!WARNING]
> I percorsi dei tuoi file contengono il tuo nome utente di Windows (`C:\Users\<you>\...`). Scrivi invece `%LOCALAPPDATA%\...`.
> I pulsanti Segnala delle app lo fanno per te.
