# Map names

Players know a map by its title; the game's files, and your mod's folders, use its **pack name**. A mod's changes to a
map go in `maps/<pack name>/`, for example `maps/SuperCrossRoads4/` for Blitz, never `maps/Blitz/`.

The Studio's map list shows both: the title first, the pack name after the dot. One pack often holds several maps
(a Battles map and the Operations played on the same ground, or several Campaign chapters).
