# Klawisze widoku mapy

Klawisze działają, gdy widok mapy w Studio jest otwarty, a żadne pole tekstowe nie jest aktywne. Każdy z nich zmienisz
w **Ustawienia > Klawisze widoku mapy** (kliknij klawisz, potem naciśnij ten, który chcesz). Klawisz, który ma już inna czynność, najpierw pyta: **Zamień**
(obie wymieniają się klawiszami), **Przejmij** (ta druga zostaje bez klawisza, dopóki jej go nie dasz) albo **Anuluj**.
Klawisze liczą się według
miejsca na klawiaturze, więc W A S D to te same klawisze na klawiaturze AZERTY.

| Klawisz | Działanie |
|---|---|
| **W A S D** albo strzałki | przesuwanie widoku (przytrzymaj **Shift**, by było trzy razy szybciej) |
| **Q** / **E** | obrót wokół punktu, na który patrzysz |
| **R** / **F** | przybliżenie / oddalenie |
| **1** do **0** | wybór jednego z pierwszych dziesięciu pędzli |
| **B** | włączenie lub wyłączenie pędzla |
| **P** | włączenie lub wyłączenie stawiania |
| **[** / **]** | mniejszy / większy rozmiar (pędzle i postawione obiekty) |
| **-** / **=** | mniejsza / większa siła (pędzle) albo obrót (postawione obiekty) |
| **Esc** | powrót do rozglądania się; porzucenie niedokończonej linii, siatki lub ścieżki; odznaczenie wszystkiego |
| **Ctrl+Z** | cofnięcie ostatniego pociągnięcia, postawionego obiektu, przesunięcia lub usunięcia |
| **Ctrl+Y** albo **Ctrl+Shift+Z** | ponowienie tego, co cofnęło Cofnij |
| **Shift+kliknięcie** | dodanie do zaznaczenia (**Zaznacz**) |
| **Delete** | usunięcie zaznaczonego |
| **Enter** | zakończenie ścieżki lub drogi dowolnej |

## Układ paneli

Panel mapy (u góry po lewej) i narzędzia (na dole) można przenieść w dowolne miejsce: przeciągnij je za uchwyt (⠿).
Strzałka obok niego zwija panel (panel mapy do samego tytułu, narzędzia do samego paska). Kliknij dwukrotnie uchwyt,
by odstawić ten panel na miejsce. Twój układ jest zachowywany.

## Myszą

| Mysz | Działanie |
|---|---|
| przeciąganie | obrót widoku (gdy narzędzie jest włączone: użycie narzędzia) |
| przeciąganie środkowym | obrót widoku (także z włączonym narzędziem) |
| przeciąganie prawym | przesuwanie widoku |
| kółko | przybliżanie i oddalanie |
