# Nazwy map

Gracze znają mapę po jej tytule; pliki gry i foldery twojego moda używają jej **nazwy paczki**. Zmiany moda w mapie
trafiają do `maps/<pack name>/`, na przykład `maps/SuperCrossRoads4/` dla Blitz, nigdy do `maps/Blitz/`.

Lista map w Studio pokazuje jedno i drugie: najpierw tytuł, nazwę paczki po kropce. Jedna paczka często zawiera kilka
map (mapę z Bitew i Operacje rozgrywane na tym samym terenie albo kilka rozdziałów Kampanii).
