# Tasten der Kartenansicht

Die Tasten funktionieren, solange die Kartenansicht des Studios offen ist und kein Textfeld den Fokus hat. Du kannst jede von
ihnen unter **Einstellungen > Tasten der Kartenansicht** ändern (klick auf eine Taste, dann drück die gewünschte). Eine Taste,
die schon eine andere Aktion hat, fragt zuerst: **Tauschen** (die beiden tauschen ihre Tasten), **Übernehmen** (die andere
bleibt ohne Taste, bis du ihr eine gibst) oder **Abbrechen**. Die Tasten richten sich danach, wo sie auf der Tastatur
liegen, also sind W A S D auf einer AZERTY-Tastatur dieselben Tasten.

| Taste | Wirkung |
|---|---|
| **W A S D** oder die Pfeiltasten | Ansicht verschieben (**Shift** halten, um dreimal so schnell zu sein) |
| **Q** / **E** | um den Punkt drehen, auf den du schaust |
| **R** / **F** | hinein- / herauszoomen |
| **1** bis **0** | einen der ersten zehn Pinsel wählen |
| **B** | Pinsel an oder aus |
| **P** | Platzieren an oder aus |
| **[** / **]** | Größe kleiner / größer (Pinsel und platzierte Objekte) |
| **-** / **=** | Stärke kleiner / größer (Pinsel), oder drehen (platzierte Objekte) |
| **Esc** | zurück zum Umschauen; verwirft eine halb fertige Linie, ein halb fertiges Raster oder einen halb fertigen Pfad; hebt die Auswahl auf |
| **Ctrl+Z** | den letzten Strich, das zuletzt platzierte Objekt, das letzte Verschieben oder Löschen rückgängig machen |
| **Ctrl+Y** oder **Ctrl+Shift+Z** | wiederherstellen, was Rückgängig zurückgenommen hat |
| **Shift+Klick** | zur Auswahl hinzufügen (**Auswählen**) |
| **Delete** | die Auswahl löschen |
| **Enter** | einen Pfad oder eine Freihand-Straße beenden |

## Die Bereiche anordnen

Der Kartenbereich (oben links) und die Werkzeuge (unten) lassen sich überallhin schieben: zieh sie an ihrem Griff (⠿). Der Pfeil
daneben klappt einen Bereich ein (den Kartenbereich bis auf seinen Titel, die Werkzeuge bis auf ihre Leiste). Ein Doppelklick auf
einen Griff setzt diesen Bereich an seinen Platz zurück. Deine Anordnung bleibt erhalten.

## Mit der Maus

| Maus | Wirkung |
|---|---|
| ziehen | Ansicht drehen (wenn ein Werkzeug an ist: das Werkzeug benutzen) |
| mit der mittleren Taste ziehen | Ansicht drehen (auch wenn ein Werkzeug an ist) |
| mit der rechten Taste ziehen | Ansicht verschieben |
| Mausrad | zoomen |
