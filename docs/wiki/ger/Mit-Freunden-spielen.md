# Mit Freunden spielen

> **Für:** Spieler · **Du brauchst:** RUSE Launcher und dieselben Mods wie deine Freunde · **Dauer:** 5 Minuten

Jeder Spieler braucht **dieselben Mods in derselben Reihenfolge**, sonst passen die Spiele nicht zusammen.

1. Der Host wählt das Mod-Set und klickt auf **Teilen**: die Ladereihenfolge des Sets wird als Text kopiert.
2. Der Host schickt diesen Text (Discord, Chat...), zusammen mit den Mod-Dateien, die jemandem fehlen.
3. Jeder Freund fügt die fehlenden Mod-Dateien hinzu, klickt dann auf **Ladereihenfolge importieren…** und fügt den Text
   ein: ein neues Mod-Set mit denselben Mods in derselben Reihenfolge.
4. Alle drücken auf **Spielen**, und der Host richtet das Spiel wie gewohnt ein.

> [!TIP]
> Der Text hat dasselbe Format, das RUSE-Mod-Manager kopiert und liest, also können auch Freunde mitspielen, die ihn benutzen.

## Prüfen, ob ihr dasselbe Spiel habt: Beitrittscodes

Ein **Beitrittscode** ist ein kurzer Code, der aus deinem gemoddeten Spiel gemacht wird: Derselbe Code heißt dasselbe
Spiel (dieselbe Spielversion, dieselben Mods und Mod-Versionen). Vergleicht eure Codes vor einer Partie, dann wisst ihr,
dass sie nicht auseinanderläuft.

1. Drücke einmal **Spielen** mit dem Mod-Set: Der Code kommt mit der gemoddeten Kopie.
2. Klicke unten im Launcher auf **Beitrittscode**. Das Fenster **RUSE Guard: Ihr Beitrittscode** zeigt deinen:
   **Kopieren** und schick ihn an die, mit denen du spielst.
3. Füge den Code eines Freundes bei **Beitrittscode eines Freundes einfügen** ein und klicke auf **Vergleichen**:
   „Gleiches Spiel: Sie können zusammen spielen.“ oder „Nicht das gleiche Spiel.“ mit dem, was abweicht.

Gut zu wissen:

- Der Code ändert sich, wenn sich deine Mods ändern: Schick ihn nach einer Änderung neu.
- „Kein Code: Diese Mods ändern das Spiel nicht, jeder kann mit Ihnen spielen.“
- Ein Set mit einem Cheat-Mod oder einem Testwerkzeug spielt Mehrspieler und Koop nur mit Spielern, die denselben Code
  haben, und verlässt jede andere Partie nach ein paar Sekunden.
- **Noch nicht voll unterstützt:** Wir haben es im Spiel mit einem Spieler getestet, der allein ein Mehrspieler-Gefecht gegen den Computer gehostet hat, und außerhalb des Spiels mit 20 simulierten Gefechten mit bis zu vier Spielern. Zu zweit in einem echten Gefecht hat es noch niemand gespielt, es kann also noch Fehler haben: Nutze es im Mehrspieler auf eigene Verantwortung. Probier es aus und sag uns auf Discord oder GitHub, was passiert ist: welche RUSE-Guard-Meldung du gesehen hast und ob das Gefecht weiterging.
- **Jede Datei der Kopie prüfen** prüft, ob deine gemoddete Kopie genau so ist, wie sie erstellt wurde.
