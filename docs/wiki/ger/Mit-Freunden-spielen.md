# Mit Freunden spielen

> **Für:** Spieler · **Du brauchst:** RUSE Launcher und dieselben Mods wie deine Freunde · **Dauer:** 5 Minuten

Jeder Spieler braucht **dieselben Mods in derselben Reihenfolge**, sonst passen die Spiele nicht zusammen.

1. Der Host wählt das Mod-Set und klickt auf **Teilen**: die Ladereihenfolge des Sets wird als Text kopiert.
2. Der Host schickt diesen Text (Discord, Chat...), zusammen mit den Mod-Dateien, die jemandem fehlen.
3. Jeder Freund fügt die fehlenden Mod-Dateien hinzu, klickt dann auf **Ladereihenfolge importieren…** und fügt den Text
   ein: ein neues Mod-Set mit denselben Mods in derselben Reihenfolge.
4. Alle drücken auf **Spielen**, und der Host richtet das Spiel wie gewohnt ein.

> [!TIP]
> Der Text hat dasselbe Format, das RUSE-Mod-Manager kopiert und liest, also können auch Freunde mitspielen, die ihn benutzen.

**Demnächst:** Beitrittscodes, ein kurzer Code, der prüft, ob alle genau dieselben Mods haben, bevor das Spiel beginnt.
