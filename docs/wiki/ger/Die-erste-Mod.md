# Die erste Mod

> **Für:** neue Modder · **Du brauchst:** R.U.S.E. auf Steam · **Dauer:** 10 Minuten

Eine vollständige Anleitung: das Studio installieren, einen Mod erstellen, mit dem der M4 Sherman $1 kostet, und das im
Spiel sehen.

## 1. RUSE Studio installieren

1. Lade das Installationsprogramm von den [Studio-Releases](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/releases?q=studio)
   herunter und führ es aus („Der Computer wurde durch Windows geschützt“: **Weitere Informationen**, **Trotzdem ausführen**).
2. Beim ersten Start liest das Studio die Dateien des Spiels in einen Index ein: ein, zwei Minuten, einmal pro Spiel-Update.

## 2. Einen Mod erstellen

Das Studio öffnet sich auf **Was möchten Sie tun?**: **An einem Mod weiterarbeiten**, **Einen neuen Mod beginnen** oder
**Überspringen** (hake **Diesen Bildschirm immer überspringen** an, um von da an direkt zu den Reitern zu gehen; die
Einstellungen bringen ihn zurück).

1. Klick auf **Einen neuen Mod beginnen**.
2. Gib einen Namen ein, zum Beispiel `cheap-sherman` (der Name, den Spieler im Launcher sehen), und klick auf
   **Erstellen**. Das Studio öffnet sich auf deinem neuen Mod.

Schon im Studio? Das Menü **Mod** in der Kopfleiste hat auch **Neue Mod…**: gib einen Namen ein und klick auf
**Erstellen**.

Ab jetzt wird alles, was du änderst, in diesem Mod gespeichert, nie im Spiel.

## 3. Den Sherman ändern

1. Öffne den Reiter **Einheiten** und gib `sherman` in das Suchfeld ein.
2. Klick auf **M4 Sherman**.
3. Such seinen Preis und gib `1` ein. Er wird sofort gespeichert, und der alte Wert steht daneben. **Rückgängig** stellt ihn wieder her.

## 4. Testen

1. Klick auf **Im Spiel testen** (Kopfleiste). Das Studio prüft den Mod, baut die gemoddete Kopie (eine für den ganzen PC, `RUSE-Instances\Modded game` auf dem Laufwerk des Spiels, oder der Ordner, den du in den Einstellungen gewählt hast) und startet R.U.S.E.
2. Klick im Hauptmenü des Spiels auf **KÄMPFE** (ein freies Gefecht gegen den Computer), wähl eine beliebige Karte, spiel die USA und
   öffne die **PANZERBASIS**: der Sherman kostet $1.

> [!TIP]
> Erscheint stattdessen ein roter Balken unter der Kopfleiste, hat die Mod-Prüfung einen Fehler in einer Datei deines Mods gefunden. Siehe
> [[Wenn etwas schiefgeht|Wenn-etwas-schiefgeht]].
