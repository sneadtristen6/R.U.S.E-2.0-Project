# Eine Frage stellen

Im Handbuch nicht gefunden? Frag in
[Discussions > ❓ Help](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) (zum Schreiben brauchst du ein
kostenloses GitHub-Konto).

1. Durchsuche zuerst Help: vielleicht hat schon jemand gefragt.
2. Sag, was du vorhast, was du versucht hast und welche App in welcher Version du benutzt.
3. Wenn eine Antwort das Problem löst, klick auf **Mark as answer**, damit die nächste Person sie findet.

## Beantwortete Fragen

Fragen, die öfter als einmal kommen, werden hier gesammelt, mit einem Link dorthin, wo sie beantwortet wurden.

*Noch keine: stell die erste Frage.*
