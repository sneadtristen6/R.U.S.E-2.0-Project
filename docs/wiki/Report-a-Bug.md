# Report a bug

> **You need:** a free GitHub account · **Takes:** 5 minutes

## From the app (quickest)

- **RUSE Studio:** Settings > Help & community > **Report a problem**, or **Report** next to an error message.
- **RUSE Launcher:** **Report a problem** in the bottom bar.

Your browser opens a new bug report with the app and its version filled in (and the error, if you pressed Report
next to one). Nothing is sent until you post it yourself.

## From the website

[Discussions](https://github.com/sneadtristen6/R.U.S.E-2.0-Project/discussions) > **🐞 Bug reports** > **New
discussion**. A short form asks for the details.

## What helps us fix it

1. **The app and version** (Settings shows it).
2. **What you did**, step by step, so we can do the same.
3. **What happened**, and what you expected.
4. **The message**, if there was one: select it, copy it, paste it.
5. **A screenshot**: drag it into the post.

> [!WARNING]
> Paths to your files contain your Windows user name (`C:\Users\<you>\...`). Write `%LOCALAPPDATA%\...` instead.
> The apps' Report buttons do this for you.
